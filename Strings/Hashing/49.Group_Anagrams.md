# Group Anagrams

| Topic   | Difficulty | Pattern            |
| :------ | :--------- | :----------------- |
| Strings | Medium     | Hashing + Grouping |

---

## 📌 Problem Description

Given an array of strings, group all anagrams together.

Example:

```text
Input:
["eat","tea","tan","ate","nat","bat"]

Output:
[
 ["eat","tea","ate"],
 ["tan","nat"],
 ["bat"]
]
```

---

## 🧠 Core Insight

Anagrams contain the same characters.

If we sort every string:

```text
eat -> aet
tea -> aet
ate -> aet
```

All anagrams produce the same sorted string.

Therefore:

```text
Sorted String = Key
```

can be used to group anagrams.

---

## ⚙️ Algorithm

### Step 1

Create:

```cpp
unordered_map<string, vector<string>> mp;
```

Meaning:

```text
Sorted String -> Group of Strings
```

Example:

```text
"aet" -> ["eat","tea","ate"]

"ant" -> ["tan","nat"]

"abt" -> ["bat"]
```

---

### Step 2

For every string:

```cpp
string word = strs[i];
sort(word.begin(), word.end());
```

Now:

```text
eat -> aet
tea -> aet
ate -> aet
```

---

### Step 3

Store original string inside the group.

```cpp
mp[word].push_back(strs[i]);
```

---

### Step 4

Traverse the map and collect all groups.

```cpp
vector<vector<string>> ans;
```

Push every group into answer.

## 🧠 STL Concepts Used

### unordered_map

```cpp
unordered_map<string, vector<string>> mp;
```

Stores:

```text
Key -> Value
```

Example:

```text
"aet" -> ["eat","tea","ate"]
```

---

### auto

Instead of writing:

```cpp
pair<const string, vector<string>>
```

we write:

```cpp
auto
```

and let the compiler determine the type.

Example:

```cpp
for(auto &it : mp)
```

---

### Why `&` ?

```cpp
for(auto &it : mp)
```

avoids making copies of map elements.

Faster and preferred.

---

### it.first

Represents the key.

Example:

```text
"aet"
```

For:

```text
"aet" -> ["eat","tea","ate"]
```

```cpp
it.first
```

↓

```text
"aet"
```

---

### it.second

Represents the value.

```cpp
it.second
```

↓

```text
["eat","tea","ate"]
```

Type:

```cpp
vector<string>
```

---

### Why Push it.second?

Answer needs:

```cpp
vector<vector<string>>
```

which stores groups.

Example:

```text
[
 ["eat","tea","ate"],
 ["tan","nat"]
]
```

Each group is:

```cpp
vector<string>
```

and:

```cpp
it.second
```

is already a complete group.

So:

```cpp
ans.push_back(it.second);
```

## ⏱ Time Complexity

Let:

```text
n = number of strings
k = average string length
```

Sorting one string:

```text
O(k log k)
```

For all strings:

```text
O(n * k log k)
```

---

## 📦 Space Complexity

Hash Map stores all strings:

```text
O(n * k)
```

## ⚠️ Common Mistakes

### Mistake 1

Using:

```cpp
mp[word] = strs[i];
```

Wrong.

Because:

```cpp
mp[word]
```

is:

```cpp
vector<string>
```

not:

```cpp
string
```

Use:

```cpp
mp[word].push_back(strs[i]);
```

---

### Mistake 2

Pushing:

```cpp
it.first
```

into answer.

Wrong.

Question wants groups:

```cpp
it.second
```

---

### Mistake 3

Forgetting that:

```cpp
sort(word.begin(), word.end());
```

creates the common key.

Without sorting:

```text
eat
tea
ate
```

will never be grouped together.

---

## 🔥 Key Insight

All anagrams become identical after sorting.

Use:

```text
Sorted String
```

as the hash key.

---

## 🎯 Interview One-Liner

Sort each string, use the sorted string as a key in a hash map, and group all original strings sharing the same key.

---

## 💻 Code (C++)

```cpp
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {

        unordered_map<string, vector<string>> mp;

        for(int i = 0; i < strs.size(); i++) {

            string word = strs[i];

            sort(word.begin(), word.end());

            mp[word].push_back(strs[i]);
        }

        vector<vector<string>> ans;

        for(auto &it : mp) {
            ans.push_back(it.second);
        }

        return ans;
    }
};
```
