# Valid Anagram

| Topic   | Difficulty | Pattern                   |
| :------ | :--------- | :------------------------ |
| Strings | Easy       | Hashing / Frequency Count |

---

## 📌 Problem Description

Given two strings `s` and `t`, determine whether `t` is an anagram of `s`.

An anagram contains:

* The same characters
* The same frequency of each character
* Characters may appear in a different order

### Example

Input:

```text
s = "anagram"
t = "nagaram"
```

Output:

```text
true
```

---

## 🧠 Core Insight

Two strings are anagrams if every character appears the same number of times in both strings.

Since the strings contain only lowercase English letters:

```text
a → z
```

we can use a frequency array of size:

```text
26
```

instead of a hash map.

---

## ⚙️ Algorithm

### Step 1

Create a frequency array:

```cpp
vector<int> count(26, 0);
```

---

### Step 2

Traverse string `s`.

Increase frequency:

```cpp
count[c - 'a']++;
```

---

### Step 3

Traverse string `t`.

Decrease frequency:

```cpp
count[c - 'a']--;
```

---

### Step 4

Check the frequency array.

If any value is not zero:

```cpp
return false;
```

Otherwise:

```cpp
return true;
```

---

```text

```

### After Processing `s`

### After Processing `t`


Input:


After processing both strings:

```text

```

Some frequencies are non-zero.

Answer:

```text
false
```

## ⏱ Time Complexity

```text
O(n)
```

Where:

```text
n = length of string
```

We traverse both strings once.

---

## 📦 Space Complexity

```text
O(1)
```

Frequency array size is always:

```text
26
```

and does not depend on input size.

---

## ⚠️ Common Mistakes

### Mistake 1

Using:

```cpp
count.empty()
```

to check frequencies.

`empty()` only checks whether the vector contains elements.

Our vector always contains:

```text
26 elements
```

---

### Mistake 2

Forgetting:

```cpp
count[c - 'a']
```

Character must be converted into an index.

---

### Mistake 3

Using sorting first.

Sorting works:

```text
O(n log n)
```

But hashing gives:

```text
O(n)
```

---

## 🔥 Key Insight

For lowercase English letters:

```cpp
'a' - 'a' = 0
'b' - 'a' = 1
'c' - 'a' = 2
...
'z' - 'a' = 25
```

This allows us to store character frequencies directly in an array.

---

## 🎯 Interview One-Liner

Count frequencies of characters in the first string, subtract frequencies from the second string, and verify that all counts become zero.

---

## 💻 Code (C++)

```cpp
class Solution {
public:
    bool isAnagram(string s, string t) {

        vector<int> count(26, 0);

        for(char c : s) {
            count[c - 'a']++;
        }

        for(char c : t) {
            count[c - 'a']--;
        }

        for(int i : count) {
            if(i != 0) {
                return false;
            }
        }

        return true;
    }
};
```
