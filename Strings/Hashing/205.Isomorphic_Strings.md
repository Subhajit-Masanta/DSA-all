# Isomorphic Strings

| Topic   | Difficulty | Pattern                      |
| :------ | :--------- | :--------------------------- |
| Strings | Easy       | Hash Map / Character Mapping |

---

## 📌 Problem Description

Given two strings `s` and `t`, determine whether they are isomorphic.

Two strings are isomorphic if:

* Every character in `s` maps to exactly one character in `t`.
* No two different characters in `s` can map to the same character in `t`.
* The order of characters must remain unchanged.

---

## 🧠 Core Insight

This is **not a frequency problem**.

We do **not** care how many times a character appears.

Instead, we care about:

```text
Character -> Character Mapping
```

Example:

```text
egg
add
```

Mapping:

```text
e -> a
g -> d
```

Valid.

---

## ⚙️ Algorithm

Maintain two hash maps:

### Forward Mapping

```cpp
s -> t
```

### Reverse Mapping

```cpp
t -> s
```

For every index:

1. Check if `s[i]` already has a mapping.
2. If yes, verify it matches `t[i]`.
3. Check if `t[i]` already has a mapping.
4. If yes, verify it matches `s[i]`.
5. Otherwise create new mappings.

If any conflict occurs:

```cpp
return false;
```

Otherwise:

```cpp
return true;
```

## 🧪 Why One Map Is Not Enough?

Input:

```text
s = "ab"
t = "aa"
```

Using only:

```text
s -> t
```

we get:

```text
a -> a
b -> a
```

Looks valid.

But:

```text
a
b
```

cannot both map to:

```text
a
```

Therefore:

```text
false
```

We need the reverse map to detect this conflict.

---

## ⏱ Time Complexity

```text
O(n)
```

Each lookup and insertion in `unordered_map` is:

```text
O(1)
```

on average.

---

## 📦 Space Complexity

```text
O(n)
```

In the worst case, every character creates a new mapping.

---

## ⚠️ Common Mistakes

### Mistake 1

Using frequency counting.

```text
Frequency ≠ Mapping
```

This is not an anagram problem.

---

### Mistake 2

Using only one hash map.

Example:

```text
ab
aa
```

fails.

---

### Mistake 3

Checking:

```cpp
mp[key] == mp.end()
```

Wrong.

Use:

```cpp
mp.find(key) == mp.end()
```

to check whether a key exists.

---

## 🔥 Key Insight

An isomorphic relationship must be:

```text
One-to-One
```

Therefore we must validate:

```text
s -> t
```

and

```text
t -> s
```

simultaneously.

---

## 🎯 Interview One-Liner

Use two hash maps to maintain a bijection between characters of both strings.

---

## 💻 Code (C++)

```cpp
class Solution {
public:
    bool isIsomorphic(string s, string t) {

        unordered_map<char, char> mp1;
        unordered_map<char, char> mp2;

        if(s.size() != t.size()) {
            return false;
        }

        for(int i = 0; i < s.size(); i++) {

            if(mp1.find(s[i]) == mp1.end()) {
                mp1[s[i]] = t[i];
            }
            else {
                if(mp1[s[i]] != t[i]) {
                    return false;
                }
            }

            if(mp2.find(t[i]) == mp2.end()) {
                mp2[t[i]] = s[i];
            }
            else {
                if(mp2[t[i]] != s[i]) {
                    return false;
                }
            }
        }

        return true;
    }
};
```
