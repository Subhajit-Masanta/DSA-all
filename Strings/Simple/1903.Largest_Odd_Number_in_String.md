# Largest_Odd_Number_in_String

| Topic   | Difficulty | Pattern          |
| :------ | :--------- | :--------------- |
| Strings | Easy       | String Traversal |

---

## 📌 Problem Description

Given a numeric string `num`, return the largest-valued odd integer that is a non-empty substring of `num`.

If no odd integer exists, return an empty string.

### Example

Input:

```text
"52"
```

Output:

```text
"5"
```

---

## 🧠 Core Insight

A number is odd if its **last digit is odd**.

To get the **largest substring**, we should keep as many digits as possible from the beginning.

Therefore:

* Traverse from right to left.
* Find the first odd digit.
* Return the substring from index `0` to that position.

---

## ⚙️ Algorithm

1. Traverse the string from the last index.
2. Check whether the current digit is odd.
3. If odd:

   * Return `num.substr(0, i + 1)`.
4. If no odd digit is found, return `""`.

---

## 🧪 Example / Dry Run

Input:

```text
"4206358"
```

Traversal:

```text
8 -> Even
5 -> Odd
```

Return:

```text
"420635"
```

---

## ⏱ Time Complexity

```text
O(n)
```

---

## 📦 Space Complexity

```text
O(1)
```

Ignoring the returned output string.

---

## 🔥 Key Insight

The parity of a number depends only on its **last digit**.

We do not need to generate all substrings.

Just find the **rightmost odd digit**.

---

## 🎯 Interview One-Liner

Find the rightmost odd digit and return the prefix ending at that index.

---

## 💻 Code (C++)

```cpp
class Solution {
public:
    string largestOddNumber(string num) {

        for(int i = num.size() - 1; i >= 0; i--) {

            if((num[i] - '0') % 2 == 1) {
                return num.substr(0, i + 1);
            }
        }

        return "";
    }
};
```

## 📝 Character to Integer Conversion

```cpp
char ch = '7';
int num = ch - '0';
```

Result:

```cpp
num = 7;
```

### Why?

ASCII values:

```text
'0' = 48
'7' = 55
```

So:

```cpp
'7' - '0'
```

becomes:

```cpp
55 - 48 = 7
```

This is the standard way to convert a digit character into an integer in C++.
