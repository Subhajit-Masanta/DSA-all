# Longest Common Prefix

| Topic   | Difficulty | Pattern                              |
| :------ | :--------- | :----------------------------------- |
| Strings | Easy       | String Traversal (Vertical Scanning) |

---

## 📌 Problem Description

Given an array of strings `strs`, find the longest common prefix among all strings.

If there is no common prefix, return an empty string.

### Example

Input:

```text
["flower","flow","flight"]
```

Output:

```text
"fl"
```

---

## 🧠 Core Insight

Compare characters **column by column**.

Use the first string as a reference.

For each character position:

* Check whether every other string has the same character.
* If a mismatch occurs, stop immediately.
* The prefix built so far is the answer.

---

## ⚙️ Algorithm

1. Take the first string as reference.
2. Traverse each character position `i`.
3. Compare `strs[0][i]` with all other strings.
4. If:

   * a string becomes shorter, or
   * a mismatch occurs,

   return the current answer.
5. Otherwise add the character to the prefix.
6. Continue until the first string ends.

---

## 🧪 Example / Dry Run

Input:

```text
["flower","flow","flight"]
```

### Column 0

```text
f f f
```

Match ✓

Answer:

```text
f
```

### Column 1

```text
l l l
```

Match ✓

Answer:

```text
fl
```

### Column 2

```text
o o i
```

Mismatch ✗

Return:

```text
fl
```

---

## ⏱ Time Complexity

```text
O(n × m)
```

Where:

* `n` = number of strings
* `m` = length of shortest common prefix examined

---

## 📦 Space Complexity

```text
O(1)
```

Ignoring the output string.

---

## 🔥 Key Insight

Think vertically, not horizontally.

Instead of comparing whole strings, compare characters at the same index across all strings.

---

## 🎯 Interview One-Liner

Use the first string as a template and perform vertical character-by-character comparison across all strings.

---

## 💻 Code (C++)

```cpp
class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {

        if(strs.size() == 1)
            return strs[0];

        string ans = "";

        for(int i = 0; i < strs[0].size(); i++) {

            for(int j = 1; j < strs.size(); j++) {

                if(i >= strs[j].size() ||
                   strs[0][i] != strs[j][i]) {
                    return ans;
                }
            }

            ans += strs[0][i];
        }

        return ans;
    }
};
```
