# Reverse Words in a String

| Topic   | Difficulty | Pattern                         |
| :------ | :--------- | :------------------------------ |
| Strings | Medium     | Two Pointers + String Traversal |

---

## 📌 Problem Description

Given a string `s`, reverse the order of the words.

Rules:

* Words are separated by spaces.
* Ignore leading and trailing spaces.
* Multiple spaces between words should become a single space.
* Return the words in reverse order.

### Example

Input:

```text
"  hello   world  "
```

Output:

```text
"world hello"
```

---

## 🧠 Core Insight

We do **not** reverse characters.

We reverse the **order of words**.

Instead of scanning from left to right and storing all words, we can scan from **right to left** and directly build the answer.

While traversing:

1. Skip spaces.
2. Mark the end of the current word.
3. Move left until a space is found.
4. Extract the word.
5. Append it to the answer.

---

## ⚙️ Algorithm

1. Start from the last index.
2. Skip trailing spaces.
3. Store current position as `j` (end of word).
4. Move left until a space or beginning of string.
5. Extract word using:

```cpp
s.substr(i + 1, j - i)
```

6. Append word to answer.
7. Repeat until the whole string is processed.

## ⏱ Time Complexity

```text
O(n)
```

Each character is visited at most twice.

---

## 📦 Space Complexity

```text
O(n)
```

For the output string.

---

## ⚠️ Common Mistakes

### Mistake 1

Treating:

```cpp
substr(start, end)
```

as start and end indexes.

Wrong.

`substr()` takes:

```cpp
substr(start, length)
```

---

### Mistake 2

Using:

```cpp
s[j - 1]
```

without checking boundaries.

Can cause out-of-bounds access when:

```cpp
j == 0
```

---

### Mistake 3

Not skipping multiple spaces.

Input:

```text
"a   good    example"
```

should become:

```text
"example good a"
```

---

### Mistake 4

Adding an extra space at the end of the answer.

Always check:

```cpp
if (!ans.empty())
```

before appending a space.

---

## 🔥 Key Insight

While processing a word:

```cpp
i -> points to space before the word
j -> points to last character of the word
```

Therefore:

```cpp
s.substr(i + 1, j - i)
```

correctly extracts the word.

---

## 🎯 Interview One-Liner

Scan the string from right to left, extract one word at a time, and build the answer while skipping extra spaces.

---

## 💻 Code (C++)

```cpp
class Solution {
public:
    string reverseWords(string s) {
        string ans;
        int i = s.size() - 1;

        while (i >= 0) {

            while (i >= 0 && s[i] == ' ')
                i--;

            if (i < 0)
                break;

            int j = i;

            while (i >= 0 && s[i] != ' ')
                i--;

            if (!ans.empty())
                ans += ' ';

            ans += s.substr(i + 1, j - i);
        }

        return ans;
    }
};
```
