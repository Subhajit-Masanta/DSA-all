# Palindromic Substrings

| Topic   | Difficulty | Pattern              |
| :------ | :--------- | :------------------- |
| Strings | Medium     | Expand Around Center |

---

## 📌 Problem Description

Given a string `s`, return the total number of palindromic substrings.

A palindrome reads the same forward and backward.

A substring must be contiguous.

---

## 🧠 Core Insight

Every palindrome has a center.

For each index:

```cpp
expand(i, i);     // Odd length palindrome

expand(i, i + 1); // Even length palindrome
```

Every successful expansion creates one palindrome.

Instead of storing the palindrome, simply:

```cpp
count++;
```

---

## ⚙️ Algorithm

1. Traverse every index.
2. Expand around:

   * `(i,i)`
   * `(i,i+1)`
3. Every successful expansion:

   * Increment count.
4. Return total count.

---

## ⏱ Time Complexity

```text
O(n²)
```

Each center may expand up to `O(n)`.

---

## 📦 Space Complexity

```text
O(1)
```

No extra data structure is used.

---

## ⚠️ Common Mistakes

### Mistake 1

Checking only:

```cpp
expand(i,i)
```

Misses:

```text
aa
abba
```

---

### Mistake 2

Checking only:

```cpp
expand(i,i+1)
```

Misses:

```text
aba
racecar
```

---

### Mistake 3

Building substrings unnecessarily.

Only counting is required.

---

## 🔥 Key Insight

Every successful expansion:

```cpp
s[left] == s[right]
```

creates exactly one palindrome.

So:

```cpp
count++;
```

is enough.

---

## 🎯 Interview One-Liner

Treat every index as a palindrome center and count all successful expansions.

---

## 💻 Code (C++)

```cpp
class Solution {
public:

    int expand(int a, int b, string &s) {

        int left = a;
        int right = b;

        int count = 0;

        while(left >= 0 && right < s.size()) {

            if(s[left] == s[right]) {

                count++;

                left--;
                right++;
            }
            else {
                return count;
            }
        }

        return count;
    }

    int countSubstrings(string s) {

        int odd = 0;
        int even = 0;

        for(int i = 0; i < s.size(); i++) {

            odd += expand(i, i, s);
            even += expand(i, i + 1, s);
        }

        return odd + even;
    }
};
```
