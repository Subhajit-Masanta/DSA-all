# Longest Palindromic Substring

| Topic   | Difficulty | Pattern              |
| :------ | :--------- | :------------------- |
| Strings | Medium     | Expand Around Center |

---

## 📌 Problem Description

Given a string `s`, return the longest palindromic substring in `s`.

A palindrome reads the same forward and backward.

### Example 1

Input:

```text
"babad"
```

Output:

```text
"bab"
```

or

```text
"aba"
```

Both are valid answers.

### Example 2

Input:

```text
"cbbd"
```

Output:

```text
"bb"
```

---

## 🧠 Core Insight

A palindrome expands from its center.

For every index:

* Check odd-length palindrome
* Check even-length palindrome

Examples:

### Odd Length

```text
aba
 ^
```

Center is one character.

---

### Even Length

```text
abba
 ^^
```

Center is between two characters.

---

For every index:

```cpp
expand(i, i);     // odd length
expand(i, i + 1); // even length
```

Keep the longest palindrome found.

---

## ⚙️ Algorithm

1. Traverse every index `i`.
2. Expand around:

   * `(i, i)` for odd-length palindromes.
   * `(i, i+1)` for even-length palindromes.
3. Return the longest palindrome obtained.

## ⏱ Time Complexity

```text
O(n²)
```

Why?

* We have `n` possible centers.
* Each expansion may take `O(n)`.

---

## 📦 Space Complexity

```text
O(1)
```

Ignoring the returned output string.

---

## ⚠️ Common Mistakes

### Mistake 1

Checking only:

```cpp
expand(i, i)
```

This misses even-length palindromes.

Example:

```text
abba
```

---

### Mistake 2

Using:

```cpp
substr(left, right-left)
```

instead of:

```cpp
substr(left, right-left+1)
```

Remember:

```cpp
substr(start, length)
```

---

### Mistake 3

Returning inside the main loop.

```cpp
for(...)
{
    return ...
}
```

This only checks the first center.

---

### Mistake 4

Keeping only the longest length and forgetting to store the actual palindrome string.

---

## 🔥 Key Insight

Every palindrome has a center.

Instead of generating all substrings:

```text
O(n³)
```

expand outward from every possible center:

```text
O(n²)
```

---

## 🎯 Interview One-Liner

Treat every index as a palindrome center and expand outward to find the longest palindrome.

---

## 💻 Code (C++)

```cpp
class Solution {
public:

    string expand(int a, int b, string &s) {

        int left = a;
        int right = b;

        string ans = "";

        while(left >= 0 && right < s.size()) {

            if(s[left] == s[right]) {

                ans = s.substr(left, right - left + 1);

                left--;
                right++;
            }
            else {
                return ans;
            }
        }

        return ans;
    }

    string longestPalindrome(string s) {

        string ans;

        for(int i = 0; i < s.size(); i++) {

            string odd = expand(i, i, s);
            string even = expand(i, i + 1, s);

            string big;

            if(odd.size() > even.size())
                big = odd;
            else
                big = even;

            if(big.size() > ans.size())
                ans = big;
        }

        return ans;
    }
};
```
