# Valid Palindrome

| Topic   | Difficulty | Pattern                        |
| :------ | :--------- | :----------------------------- |
| Strings | Easy       | String Cleaning + Two Pointers |

---

## 📌 Problem Description

A string is considered a palindrome if, after:

* Converting all uppercase letters to lowercase
* Removing all non-alphanumeric characters

it reads the same forward and backward.

Return:

```cpp
true
```

if the string is a palindrome, otherwise:

```cpp
false
```

---

## 🧠 Core Insight

The problem tells us to ignore:

* Spaces
* Commas
* Colons
* Special characters

and treat uppercase and lowercase letters as the same.

Therefore:

1. Create a cleaned string containing only lowercase alphanumeric characters.
2. Use two pointers:

   * One from the beginning
   * One from the end
3. Compare characters until the pointers meet.

---

## ⚙️ Algorithm

### Step 1

Create a new string.

Keep only:

```cpp
isalnum(ch)
```

characters.

Convert letters to lowercase:

```cpp
tolower(ch)
```

---

### Step 2

Initialize:

```cpp
left = 0
right = cleanedString.size() - 1
```

---

### Step 3

While:

```cpp
left < right
```

Compare:

```cpp
cleaned[left]
cleaned[right]
```

* If different → return `false`
* Otherwise move both pointers

---

### Step 4

If the loop finishes, return `true`.

## 🎯 Interview One-Liner

Build a lowercase alphanumeric string and compare it from both ends using two pointers.

---

## 💻 Code (C++)

```cpp
class Solution {
public:
    bool isPalindrome(string s) {

        string r;

        for(int i = 0; i < s.size(); i++) {

            if(isalnum(s[i])) {
                r += tolower(s[i]);
            }
        }

        int left = 0;
        int right = r.size() - 1;

        while(left < right) {

            if(r[left] != r[right]) {
                return false;
            }

            left++;
            right--;
        }

        return true;
    }
};
```

```cpp

```

Example:

```cpp

isalnum('7'); // true
```

```cpp
tolower(ch)

```
