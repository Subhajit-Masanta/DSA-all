# Valid Palindrome II

| Topic   | Difficulty | Pattern      |
| :------ | :--------- | :----------- |
| Strings | Easy       | Two Pointers |

---

## 📌 Problem Description

Given a string `s`, return `true` if it can become a palindrome after deleting **at most one character**.

A palindrome reads the same forward and backward.

### Example

Input:

```text
"abca"
```

Output:

```text
true
```

Explanation:

Delete `'c'`:

```text
"aba"
```

which is a palindrome.

---

## 🧠 Core Insight

This is an extension of the classic palindrome problem.

Normally:

```text
Mismatch → Not Palindrome
```

But here:

```text
Mismatch → One deletion is allowed
```

At the first mismatch between:

```cpp
s[left]
s[right]
```

we have exactly two choices:

### Choice 1

Delete the left character.

```cpp
check(left + 1, right)
```

### Choice 2

Delete the right character.

```cpp
check(left, right - 1)
```

If either remaining substring is a palindrome, return `true`.

---

## ⚙️ Algorithm

1. Initialize two pointers:

   * `left = 0`
   * `right = n - 1`

2. While `left < right`:

   * If characters match:

     * Move both pointers.
   * Otherwise:

     * Check whether deleting the left character makes the remaining substring a palindrome.
     * Check whether deleting the right character makes the remaining substring a palindrome.
     * If either works, return `true`.

3. If the loop finishes, return `true`.

## ⏱ Time Complexity

```text
O(n)
```

### Why?

* Main traversal takes O(n)
* At first mismatch, helper function checks at most two substrings.
* Total work is still O(n).

---

## 📦 Space Complexity

```text
O(1)
```

No extra data structure is used.

---

## 🔥 Key Insight

At the first mismatch:

```cpp
s[left] != s[right]
```

Do **not** greedily delete only the left or only the right character.

Try both possibilities:

```cpp
check(left + 1, right)
```

OR

```cpp
check(left, right - 1)
```

---

## 🎯 Interview One-Liner

Use two pointers and, upon the first mismatch, verify whether either substring obtained by deleting one character forms a palindrome.

---

## 💻 Code (C++)

```cpp
class Solution {
public:

    bool check(int left, int right, string s) {

        while(left <= right) {

            if(s[left] == s[right]) {
                left++;
                right--;
            }
            else {
                return false;
            }
        }

        return true;
    }

    bool validPalindrome(string s) {

        int left = 0;
        int right = s.size() - 1;

        while(left <= right) {

            if(s[left] == s[right]) {
                left++;
                right--;
            }
            else {

                return check(left + 1, right, s) ||
                       check(left, right - 1, s);
            }
        }

        return true;
    }
};
```

## ⚠️ Common Mistakes

### Mistake 1

Greedily deleting only one side:

```cpp
left++;
```

or

```cpp
right--;
```

This fails because you don't know which character should be removed.

---

### Mistake 2

Using:

```cpp
check(left, right + 1)
```

instead of:

```cpp
check(left, right - 1)
```

When deleting the right character.

---

### Mistake 3

Thinking the problem requires DP or recursion.

A simple Two Pointer approach is enough.

---

## 📚 Pattern Recognition

If a problem contains:

```text
Palindrome
Compare from both ends
Delete one character
```

Think:

```text
Two Pointers + Branch at First Mismatch
```
