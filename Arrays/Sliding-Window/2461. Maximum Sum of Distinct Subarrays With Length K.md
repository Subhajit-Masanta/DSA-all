# 📌 Problem

Given:

- An array `nums`
- An integer `k`

Find the **maximum sum** of any subarray such that:

- Window size is exactly `k`
- All elements inside the window are **distinct**

If no such window exists, return `0`. :contentReference[oaicite:0]{index=0}

# 🧠 Intuition

Maintain a window of exactly `k` elements.

For every window:

- Keep its sum.
- Keep the frequency of every number.
- If every element appears exactly once,

```cpp
mp.size() == k
```

then every element is distinct.

Update the answer.

---

# 🪜 Algorithm

### Step 1

Create

```cpp
unordered_map<int,int> mp;
```

to store frequencies.

---

### Step 2

Maintain

```cpp
long long sum
```

for the current window.

---

### Step 3

Expand the window.

```cpp
sum += nums[right];
mp[nums[right]]++;
```

---

### Step 4

If window becomes larger than `k`

Remove the left element.

```cpp
sum -= nums[left];

mp[nums[left]]--;

if(mp[nums[left]]==0)
    mp.erase(nums[left]);

left++;
```

---

### Step 5

If

```text
Window Size == k

AND

mp.size()==k
```

↓

All elements are distinct.

Update answer.

# Code

```cpp
class Solution {
public:
    long long maximumSubarraySum(vector<int>& nums, int k) {

        long long ans = 0;
        long long sum = 0;

        int left = 0;

        unordered_map<int,int> mp;

        for(int right = 0; right < nums.size(); right++) {

            sum += nums[right];
            mp[nums[right]]++;

            int window = right - left + 1;

            if(window > k) {

                sum -= nums[left];

                mp[nums[left]]--;

                if(mp[nums[left]] == 0)
                    mp.erase(nums[left]);

                left++;
            }

            if(right - left + 1 == k && mp.size() == k) {
                ans = max(ans, sum);
            }
        }

        return ans;
    }
};
```
