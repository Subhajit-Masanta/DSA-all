# 73. Set Matrix Zeroes

> 🔎 Pattern: Matrix Marking Technique  
> 📂 Topic: Arrays / Matrix  
> 🏷️ Difficulty: Medium  

---

## 📌 Problem
If an element in an `m x n` matrix is 0, set its entire row and column to 0.

Must be done **in-place** with constant extra space.

---

# 🟡 Approach 1 — O(m + n) Space

## 💡 Idea

Use two arrays:
- `row[m]`
- `col[n]`

Mark which rows and columns should be zero.

---

## ⚙️ Algorithm

1. Traverse matrix.
2. If `matrix[i][j] == 0`:
   - `row[i] = 1`
   - `col[j] = 1`
3. Traverse again:
   - If `row[i] == 1` OR `col[j] == 1`
     → set `matrix[i][j] = 0`

---

## ⏱ Time Complexity
O(mn)

## 📦 Space Complexity
O(m + n)

---

# 🔴 Approach 2 — O(1) Space (Optimal)

## 💡 Key Idea

Use:
- First row as column marker
- First column as row marker

But we must preserve whether first row or column originally had zero.

So we use two flags:
- `firstRowZero`
- `firstColZero`
