# 73. Set Matrix Zeroes

> 🔎 Pattern: Matrix Marking Technique  
> 📂 Topic: Arrays / Matrix  
> 🏷️ Difficulty: Medium  

---

## 📌 Problem
If an element in an `m x n` matrix is 0, set its entire row and column to 0.

Must be done **in-place** with constant extra space.

---

# 🟡 Approach 1 — O(m + n) Space

## 💡 Idea

Use two arrays:
- `row[m]`
- `col[n]`

Mark which rows and columns should be zero.

---

## ⚙️ Algorithm

1. Traverse matrix.
2. If `matrix[i][j] == 0`:
   - `row[i] = 1`
   - `col[j] = 1`
3. Traverse again:
   - If `row[i] == 1` OR `col[j] == 1`
     → set `matrix[i][j] = 0`

---

## ⏱ Time Complexity
O(mn)

## 📦 Space Complexity
O(m + n)

---

# 🔴 Approach 2 — O(1) Space (Optimal)

## 💡 Key Idea

Use:
- First row as column marker
- First column as row marker

But we must preserve whether first row or column originally had zero.

So we use two flags:
- `firstRowZero`
- `firstColZero`

---

## ⚙️ Algorithm

### Step 1: Check first row
If any zero → `firstRowZero = true`

### Step 2: Check first column
If any zero → `firstColZero = true`

### Step 3: Mark rest of matrix
For `i = 1 to m-1`
For `j = 1 to n-1`
If `matrix[i][j] == 0`:



---

## ⏱️ Time Complexity
O(m × n)

## 📦 Space Complexity
O(1)

Only two boolean variables used.

---

## ⚠️ Common Mistakes

- Forgetting `firstRowZero` flag
- Forgetting `firstColZero` flag
- Starting marking from index 0
- Overwriting markers too early
- Updating first row before finishing inner matrix

---

## 🎯 Interview One-Liner
Use first row and first column as marker arrays to achieve constant space.

---

## 💻 Code (O(1) Space)

```cpp
class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {

        int n = matrix.size();
        int m = matrix[0].size();

        bool firstRowZero = false;
        bool firstColZero = false;

        // Step 1: Check first row
        for (int j = 0; j < m; j++) {
            if (matrix[0][j] == 0) {
                firstRowZero = true;
                break;
            }
        }

        // Step 2: Check first column
        for (int i = 0; i < n; i++) {
            if (matrix[i][0] == 0) {
                firstColZero = true;
                break;
            }
        }

        // Step 3: Use first row and column as markers
        for (int i = 1; i < n; i++) {
            for (int j = 1; j < m; j++) {
                if (matrix[i][j] == 0) {
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }
            }
        }

        // Step 4: Apply markers
        for (int i = 1; i < n; i++) {
            for (int j = 1; j < m; j++) {
                if (matrix[i][0] == 0 || matrix[0][j] == 0) {
                    matrix[i][j] = 0;
                }
            }
        }

        // Step 5: Update first row
        if (firstRowZero) {
            for (int j = 0; j < m; j++) {
                matrix[0][j] = 0;
            }
        }

        // Step 6: Update first column
        if (firstColZero) {
            for (int i = 0; i < n; i++) {
                matrix[i][0] = 0;
            }
        }
    }
};
