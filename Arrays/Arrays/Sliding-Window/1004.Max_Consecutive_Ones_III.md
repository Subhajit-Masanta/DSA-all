# 1004. Max Consecutive Ones III

## 📌 Problem Description
Given a binary array `nums` and an integer `k`, return the maximum number of consecutive `1`s in the array if you can flip at most `k` `0`s.

---

## 🧠 Core Concept: The `if` vs `while` Debate

There are **two valid ways** to solve this using a sliding window. You need to understand both.

### Approach 1: The Standard Shrinkable Window (Uses `while`)
This is the intuitive approach. 
If your window becomes invalid (i.e., you have more than `k` zeros), you **shrink** the window from the left until it is valid again.

* **Logic:** `while (zeros > k) { shrink left }`
* **Window Size:** Fluctuates. It expands and shrinks. The size of the window at any point exactly represents a *valid* subarray.

### Approach 2: The Monotonic Window (Uses `if` - Your Code)
This is a highly optimized, but less intuitive approach.
Instead of shrinking the window when it becomes invalid, you just **shift the entire window** to the right.

* **Logic:** `if (zeros > k) { move left once }`
* **Window Size:** NEVER shrinks. It either grows (when valid) or shifts to the right maintaining its maximum size (when invalid).
* **Why it works:** We only care about the **maximum** length. If we already found a valid window of size 5, we don't care about valid windows of size 3 or 4. We only care if we can find a window of size 6. So, we keep the window at size 5 and slide it until it becomes valid again, at which point it can grow to 6.

---

## ⚙️ The Algorithm (Your Optimized `if` Version)

1.  Expand window by moving `right`.
2.  If `nums[right]` is `0`, increment your `count`.
3.  **The Catch:** If `count > k`, your window is invalid. Instead of a `while` loop, use an `if` statement to increment `left` exactly once. 
4.  Because `right` moved by 1 and `left` moved by 1, the window size stays exactly the same.
5.  Keep updating `maxlength`.

---

## 💻 Implementation: The Standard Way (Using `while`)
*Memorize this underlying logic first before using the optimized version.*

```cpp
class Solution {
public:
    int longestOnes(vector<int>& nums, int k) {
        int left = 0, count = 0, maxlength = 0;
        
        for (int right = 0; right < nums.size(); right++) {
            if (nums[right] == 0) {
                count++;
            }
            
            // Shrink window until valid
            while (count > k) {
                if (nums[left] == 0) {
                    count--;
                }
                left++;
            }
            
            maxlength = max(maxlength, right - left + 1);
        }
        return maxlength;
    }
};
