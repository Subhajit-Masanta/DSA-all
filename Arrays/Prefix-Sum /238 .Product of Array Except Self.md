# Product of Array Except Self (LeetCode 238)

| Topic | Difficulty | Pattern |
|--------|------------|---------|
| Array | Medium | Prefix Product + Suffix Product |

---

# 📌 Problem

Given an integer array `nums`, return an array such that

```text
answer[i] = product of all elements except nums[i]
```

Constraints:

- No division
- O(n) time

---

# 🧠 Pattern Recognition

If every index needs

```text
Everything BEFORE me

+

Everything AFTER me
```

Think

```text
Prefix + Suffix
```

---

# 💡 Core Idea

For every index

```text
Answer[i]

=

Left Product × Right Product
```

Example

```text
nums = [1,2,3,4]
```

For index 2

```text
Left Product

1×2 = 2

Right Product

4

Answer

2×4 = 8
```

---

# Approach 1 (O(n) Extra Space)

## Idea

Create

```text
left[]

right[]
```

Then

```text
answer[i] = left[i] × right[i]
```

---

## Example

```text
nums

[1,2,3,4]
```

Left

```text
[1,1,2,6]
```

Right

```text
[24,12,4,1]
```

Answer

```text
24
12
8
6
```

---

## Algorithm

```text
Build Left[]

↓

Build Right[]

↓

Multiply both arrays
```

---

## Code

```cpp
class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {

        int n = nums.size();

        vector<int> left(n), right(n), ans(n);

        left[0] = 1;
        for(int i = 1; i < n; i++) {
            left[i] = left[i - 1] * nums[i - 1];
        }

        right[n - 1] = 1;
        for(int i = n - 2; i >= 0; i--) {
            right[i] = right[i + 1] * nums[i + 1];
        }

        for(int i = 0; i < n; i++) {
            ans[i] = left[i] * right[i];
        }

        return ans;
    }
};
```

### Complexity

Time

```text
O(n)
```

Space

```text
O(n)
```

# Approach 2 (Optimal O(1) Extra Space)

## Observation

We actually don't need

```text
right[]
```

Store the left products directly inside

```text
answer[]
```

Then traverse from right to left using

```text
rightProduct
```

---

## Algorithm

```text
Pass 1

answer[i]

=

Left Product

↓

Pass 2

Traverse Right

Maintain

rightProduct

↓

answer[i] *= rightProduct

↓

Update rightProduct
```

## Code

```cpp
class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {

        int n = nums.size();

        vector<int> ans(n);

        ans[0] = 1;

        for(int i = 1; i < n; i++) {
            ans[i] = ans[i - 1] * nums[i - 1];
        }

        int rightProduct = 1;

        for(int i = n - 1; i >= 0; i--) {
            ans[i] *= rightProduct;
            rightProduct *= nums[i];
        }

        return ans;
    }
};
```

### Complexity

Time

```text
O(n)
```

Extra Space

```text
O(1)
```

# ⭐ Key Takeaways

- No division required.
- Prefix gives product before current index.
- Suffix gives product after current index.
- O(n) approach uses `left[]` and `right[]`.
- Optimal approach stores left products in `answer[]` and uses a single `rightProduct` variable. :contentReference[oaicite:1]{index=1}
