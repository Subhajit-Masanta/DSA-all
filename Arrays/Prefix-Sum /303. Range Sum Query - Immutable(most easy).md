# 303. Range Sum Query - Immutable

| Topic | Difficulty | Pattern |
|--------|------------|---------|
| Prefix Sum | Easy | Prefix Sum |

---

# 📌 Problem

Given an immutable array `nums`, answer multiple queries:

```text
sumRange(left, right)
```

Return the sum of elements from index `left` to `right` (inclusive).

---

# 💡 Intuition

Suppose the array is:

```text
Index : 0  1  2  3  4
Array : 2  4  1  3  6
```

Instead of adding every time,

```text
2 + 4 + 1
```

store the cumulative sums once.

```text
Prefix:

2
6
7
10
16
```

Now every query becomes subtraction.

---

# 🧠 Pattern Recognition

Whenever you see:

- Multiple range sum queries
- Immutable array
- No updates

Think:

```text
Prefix Sum
```

---

# 🔍 Prefix Sum Meaning

```text
prefix[i]
```

stores

```text
Sum from index 0 to i
```

Example:

```text
Array

2 4 1 3 6

Prefix

2
6
7
10
16
```

Meaning

```text
prefix[3] = 10

↓

2 + 4 + 1 + 3
```

---

# ⚡ Query Formula

If

```text
left == 0
```

Answer is simply

```text
prefix[right]
```

Otherwise

```text
prefix[right] - prefix[left-1]
```

Why?

```text
prefix[right]

contains

0 → right

Remove

0 → left-1

Only

left → right

remains.
```

---

# 📝 Example

```text
Array

2 4 1 3 6

Prefix

2
6
7
10
16
```

Find

```text
sum(1,3)
```

Using prefix

```text
10 - 2 = 8
```

Actual

```text
4 + 1 + 3 = 8
```

---

# 🚀 Optimized Version

Instead of

```text
prefix

2
6
7
10
16
```

Store one extra zero.

```text
0
2
6
7
10
16
```

Now

```text
prefix[i]
```

means

```text
Sum of first i elements.
```

Formula becomes

```text
prefix[right+1] - prefix[left]
```

No special case for

```text
left == 0
```

This is the most common interview implementation. :contentReference[oaicite:0]{index=0}

# 📌 C++ (Your Solution)

```cpp
class NumArray {
public:
    vector<int> prefix;

    NumArray(vector<int>& nums) {
        int sum = 0;

        for(int i = 0; i < nums.size(); i++) {
            sum += nums[i];
            prefix.push_back(sum);
        }
    }

    int sumRange(int left, int right) {

        if(left == 0)
            return prefix[right];

        return prefix[right] - prefix[left - 1];
    }
};
```
