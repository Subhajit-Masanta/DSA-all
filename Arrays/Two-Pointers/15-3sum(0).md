# 15. 3Sum

> 🔎 Pattern: Sorting + Two Pointers  
> 📂 Topic: Arrays  
> 🏷️ Difficulty: Medium  

---

## 📌 Problem
Find all unique triplets in the array which give the sum of zero.

---

## 💡 Key Idea

1. Sort the array.
2. Fix one element.
3. Use two pointers to find remaining two.
4. Skip duplicates carefully.

---

## 🧠 Why Skip Duplicates ONLY After Finding a Triplet?

Because skipping early may remove valid combinations.

Duplicate handling rules:
- Skip duplicate `nums[i]`
- After finding valid triplet, skip duplicate `left`
- After finding valid triplet, skip duplicate `right`

---

## ⚙️ Algorithm

1. Sort array.
2. Loop `i` from 0 to n-3:
   - Skip duplicate `nums[i]`
   - left = i+1, right = n-1
   - While left < right:
     - Compute sum
     - If sum == 0:
         - Add triplet
         - Skip duplicate left & right
     - If sum < 0 → left++
     - If sum > 0 → right--

---

## 🧪 Dry Run

Input: `[-1,0,1,2,-1,-4]`

Sorted: `[-4,-1,-1,0,1,2]`

Triplets:
- [-1,-1,2]
- [-1,0,1]

---

## ⏱️ Time Complexity
O(n²)

## 📦 Space Complexity
O(1) (excluding output)

---

## ⚠️ Common Mistakes

- Skipping duplicates before sum == 0.
- Thinking duplicates must exist on both left and right.
- Using continue incorrectly inside while loop.
- Not sorting before applying two pointers.

---

## 🎯 Interview One-Liner
Sort the array, fix one element, and use two pointers while skipping duplicates.

---

## 💻 Code

```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        vector<vector<int>> ans;

        for (int i = 0; i < nums.size() - 2; i++) {

            if (i > 0 && nums[i] == nums[i - 1]) continue;

            int left = i + 1;
            int right = nums.size() - 1;

            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];

                if (sum == 0) {
                    ans.push_back({nums[i], nums[left], nums[right]});

                    while (left < right && nums[left] == nums[left + 1]) left++;
                    while (left < right && nums[right] == nums[right - 1]) right--;

                    left++;
                    right--;
                }
                else if (sum < 0) {
                    left++;
                }
                else {
                    right--;
                }
            }
        }
        return ans;
    }
};
