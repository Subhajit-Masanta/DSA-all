# 124. Binary Tree Maximum Path Sum

| Topic | Difficulty | Pattern |
|--------|------------|---------|
| Tree | Hard | Bottom-Up DFS / Tree DP |

---

## 📌 Problem Description

Given the `root` of a binary tree, return the **maximum path sum**.

A path is any sequence of nodes connected by edges.

Rules:

- A path **does not need to pass through the root**.
- A path **must contain at least one node**.
- A path **cannot visit the same node twice**.

---

## 🧠 Intuition

Unlike Maximum Depth, here a path can:

- Start anywhere.
- End anywhere.
- Pass through a node using **both** left and right children.

At every node, we have **two different jobs**.

---

## 🎯 Pattern Recognition

Keywords:

- Maximum Path
- Maximum Sum
- Any Node to Any Node
- Tree DP
- Bottom-Up DFS

Whenever you hear:

> Maximum path involving subtrees

Think:

> **Bottom-Up DFS**

because the parent needs information from both children.

---

## ⚙️ Approach

For every node:

### Job 1

Compute the maximum path **passing through the current node**.

```text
left + root + right
```

Update the global answer.

---

### Job 2

Return the maximum contribution to the parent.

A parent can continue through **only one child**.

Return

```text
root + max(left, right)
```

---

Ignore negative paths because they only decrease the answer.

```cpp
left = max(0, left);
right = max(0, right);
```

Tree

```text
        -10
       /   \
      9     20
           /  \
         15    7
```

### Node 15

```text
left = 0
right = 0

ans = 15

return 15
```

---

### Node 7

```text
left = 0
right = 0

ans = 15

return 7
```

---

### Node 20

```text
left = 15
right = 7

Current Path

15 + 20 + 7 = 42

ans = 42

Return

20 + max(15,7)

=35
```

---

### Node -10

```text
left = 9

right = 35

Current Path

9 + (-10) + 35 = 34

ans remains 42

Return

-10 + 35 = 25
```

Final Answer

```text
42
```

## 🌳 Why Return Only One Branch?

Suppose

```text
      10
     /
    5
   / \
  2   3
```

Node 5 can make

```text
2 -> 5 -> 3
```

But parent 10 cannot continue through **both** branches.

It must choose

```text
10 -> 5 -> 3
```

or

```text
10 -> 5 -> 2
```

Hence we return

```cpp
root->val + max(left, right)
```

---

## ⚠️ Common Mistakes

### 1. Returning

```cpp
left + right + root->val
```

Wrong.

The parent cannot continue through two branches.

Return only one branch.

---

### 2. Forgetting to Ignore Negative Paths

Wrong

```cpp
return root->val + max(left,right);
```

without

```cpp
left=max(0,left);
right=max(0,right);
```

Negative branches reduce the answer.

---

### 3. Initializing

```cpp
int ans = 0;
```

Wrong.

Tree may contain only negative values.

Correct

```cpp
int ans = INT_MIN;
```

---

### 4. Thinking Path Must Start at Root

No.

The maximum path can be completely inside any subtree.

---

## 🎯 Key Takeaways

- Bottom-Up DFS.
- Every node performs **two jobs**.
- Update global answer using both branches.
- Return only one branch to parent.
- Ignore negative contributions.
- Initialize answer with `INT_MIN`.

---

## 💻 Implementation (C++)

```cpp
class Solution {
public:

    int solve(TreeNode* root, int &ans)
    {
        if(root == nullptr)
            return 0;

        int left = solve(root->left, ans);
        int right = solve(root->right, ans);

        // Ignore negative paths
        left = max(0, left);
        right = max(0, right);

        // Job 1: Update global answer
        ans = max(ans, left + right + root->val);

        // Job 2: Return best single branch
        return root->val + max(left, right);
    }

    int maxPathSum(TreeNode* root)
    {
        int ans = INT_MIN;

        solve(root, ans);

        return ans;
    }
};
```

## ⏱️ Complexity Analysis

| Complexity | Value |
|------------|-------|
| Time | **O(n)** |
| Space | **O(h)** |

Where:

- **n** = Number of nodes.
- **h** = Height of the tree (recursion stack).

Balanced Tree

```text
Space = O(log n)
```
