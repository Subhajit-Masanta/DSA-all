# 110. Balanced Binary Tree

| Topic | Difficulty | Pattern                   |
| ----- | ---------- | ------------------------- |
| Tree  | Easy       | DFS / Bottom-Up Recursion |

---

## 📌 Problem Description

Given the root of a binary tree, determine whether it is **height-balanced**.

A binary tree is balanced if, for **every node**, the height difference between its left and right subtree is at most **1**.

---

## 🧠 Intuition

This problem is an extension of **104. Maximum Depth**.

For every node we need:

* Height of left subtree
* Height of right subtree
* Check if:

```text
|Left Height - Right Height| ≤ 1
```

There are two approaches.

### Brute Force

* Compute left height.
* Compute right height.
* Check balance.
* Recursively repeat for left and right subtree.

The same subtree heights are calculated many times.

---

### Optimized

Use a single DFS.

The helper function returns:

* Height → if subtree is balanced.
* `-1` → if subtree is not balanced.

This avoids recomputing heights.

---

## 🎯 Pattern Recognition

Keywords:

---

## ⚙️ Approach

### Brute Force

1. Compute left height.
2. Compute right height.
3. If difference > 1 → return false.
4. Recursively check left subtree.
5. Recursively check right subtree.

---

### Optimized

For every node:

* Calculate left height.
* Calculate right height.
* If either returns `-1`, return `-1`.
* If difference > 1, return `-1`.
* Otherwise return:

```cpp
1 + max(left, right)
```

## 🧪 Dry Run

Tree

```text
        3
      /   \
     9     20
          /  \
         15   7
```

Leaf Nodes

```text
9  → 1

15 → 1

7  → 1
```

Node 20

```text
Left = 1

Right = 1

↓

Return 2
```

Root

```text
Left = 1

Right = 2

Difference = 1

↓

Return 3
```

Since the helper never returns `-1`, the tree is balanced.

---

## ⚠️ Common Mistakes

### 1. Checking Only the Root

Every node must satisfy the balance condition.

---

### 2. Forgetting to Check Child Subtrees

Even if the current node is balanced, a child subtree may not be.

---

### 3. Brute Force Recomputes Heights

Calling `height()` repeatedly increases complexity.

---

### 4. Forgetting the `-1` Propagation

If either subtree returns `-1`, immediately return `-1`.

---

## 🎯 Key Takeaways

* Builds directly on Maximum Depth.
* Brute Force uses two recursive functions.
* Optimal solution combines height calculation and balance checking.
* `-1` represents an unbalanced subtree.
* Bottom-up DFS visits every node only once.

---

## 💻 Brute Force (O(n²))

```cpp
class Solution {
public:

    int height(TreeNode* root){

        if(root == nullptr)
            return 0;

        int left = height(root->left);
        int right = height(root->right);

        return 1 + max(left, right);
    }

    bool isBalanced(TreeNode* root){

        if(root == nullptr)
            return true;

        int leftHeight = height(root->left);
        int rightHeight = height(root->right);

        if(abs(leftHeight-rightHeight) > 1)
            return false;

        return isBalanced(root->left) &&
               isBalanced(root->right);
    }
};
```

---

## 💻 Optimized (O(n))

```cpp
class Solution {
public:

    int height(TreeNode* root){

        if(root == nullptr)
            return 0;

        int left = height(root->left);
        int right = height(root->right);

        if(left == -1 || right == -1)
            return -1;

        if(abs(left-right) > 1)
            return -1;

        return 1 + max(left, right);
    }

    bool isBalanced(TreeNode* root){

        return height(root) != -1;
    }
};
```
