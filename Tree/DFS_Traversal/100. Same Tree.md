# 100. Same Tree

| Topic | Difficulty | Pattern                    |
| ----- | ---------- | -------------------------- |
| Tree  | Easy       | DFS / Recursive Comparison |

---

## 📌 Problem Description

Given the roots of two binary trees `p` and `q`, determine whether they are **identical**.

Two binary trees are considered the same if:

* They have the **same structure**.
* The corresponding nodes have the **same values**.

---

## 🧠 Intuition

Unlike previous tree problems where we traverse **one tree**, here we traverse **two trees simultaneously**.

At every recursive call, compare:

* Current nodes
* Left subtrees
* Right subtrees

The trees are the same only if **every comparison succeeds**.

---

## 🎯 Pattern Recognition

Keywords:

* DFS
* Two Tree Recursion
* Tree Comparison
* Recursive Verification

---

## ⚙️ Approach

At every recursive call:

1. If both nodes are `NULL` → return `true`.
2. If one node is `NULL` and the other isn't → return `false`.
3. If node values differ → return `false`.
4. Recursively compare:

   * Left subtree
   * Right subtree
5. Return:

```cpp
left && right
```

Both subtrees must be identical.

---

## 🧪 Dry Run

Tree P

```text
        1
      /   \
     2     3
```

Tree Q

```text
        1
      /   \
     2     3
```

Comparison:

```text
1 == 1 ✓

↓

2 == 2 ✓

↓

NULL == NULL ✓

↓

NULL == NULL ✓

↓

3 == 3 ✓

↓

NULL == NULL ✓

↓

NULL == NULL ✓
```

Final:

```text
true && true

↓

true
```

Answer:

```text
true
```

---

## ⚠️ Common Mistakes

### 1. Comparing Only Values

Nodes must have:

* Same value ✅
* Same position (structure) ✅

---

### 2. Forgetting the NULL Cases

Always handle:

```cpp
Both NULL → true

One NULL → false
```

before accessing `val`.

---

### 3. Using `||` Instead of `&&`

Wrong:

```cpp
left || right
```

Correct:

```cpp
left && right
```

Both left and right subtrees must match.

---

## 🎯 Key Takeaways

* Traverse **both trees together**.
* Compare structure before values.
* Both left and right subtree comparisons must return `true`.
* First problem introducing the **Two-Tree DFS** pattern.
* This pattern is reused in **Symmetric Tree**.

---

## 💻 Implementation (C++)

```cpp
class Solution {
public:

    bool solve(TreeNode* p, TreeNode* q){

        if(p == nullptr && q == nullptr)
            return true;

        if(p == nullptr || q == nullptr)
            return false;

        if(p->val != q->val)
            return false;

        bool left = solve(p->left, q->left);
        bool right = solve(p->right, q->right);

        return left && right;
    }

    bool isSameTree(TreeNode* p, TreeNode* q) {

        return solve(p, q);
    }
};
```

## ⏱️ Complexity Analysis

| Complexity | Value    |
| ---------- | -------- |
| Time       | **O(n)** |
| Space      | **O(h)** |

Where:

* **n** = Number of nodes (in the worst case, every corresponding node is visited once).
* **h** = Height of the tree (recursion stack).
