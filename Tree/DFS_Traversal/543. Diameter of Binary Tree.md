# 543. Diameter of Binary Tree

| Topic | Difficulty | Pattern                        |
| ----- | ---------- | ------------------------------ |
| Tree  | Easy       | DFS / Height + Global Variable |

---

## 📌 Problem Description

Given the root of a binary tree, return the **diameter** of the tree.

The **diameter** is the **longest path between any two nodes** in the tree.

> **Note:** The answer is measured in **edges**, not nodes.

The longest path **may or may not pass through the root**.

---

## 🧠 Intuition

This problem is a direct extension of **104. Maximum Depth**.

In Maximum Depth, we returned:

```cpp
height = 1 + max(leftHeight, rightHeight);
```

Here, at every node we ask:

> **What is the longest path passing through this node?**

That path is:

```text
Deepest Node (Left)

↓

Current Node

↓

Deepest Node (Right)
```

So,

```text
Diameter Through Current Node

=

Left Height + Right Height
```

While recursion returns the **height**, we continuously update the **maximum diameter** found so far.

---

## 🎯 Pattern Recognition

Keywords:

* DFS
* Height Calculation
* Bottom-Up Recursion
* Global Variable
* Tree DP

---

## ⚙️ Approach

For every node:

1. Recursively calculate left height.
2. Recursively calculate right height.
3. Update

```cpp
dia = max(dia, left + right);
```

4. Return current height:

```cpp
1 + max(left, right)
```

The recursion returns **height**, while the global variable stores the **best diameter**.


```text

```

## ⚠️ Common Mistakes

### 1. Returning Diameter Instead of Height

The recursive function should return:

```cpp
Height
```

not diameter.

---

### 2. Forgetting the Global Variable

Diameter is updated at **every node**, not only at the root.

---

### 3. Counting Nodes Instead of Edges

Diameter is measured using **edges**.

Using

```cpp
left + right
```

automatically gives the number of edges.

---

## 🎯 Key Takeaways

* Builds directly on **Maximum Depth**.
* Recursion returns **height**.
* Global variable stores **maximum diameter**.
* Longest path may **not** pass through the root.
* First problem using the pattern:

  * **Return one value**
  * **Update another value**

## 💻 Implementation (C++)

```cpp
class Solution {
public:

    int solve(TreeNode* root, int &dia){

        if(root == nullptr)
            return 0;

        int left = solve(root->left, dia);
        int right = solve(root->right, dia);

        dia = max(dia, left + right);

        return 1 + max(left, right);
    }

    int diameterOfBinaryTree(TreeNode* root) {

        int dia = 0;

        solve(root, dia);

        return dia;
    }
};
```
