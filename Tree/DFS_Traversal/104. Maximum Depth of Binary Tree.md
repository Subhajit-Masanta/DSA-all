# 104. Maximum Depth of Binary Tree

| Topic | Difficulty | Pattern                       |
| ----- | ---------- | ----------------------------- |
| Tree  | Easy       | DFS (Recursion) / BFS (Queue) |

---

## 📌 Problem Description

Given the root of a binary tree, return its **maximum depth**.

The maximum depth is the **number of nodes** along the longest path from the root node to the farthest leaf node.

---

## 🧠 Intuition

There are **two standard approaches**.

### 1. DFS (Recursive) ⭐ Preferred

Every node asks:

* What is the maximum depth of my left subtree?
* What is the maximum depth of my right subtree?

Take the larger one and add **1** for the current node.

Recursive Formula:

```text
Depth(Current)

= 1 + max(Depth(Left), Depth(Right))
```

---

### 2. BFS (Level Order)

Process the tree **level by level** using a queue.

Every time one complete level is processed,

```cpp
depth++;
```

When the queue becomes empty,

`depth` is the maximum depth of the tree.

---

## 🎯 Pattern Recognition

Keywords:

* Binary Tree
* Maximum Depth / Height
* DFS Recursion
* BFS Level Order
* Height of Tree

---

## ⚙️ Approach

### DFS

* If node is `NULL`, return `0`.
* Recursively calculate left subtree depth.
* Recursively calculate right subtree depth.
* Return:

```cpp
1 + max(leftDepth, rightDepth)
```

---

### BFS

* Push root into queue.
* While queue is not empty:

  * Process one complete level.
  * Increment depth.
* Return depth.

---

## 🧪 Dry Run

Tree:

```text
        3
      /   \
     9     20
          /  \
         15   7
```

### DFS

```text
15 → returns 1

7 → returns 1

20 → 1 + max(1,1) = 2

9 → returns 1

3 → 1 + max(1,2) = 3
```

Answer:

```text
3
```

---

## ⚠️ Common Mistakes

### 1. Returning 1 for NULL

Wrong:

```cpp
if(root == nullptr)
    return 1;
```

Correct:

```cpp
if(root == nullptr)
    return 0;
```

---

### 2. Forgetting to Add Current Node

Always return:

```cpp
1 + max(left,right)
```

---

### 3. Using Global Variables Unnecessarily

This problem is naturally solved using the recursive return value.

---

### 4. In BFS, Incrementing Depth for Every Node

Increase depth only **after one complete level is processed**, not after every node.

---

## 🎯 Key Takeaways

* DFS computes depth **bottom-up**.
* BFS computes depth **level-by-level**.
* DFS is the most common interview solution.
* Both solutions visit every node exactly once.

---

## 💻 DFS Implementation (C++)

```cpp
class Solution {
public:

    int solve(TreeNode* root){

        if(root == nullptr)
            return 0;

        int left = solve(root->left);
        int right = solve(root->right);

        return 1 + max(left, right);
    }

    int maxDepth(TreeNode* root) {

        return solve(root);
    }
};
```

---

## 💻 BFS Implementation (C++)

```cpp
class Solution {
public:

    int maxDepth(TreeNode* root) {

        if(root == nullptr)
            return 0;

        queue<TreeNode*> q;
        q.push(root);

        int depth = 0;

        while(!q.empty()){

            int size = q.size();

            while(size--){

                TreeNode* node = q.front();
                q.pop();

                if(node->left)
                    q.push(node->left);

                if(node->right)
                    q.push(node->right);
            }

            depth++;
        }

        return depth;
    }
};
```

## ⏱️ Complexity Analysis

### DFS

| Complexity | Value    |
| ---------- | -------- |
| Time       | **O(n)** |
| Space      | **O(h)** |

---

### BFS

| Complexity | Value    |
| ---------- | -------- |
| Time       | **O(n)** |
| Space      | **O(n)** |

Where:

* **n** = Number of Nodes
* **h** = Height of the Tree
