# 101. Symmetric Tree

| Topic | Difficulty | Pattern                |
| ----- | ---------- | ---------------------- |
| Tree  | Easy       | DFS / Mirror Recursion |

---

## 📌 Problem Description

Given the root of a binary tree, determine whether it is **symmetric** around its center.

A binary tree is symmetric if its **left subtree is the mirror image of its right subtree.**

---

## 🧠 Intuition

This problem is almost identical to **100. Same Tree**.

The only difference is:

**Same Tree**

```text
Left  ↔ Left

Right ↔ Right
```

**Symmetric Tree**

```text
Left  ↔ Right

Right ↔ Left
```

Think of cutting the tree into two halves.

```text
        1
      /   \
     2     2
```

Treat them as two separate trees and check whether they are **mirror images**.

---

## 🎯 Pattern Recognition

Keywords:

* DFS
* Mirror Tree
* Two-Tree Recursion
* Recursive Comparison

---

## ⚙️ Approach

Create a helper function:

```cpp
solve(left, right)
```

At every recursive call:

1. If both nodes are `NULL` → return `true`.
2. If one node is `NULL` → return `false`.
3. If values differ → return `false`.
4. Recursively compare:

   * `left->left` with `right->right`
   * `left->right` with `right->left`
5. Return:

```cpp
outer && inner
```

Both mirror comparisons must be true.

---

## 🧪 Dry Run

Tree

```text
        1
      /   \
     2     2
    / \   / \
   3   4 4   3
```

Start:

```text
solve(2,2)
```

Compare:

```text
2 == 2 ✓
```

Outer:

```text
solve(3,3)

↓

true
```

Inner:

```text
solve(4,4)

↓

true
```

Return:

```text
true && true

↓

true
```

Answer:

```text
true
```

---

## ⚠️ Common Mistakes

### 1. Comparing the Wrong Nodes

Wrong:

```cpp
left->left ↔ right->left
```

Correct:

```cpp
left->left ↔ right->right
```

---

### 2. Forgetting NULL Checks

Always handle:

```cpp
Both NULL → true

One NULL → false
```

before accessing node values.

---

### 3. Using `||` Instead of `&&`

Both mirror comparisons must succeed.

Correct:

```cpp
outer && inner
```

---

## 🎯 Key Takeaways

* Extension of **100. Same Tree**.
* Compare **mirror positions**, not the same positions.
* Uses DFS recursion.
* Every node is visited exactly once.

---

## 💻 Implementation (C++)

```cpp
class Solution {
public:

    bool solve(TreeNode* left, TreeNode* right){

        if(left == nullptr && right == nullptr)
            return true;

        if(left == nullptr || right == nullptr)
            return false;

        if(left->val != right->val)
            return false;

        return solve(left->left, right->right) &&
               solve(left->right, right->left);
    }

    bool isSymmetric(TreeNode* root) {

        if(root == nullptr)
            return true;

        return solve(root->left, root->right);
    }
};
```
