# 144. Binary Tree Preorder Traversal

| Topic | Difficulty | Pattern |
|-------|------------|---------|
| Tree | Easy | DFS / Recursion |

---

## 📌 Problem Description

Given the root of a binary tree, return the **preorder traversal** of its nodes' values.

Preorder Traversal follows:

```text
Root → Left → Right
```

---

## 🧠 Intuition

Visit the current node first.

Then recursively traverse:

1. Left subtree
2. Right subtree

Since every subtree is itself a tree, the same recursive logic applies.

---

## 🎯 Pattern Recognition

Keywords:

- DFS
- Binary Tree Traversal
- Recursion
- Root → Left → Right

---

## ⚙️ Approach

Create a recursive helper function.

At every node:

```cpp
Visit Current Node
↓

Left

↓

Right
```

Store every visited node in the answer vector.

---

## 🧪 Dry Run

Tree:

```text
        1
       / \
      2   3
     / \
    4   5
```

Traversal:

```text
Visit 1

↓

Visit 2

↓

Visit 4

↓

Visit 5

↓

Visit 3
```

Output:

```text
[1,2,4,5,3]
```

---

## ⚠️ Common Mistakes

### 1. Visiting the root after recursion

Wrong:

```text
Left → Root → Right
```

Correct:

```text
Root → Left → Right
```

---

### 2. Forgetting the Base Case

Always check:

```cpp
if(root == nullptr)
    return;
```

---

### 3. Creating a New Vector in Every Recursive Call

Maintain one answer vector for the entire traversal.

---

## 🎯 Key Takeaways

- Preorder = Root → Left → Right
- DFS Recursive Traversal
- Every node is visited exactly once.
- Base case is `root == nullptr`.

---

## 💻 Implementation (C++)

```cpp
class Solution {
public:

    vector<int> ans;

    void preorder(TreeNode* root){

        if(root == nullptr)
            return;

        ans.push_back(root->val);

        preorder(root->left);

        preorder(root->right);
    }

    vector<int> preorderTraversal(TreeNode* root) {

        preorder(root);

        return ans;
    }
};
```
