# 226. Invert Binary Tree

| Topic | Difficulty | Pattern |
|--------|------------|---------|
| Tree | Easy | DFS / Top-Down Recursion |

---

## 📌 Problem Description

Given the root of a binary tree, invert the tree and return its root.

Inverting a binary tree means **swapping the left and right child of every node**.

---

## 🧠 Intuition

Every node performs exactly one operation:

- Swap its left and right child.
- Repeat the same operation for both subtrees.

Since every subtree is itself a binary tree, recursion naturally fits.

---

## 🎯 Pattern Recognition

Keywords:

- Mirror Tree
- Invert Tree
- Swap Children
- DFS
- Recursive Traversal

Whenever you hear:

> "Mirror the tree"

or

> "Invert every node"

Think:

> **DFS + Swap Left & Right**

---

## ⚙️ Approach (Top-Down DFS)

At every node:

1. If node is `NULL`, return.
2. Swap left and right children.
3. Recurse on new left subtree.
4. Recurse on new right subtree.
5. Return the root.

This is a **Preorder (Top-Down)** recursion because the work is done before visiting children.

---

## 🧪 Dry Run

Original Tree

```text
        4
      /   \
     2     7
    / \   / \
   1   3 6   9
```

Visit 4

Swap

```text
        4
      /   \
     7     2
    / \   / \
   6   9 3   1
```

Now recurse on 7

Swap

```text
      7
     / \
    9   6
```

Recurse on 2

Swap

```text
      2
     / \
    3   1
```

Final Tree

```text
        4
      /   \
     7     2
    / \   / \
   9   6 3   1
```

---

## 🔄 Recursive Call Flow

Suppose we call

```cpp
invertTree(root);
```

Call Stack

```text
invertTree(4)
    ↓
invertTree(7)
    ↓
invertTree(9)
    ↓
invertTree(NULL)
```

Base case returns immediately.

The stack then unwinds.

Every node swaps its own children.

Since pointers are modified **in-place**, the original tree becomes inverted.

Finally,

```cpp
return root;
```

returns the pointer to the original root node, whose children have already been updated.

---

## ⚠️ Common Mistakes

### 1. Forgetting the Base Case

Always check

```cpp
if(root == nullptr)
    return nullptr;
```

before accessing children.

---

### 2. Thinking a New Tree is Created

No new nodes are created.

Only existing child pointers are swapped.

---

### 3. Confusing Top-Down and Bottom-Up

Both work.

Top-down:

```cpp
swap()

left recursion

right recursion
```

Bottom-up:

```cpp
left recursion

right recursion

swap()
```

Top-down is simpler for this problem.

---

### 4. Writing

```cpp
return;
```

The function returns

```cpp
TreeNode*
```

so every return statement must return a pointer.

Correct:

```cpp
return nullptr;
```

or

```cpp
return root;
```

---

## 🎯 Key Takeaways

- Swap children of every node.
- Use DFS recursion.
- Modify pointers in-place.
- No extra tree is created.
- This is a classic **Top-Down Tree DFS** problem.
- Returning `root` simply returns the original root pointer after modification.

---

## 💻 Implementation (C++)

```cpp
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {

        if(root == nullptr)
            return nullptr;

        swap(root->left, root->right);

        invertTree(root->left);
        invertTree(root->right);

        return root;
    }
};
```

---

## 🔁 Bottom-Up Version

```cpp
class Solution {
public:
    TreeNode* invertTree(TreeNode* root) {

        if(root == nullptr)
            return nullptr;

        TreeNode* left = invertTree(root->left);
        TreeNode* right = invertTree(root->right);

        root->left = right;
        root->right = left;

        return root;
    }
};
```

## ⏱️ Complexity Analysis

| Complexity | Value |
|------------|-------|
| Time | **O(n)** |
| Space | **O(h)** |

Where:

- **n** = Number of nodes
- **h** = Height of the tree (recursion stack)

Worst case (skewed tree):

```text
Space = O(n)
```

Balanced tree:

```text
Space = O(log n)
```
