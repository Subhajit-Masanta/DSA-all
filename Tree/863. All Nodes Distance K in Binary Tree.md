# 863. All Nodes Distance K in Binary Tree

| Topic | Difficulty | Pattern              |
| ----- | ---------- | -------------------- |
| Tree  | Medium     | Parent Mapping + BFS |

---

# 📌 Problem Description

Given

* Root of a binary tree
* A target node
* An integer **K**

Return every node that is exactly **K edges away** from the target node.

The answer can be returned in any order.

---

# 🧠 Intuition

Normally in a binary tree we can only move

```text
Parent

↓

Child
```

But this problem allows us to travel

```text
Parent

↕

Child
```

because nodes at distance **K** may lie

* Below the target
* Above the target
* In another subtree

Example

```text
                3
             /     \
            5       1
          /   \    / \
         6     2  0   8
              / \
             7   4
```

Target

```text
5
```

K

```text
2
```

Nodes at distance 2

```text
7

4

1
```

---

# Key Observation

Tree nodes do **not** have

```cpp
root->parent
```

So first we create one.

---

# Step 1

Build Parent Mapping.

```cpp
unordered_map<TreeNode*, TreeNode*> parent;
```

Store

```text
Child

↓

Parent
```

Example

```text
parent[5] = 3

parent[6] = 5

parent[2] = 5

parent[7] = 2

parent[4] = 2
```

This takes one DFS traversal.

---

# Step 2

Start BFS from target.

```text
Queue

↓

Target
```

Instead of starting from the root.

---

# Three Neighbours

Every node can now move to

```text
Parent

Left Child

Right Child
```

Example

```text
        5
      /   \
     6     2
     ↑     ↓
     3     7
           4
```

When processing node 5

Possible moves are

```text
3

6

2
```

---

# Why Visited?

Without visited

```text
5

↓

3

↓

5

↓

3
```

Infinite loop.

Use

```cpp
unordered_map<TreeNode*, bool> visited;
```

or

```cpp
unordered_set<TreeNode*> visited;
```

---

# Algorithm

```text
DFS

↓

Build Parent Map

↓

Queue ← Target

↓

Visited ← Target

↓

BFS

↓

Left

Right

Parent

↓

After K Levels

↓

Nodes remaining inside queue

↓

Answer
```

# Code

```cpp
class Solution {
public:

    unordered_map<TreeNode*, TreeNode*> parent;

    void buildParent(TreeNode* root)
    {
        if(root == nullptr)
            return;

        if(root->left)
            parent[root->left] = root;

        if(root->right)
            parent[root->right] = root;

        buildParent(root->left);
        buildParent(root->right);
    }

    vector<int> distanceK(TreeNode* root, TreeNode* target, int k)
    {
        if(root == nullptr)
            return {};

        buildParent(root);

        unordered_map<TreeNode*, bool> visited;

        queue<TreeNode*> q;

        q.push(target);

        visited[target] = true;

        int level = 0;

        while(!q.empty())
        {
            if(level == k)
                break;

            int size = q.size();

            while(size--)
            {
                TreeNode* node = q.front();
                q.pop();

                if(node->left && !visited[node->left])
                {
                    q.push(node->left);
                    visited[node->left] = true;
                }

                if(node->right && !visited[node->right])
                {
                    q.push(node->right);
                    visited[node->right] = true;
                }

                if(parent[node] && !visited[parent[node]])
                {
                    q.push(parent[node]);
                    visited[parent[node]] = true;
                }
            }

            level++;
        }

        vector<int> ans;

        while(!q.empty())
        {
            ans.push_back(q.front()->val);
            q.pop();
        }

        return ans;
    }
};
```

# Common Mistakes

## ❌ Forgetting Parent Map

Then you cannot move upward.

---

## ❌ Forgetting Visited

Creates infinite loops

```text
5

↓

3

↓

5
```

---

## ❌ Starting BFS from Root

Wrong.

Start from

```text
Target
```

---

## ❌ Processing Level K

When

```cpp
level == k
```

Stop BFS.

The queue already contains the correct nodes.

---

# Complexity

| Complexity | Value |
| ---------- | ----- |
| Time       | O(n)  |
| Space      | O(n)  |

* **DFS** builds the parent map in **O(n)**.
* **BFS** visits each node at most once.
* The parent map and visited map together use **O(n)** extra space.

---

# Key Takeaways

* Convert the tree into an **undirected graph** by storing parent pointers.
* Build the parent map with one DFS.
* Start BFS from the **target**, not the root.
* Every node has **three neighbors**: left child, right child, and parent.
* Use a visited structure to avoid revisiting nodes.
* When BFS reaches level **K**, the queue already contains the answer nodes.
