# 993. Cousins in Binary Tree

| Topic | Difficulty | Pattern                             |
| ----- | ---------- | ----------------------------------- |
| Tree  | Easy       | BFS / Level Order + Parent Tracking |

---

## 📌 Problem Description

Given the root of a binary tree and two node values `x` and `y`, determine whether they are **cousins**.

Two nodes are cousins if:

* They are at the **same depth (level)**.
* They have **different parents**.

---

## 🧠 Intuition

This problem is another **Level Order Traversal (BFS)** problem.

Unlike previous BFS questions, we do **not** store node values.

Instead, during each level we track:

* Whether `x` is found.
* Whether `y` is found.
* Parent of `x`.
* Parent of `y`.

After processing one complete level, we compare this information.

---

## 🎯 Pattern Recognition

Keywords:

* BFS
* Queue
* Level Order
* Parent Tracking
* Same Level
* Different Parents

---

## ⚙️ Approach

For every level:

1. Initialize

```cpp
foundX = false;
foundY = false;

parentX = nullptr;
parentY = nullptr;
```

2. Process every node of the current level.

3. For every node:

* Check its left child.
* Check its right child.
* If child value is `x` or `y`, remember the current node as its parent.
* Push existing children into the queue.

4. After finishing the level:

* If both are found:

  * Return

```cpp
parentX != parentY
```

* If only one is found:

  * Return `false`.

Otherwise continue to the next level.

## ⚠️ Common Mistakes

### 1. Returning True When Both Nodes Are Found

Wrong.

Always verify:

```cpp
parentX != parentY
```

Otherwise siblings would incorrectly be considered cousins.

---

### 2. Declaring Variables Inside the Inner Loop

Wrong:

```cpp
while(size--){
    bool foundX = false;
}
```

They get reset for every node.

Declare them **once per level**.

---

### 3. Searching for Parents Later

You already know the parent.

When processing:

```cpp
TreeNode* node
```

The parent of

```cpp
node->left
```

and

```cpp
node->right
```

is simply

```cpp
node
```

---

## 🎯 Key Takeaways

* Same BFS template as previous problems.
* Process one level at a time.
* Track parent information.
* Cousins = Same Level + Different Parents.
* If only one node is found at a level, return `false`.

---

## 💻 Implementation (C++)

```cpp
class Solution {
public:
    bool isCousins(TreeNode* root, int x, int y) {

        if(root == nullptr)
            return false;

        queue<TreeNode*> q;
        q.push(root);

        while(!q.empty()){

            int size = q.size();

            bool foundX = false;
            bool foundY = false;

            TreeNode* parentX = nullptr;
            TreeNode* parentY = nullptr;

            while(size--){

                TreeNode* node = q.front();
                q.pop();

                if(node->left){

                    if(node->left->val == x){
                        foundX = true;
                        parentX = node;
                    }

                    if(node->left->val == y){
                        foundY = true;
                        parentY = node;
                    }

                    q.push(node->left);
                }

                if(node->right){

                    if(node->right->val == x){
                        foundX = true;
                        parentX = node;
                    }

                    if(node->right->val == y){
                        foundY = true;
                        parentY = node;
                    }

                    q.push(node->right);
                }
            }

            if(foundX && foundY)
                return parentX != parentY;

            if(foundX || foundY)
                return false;
        }

        return false;
    }
};
```
