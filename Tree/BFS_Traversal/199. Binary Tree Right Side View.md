# 199. Binary Tree Right Side View

| Topic | Difficulty | Pattern                     |
| ----- | ---------- | --------------------------- |
| Tree  | Medium     | BFS / Level Order Traversal |

---

## 📌 Problem Description

Given the root of a binary tree, return the values of the nodes visible when viewing the tree from the **right side**, from top to bottom.

At every level, only the **rightmost node** is visible.

---

## 🧠 Intuition

This problem is another variation of **102. Binary Tree Level Order Traversal**.

The BFS traversal **does not change**.

The only difference is:

* Process the tree level by level.
* Store **only the last node** of each level.

Since BFS visits each level from **left to right**, the last processed node is the **rightmost node**.

---

## 🎯 Pattern Recognition

Keywords:

* BFS
* Queue
* Level Order Traversal
* Right View
* Last Node of Level

---

## ⚙️ Approach

For every level:

1. Get the number of nodes in the current level.
2. Process all nodes of that level.
3. If the current node is the **last node** of the level, store its value.
4. Push its left and right children into the queue.

---

---

## ⚠️ Common Mistakes

### 1. Saving Every Node

Only save the **last node** of the current level.

---

### 2. Confusing Right Child with Rightmost Node

The rightmost node is **not always a right child**.

It is simply the **last node processed at that level**.

---

### 3. Changing the BFS Traversal

Keep the normal BFS:

```cpp
Left Child

↓

Right Child
```

Only change what you save from each level.

---

## 🎯 Key Takeaways

* Same BFS template as **102**.
* Queue logic never changes.
* Store only the last node of every level.
* One value is added to the answer for each level.

---

## 💻 Implementation (C++)

```cpp
class Solution {
public:

    queue<TreeNode*> q;
    vector<int> ans;

    vector<int> rightSideView(TreeNode* root) {

        if(root)
            q.push(root);

        while(!q.empty()){

            int size = q.size();

            while(size--){

                TreeNode* node = q.front();
                q.pop();

                if(size == 0)
                    ans.push_back(node->val);

                if(node->left)
                    q.push(node->left);

                if(node->right)
                    q.push(node->right);
            }
        }

        return ans;
    }
};
```
