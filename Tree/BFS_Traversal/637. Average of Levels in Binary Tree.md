# 637. Average of Levels in Binary Tree

| Topic | Difficulty | Pattern                     |
| ----- | ---------- | --------------------------- |
| Tree  | Easy       | BFS / Level Order Traversal |

---

## 📌 Problem Description

Given the root of a binary tree, return the **average value of the nodes at each level**.

The answer should contain one average for every level from top to bottom.

---

## 🧠 Intuition

This problem is almost identical to **102. Binary Tree Level Order Traversal**.

The BFS traversal **does not change**.

Instead of storing every node of a level, we:

* Calculate the sum of all nodes in that level.
* Divide the sum by the number of nodes in that level.
* Store the average.

---

## 🎯 Pattern Recognition

Keywords:

* BFS
* Queue
* Level Order Traversal
* Sum of Level
* Average of Level

---

## ⚙️ Approach

For every level:

1. Store the number of nodes in the current level.
2. Initialize `sum = 0`.
3. Traverse all nodes of that level.
4. Add every node value to `sum`.
5. Push children into the queue.
6. Compute:

```cpp
average = (double)sum / levelSize;
```

7. Store the average.

## ⚠️ Common Mistakes

### 1. Using `int` for Sum

Use:

```cpp
long long sum = 0;
```

to avoid overflow when adding many node values.

---

### 2. Dividing Using Integer Division

Wrong

```cpp
sum / size
```

Correct

```cpp
(double)sum / size
```

---

### 3. Changing the BFS Logic

The queue traversal is exactly the same as **102**.

Only the processing of one level changes.

---

## 🎯 Key Takeaways

* Same BFS template as Level Order Traversal.
* Calculate the sum of each level.
* Average = Sum / Number of Nodes.
* Visit every node exactly once.

---

## 💻 Implementation (C++)

```cpp
class Solution {
public:

    queue<TreeNode*> q;
    vector<double> ans;

    vector<double> averageOfLevels(TreeNode* root) {

        if(root)
            q.push(root);

        while(!q.empty()){

            int size = q.size();
            int total = size;
            double current = 0;

            while(size--){

                TreeNode* node = q.front();
                q.pop();

                current += node->val;

                if(node->left)
                    q.push(node->left);

                if(node->right)
                    q.push(node->right);
            }

            current /= total;

            ans.push_back(current);
        }

        return ans;
    }
};
```

| Complexity | Value    |
| ---------- | -------- |
| Time       | **O(n)** |

* **n** = Number of nodes in the tree.
* Every node is processed exactly once.
