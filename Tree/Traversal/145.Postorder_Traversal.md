# 145. Binary Tree Postorder Traversal

| Topic | Difficulty | Pattern |
|-------|------------|---------|
| Tree | Easy | DFS / Recursion |

---

## 📌 Problem Description

Given the root of a binary tree, return the **postorder traversal** of its nodes' values.

Postorder Traversal follows:

```text
Left → Right → Root
```

---

## 🧠 Intuition

Traverse both subtrees first.

Visit the current node only after both recursive calls finish.

---

## 🎯 Pattern Recognition

Keywords:

- DFS
- Binary Tree Traversal
- Recursion
- Left → Right → Root

---

## ⚙️ Approach

Create a recursive helper function.

At every node:

```cpp
Left

↓

Right

↓

Visit Current Node
```

Store the node value after visiting both subtrees.

---

## 🧪 Dry Run

Tree:

```text
        1
       / \
      2   3
     / \
    4   5
```

Traversal:

```text
Visit 4

↓

Visit 5

↓

Visit 2

↓

Visit 3

↓

Visit 1
```

Output:

```text
[4,5,2,3,1]
```

---

## ⚠️ Common Mistakes

### 1. Visiting the root too early

Wrong:

```text
Root → Left → Right
```

Correct:

```text
Left → Right → Root
```

---

### 2. Forgetting the Base Case

Always check:

```cpp
if(root == nullptr)
    return;
```

---

### 3. Creating a New Vector in Every Recursive Call

Maintain one answer vector throughout recursion.

---

## 🎯 Key Takeaways

- Postorder = Left → Right → Root
- DFS Recursive Traversal
- Current node is visited last.
- Base case is `root == nullptr`.

---

## 💻 Implementation (C++)

```cpp
class Solution {
public:

    vector<int> ans;

    void postorder(TreeNode* root){

        if(root == nullptr)
            return;

        postorder(root->left);

        postorder(root->right);

        ans.push_back(root->val);
    }

    vector<int> postorderTraversal(TreeNode* root) {

        postorder(root);

        return ans;
    }
};
```

---

## ⏱️ Complexity Analysis

| Complexity | Value |
|------------|-------|
| Time | **O(n)** |
| Space | **O(h)** |
