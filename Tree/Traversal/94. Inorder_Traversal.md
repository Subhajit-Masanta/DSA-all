# 94. Binary Tree Inorder Traversal

| Topic | Difficulty | Pattern |
|-------|------------|---------|
| Tree | Easy | DFS / Recursion |

---

## 📌 Problem Description

Given the root of a binary tree, return the **inorder traversal** of its nodes' values.

Inorder Traversal follows:

```text
Left → Root → Right
```

---

## 🧠 Intuition

Think recursively.

For every node:

1. Traverse the left subtree.
2. Visit the current node.
3. Traverse the right subtree.

Every subtree is itself a binary tree, so the same logic applies recursively.

---

## 🎯 Pattern Recognition

Keywords:

- DFS
- Binary Tree Traversal
- Recursion
- Left → Root → Right

---

## ⚙️ Approach

Create a recursive helper function.

At every node:

```cpp
Left
↓

Visit Current Node
↓

Right
```

Store the visited node values in a vector.

---

## 🧪 Dry Run

Tree:

```text
        1
       / \
      2   3
     / \
    4   5
```

Traversal:

```text
Go Left

4

Visit 2

5

Visit 1

3
```

Output:

```text
[4,2,5,1,3]
```

---

## ⚠️ Common Mistakes

### 1. Visiting the root first

Wrong:

```text
Root → Left → Right
```

Correct:

```text
Left → Root → Right
```

---

### 2. Forgetting the Base Case

Always check:

```cpp
if(root == nullptr)
    return;
```

---

### 3. Creating a New Vector in Every Recursive Call

Maintain a single answer vector throughout the recursion.

---

## 🎯 Key Takeaways

- Inorder = Left → Root → Right
- DFS Recursive Traversal
- Every node is visited exactly once.
- Base case is `root == nullptr`.

---

## 💻 Implementation (C++)

```cpp
class Solution {
public:

    vector<int> ans;

    void inorder(TreeNode* root){

        if(root == nullptr)
            return;

        inorder(root->left);

        ans.push_back(root->val);

        inorder(root->right);
    }

    vector<int> inorderTraversal(TreeNode* root) {

        inorder(root);

        return ans;
    }
};
```
