# 226. Invert Binary Tree

| Topic | Difficulty | Pattern                 |
| ----- | ---------- | ----------------------- |
| Tree  | Easy       | DFS / Tree Modification |

---

## 📌 Problem Description

Given the root of a binary tree, **invert (mirror)** the tree and return its root.

Inverting a tree means swapping the **left** and **right** child of **every node** in the tree.

---

## 🧠 Intuition

Unlike previous tree problems where we **returned information** (height or boolean), this problem asks us to **modify the tree itself**.

At every node:

```text
Left Child  ↔  Right Child
```

Since every child is itself the root of another tree, recursion naturally solves the problem.

---

## 🎯 Pattern Recognition

Keywords:

* DFS
* Tree Modification
* Mirror Tree
* Recursion
* Swap Children

---

## ⚙️ Approach

For every node:

1. If the node is `NULL`, return.
2. Recursively invert the left subtree.
3. Recursively invert the right subtree.
4. Swap the left and right child.
5. Return the current root.

> **Note:** Swapping **before recursion (Preorder)** or **after recursion (Postorder)** both work because every node is swapped exactly once.

---

## 🧪 Dry Run

Original Tree

```text
          4
        /   \
       2     7
      / \   / \
     1   3 6   9
```

Invert left subtree:

```text
      2              2
     / \    →       / \
    1   3          3   1
```

Invert right subtree:

```text
      7              7
     / \    →       / \
    6   9          9   6
```

Finally invert root:

```text
          4
        /   \
       7     2
      / \   / \
     9   6 3   1
```

---

## ⚠️ Common Mistakes

### 1. Forgetting the Base Case

Always start with:

```cpp
if(root == nullptr)
    return root;
```

---

### 2. Handling Leaf Nodes Separately

A leaf node already swaps

```text
NULL ↔ NULL
```

which changes nothing.

No separate leaf-node condition is required.

---

### 3. Forgetting to Return the Root

The function must return the root of the modified subtree.

---

## 🎯 Key Takeaways

* First tree problem that **modifies** the tree.
* Every node swaps its left and right children.
* DFS recursion naturally visits every node.
* Both **Preorder** and **Postorder** recursive solutions are correct.

---

## 💻 DFS (Postorder) Implementation

```cpp
class Solution {
public:

    TreeNode* solve(TreeNode* root){

        if(root == nullptr)
            return root;

        solve(root->left);
        solve(root->right);

        swap(root->left, root->right);

        return root;
    }

    TreeNode* invertTree(TreeNode* root) {

        return solve(root);
    }
};
```

---

## 💻 DFS (Preorder) Implementation

```cpp
class Solution {
public:

    TreeNode* invertTree(TreeNode* root) {

        if(root == nullptr)
            return root;

        swap(root->left, root->right);

        invertTree(root->left);
        invertTree(root->right);

        return root;
    }
};
```

## ⏱️ Complexity Analysis

| Complexity | Value    |
| ---------- | -------- |
| Time       | **O(n)** |
| Space      | **O(h)** |

Where:

* **n** = Number of Nodes
* **h** = Height of the Tree (recursion stack).
