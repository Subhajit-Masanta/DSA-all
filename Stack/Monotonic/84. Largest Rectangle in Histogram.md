# 84. Largest Rectangle in Histogram

| Topic | Difficulty | Pattern                    |
| ----- | ---------- | -------------------------- |
| Stack | Hard       | Monotonic Increasing Stack |

---

## 📌 Problem Description

Given an array `heights`, where each element represents the height of a histogram bar (width = 1), find the area of the largest rectangle that can be formed.

---

## 🧠 Intuition

Assume every bar is the **smallest bar** in its rectangle.

For each bar, find:

* Previous Smaller Element (PSE)
* Next Smaller Element (NSE)

These two elements determine how far this bar can extend.

---

## 🎯 Pattern Recognition

Keywords:

* Previous Smaller Element
* Next Smaller Element
* Width Calculation
* Monotonic Increasing Stack

---

## ⚙️ Formula

For every index `i`:

```text
width = right[i] - left[i] - 1
area = heights[i] × width
```

Where:

* `left[i]` = Previous Smaller Index
* `right[i]` = Next Smaller Index

Special cases:

```text
No Previous Smaller → left = -1
No Next Smaller     → right = n
```

---

## 🧪 Dry Run

Input

```text
[2,1,5,6,2,3]
```

Previous Smaller:

```text
[-1,-1,1,2,1,4]
```

Next Smaller:

```text
[1,6,4,4,6,6]
```

Area Calculation:

| Height | Left | Right | Width | Area |
| -----: | ---: | ----: | ----: | ---: |
|      2 |   -1 |     1 |     1 |    2 |
|      1 |   -1 |     6 |     6 |    6 |
|      5 |    1 |     4 |     2 |   10 |
|      6 |    2 |     4 |     1 |    6 |
|      2 |    1 |     6 |     4 |    8 |
|      3 |    4 |     6 |     1 |    3 |

Maximum Area:

```text
10
```

---

## 📚 Stack Behavior

Maintain a **Monotonically Increasing Stack**.

Whenever a smaller height arrives:

* Current index becomes Next Smaller.
* New stack top becomes Previous Smaller.
* Rectangle width becomes finalized.

---

## ⚠️ Common Mistakes

### 1. Storing Heights Instead of Indices

Wrong:

```cpp
stack<int> // storing heights
```

Correct:

```cpp
stack<int> // storing indices
```

---

### 2. Initializing Right with -1

Wrong:

```cpp
vector<int> right(n,-1);
```

Correct:

```cpp
vector<int> right(n,n);
```

---

### 3. Forgetting Equal Heights

Use:

```cpp
>=
```

while finding Previous Smaller.

---

### 4. Wrong Width Formula

Wrong:

```cpp
right-left
```

Correct:

```cpp
right-left-1
```

because both boundaries are excluded.

## 🎯 Key Takeaways

* Every bar acts as the smallest bar once.
* Width is determined by Previous & Next Smaller.
* Histogram is the combination of PSE + NSE.
* One-pass solution calculates area while popping.

---

# 💻 Approach 1 (Two Arrays)

```cpp
class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {

        int n = heights.size();

        vector<int> left(n,-1);
        vector<int> right(n,n);

        stack<int> st;

        // Next Smaller
        for(int i=0;i<n;i++){

            while(!st.empty() &&
                  heights[i] < heights[st.top()]){

                right[st.top()] = i;
                st.pop();
            }

            st.push(i);
        }

        while(!st.empty())
            st.pop();

        // Previous Smaller
        for(int i=0;i<n;i++){

            while(!st.empty() &&
                  heights[st.top()] >= heights[i])
                st.pop();

            if(!st.empty())
                left[i]=st.top();

            st.push(i);
        }

        int ans=0;

        for(int i=0;i<n;i++){

            int width = right[i]-left[i]-1;
            int area = heights[i]*width;

            ans=max(ans,area);
        }

        return ans;
    }
};
```

### Complexity

* **Time:** `O(n)`
* **Space:** `O(n)`

# 💻 Approach 2 (One Pass Stack)

```cpp
class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {

        int n = heights.size();

        stack<int> st;
        int ans = 0;

        for(int i=0;i<=n;i++){

            int currHeight = (i==n)?0:heights[i];

            while(!st.empty() &&
                  currHeight < heights[st.top()]){

                int idx = st.top();
                st.pop();

                int left = st.empty() ? -1 : st.top();
                int width = i - left - 1;

                ans = max(ans, heights[idx]*width);
            }

            st.push(i);
        }

        return ans;
    }
};
```

### Complexity

* **Time:** `O(n)`
* **Space:** `O(n)`
