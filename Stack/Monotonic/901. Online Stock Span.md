# 901. Online Stock Span

| Topic | Difficulty | Pattern                    |
| ----- | ---------- | -------------------------- |
| Stack | Medium     | Monotonic Decreasing Stack |

---

## 📌 Problem Description

Design a data structure that receives stock prices one by one.

For every incoming price, return its **span**.

Span = Number of consecutive days (including today) for which:

```text
previous price <= current price
```

when moving backwards.

---

## 🧠 Intuition

For every new stock price, we need to find:

```text
Nearest Previous Greater Element
```

Why?

Because all prices after that greater element and before today contribute to the span.

Example:

```text
100 80 60 70 60 75
```

Current:

```text
75
```

Previous Greater:

```text
80
```

Index:

```text
1
```

Current Index:

```text
5
```

Span:

```text
5 - 1 = 4
```

## ⚙️ Approach

Maintain a stack storing:

```cpp
{price, index}
```

For each incoming price:

### Step 1

Remove all prices:

```cpp
<= current price
```

because they can never be Previous Greater Elements for future prices.

### Step 2

After popping:

If stack is empty:

```cpp
span = currentIndex + 1
```

Else:

```cpp
span = currentIndex - previousGreaterIndex
```

### Step 3

Push current:

```cpp
{price, currentIndex}
```

into stack.

## ⚠️ Common Mistakes

### 1. Creating Stack Inside next()

Wrong:

```cpp
int next(int price){
    stack<pair<int,int>> st;
}
```

Stack becomes empty every function call.

History is lost.

Stack must be a class member.

---

### 2. Using Current Span Counter Incorrectly

Always find:

```text
Nearest Previous Greater
```

first.

Then calculate span.

---

### 3. Using < Instead of <=

Wrong:

```cpp
price > st.top().first
```

Correct:

```cpp
price >= st.top().first
```

Because equal prices are also included in span.

## 🎯 Key Takeaways

* Stock Span is a Previous Greater Element problem.
* Stack remains Monotonically Decreasing.
* Remove all smaller/equal prices.
* Top becomes Nearest Previous Greater.
* Span is computed using indices.

## 💻 Online Stock Span (LeetCode 901)

```cpp
class StockSpanner {
private:
    stack<pair<int,int>> st;
    int idx;

public:
    StockSpanner() {
        idx = 0;
    }

    int next(int price) {

        while(!st.empty() &&
              price >= st.top().first) {
            st.pop();
        }

        int span;

        if(st.empty())
            span = idx + 1;
        else
            span = idx - st.top().second;

        st.push({price, idx});
        idx++;

        return span;
    }
};
```

## 💻 If Question Asks Entire Span Array

Input:

```text
100 80 60 70 60 75 85
```

Output:

```text
1 1 1 2 1 4 6
```

```cpp
vector<int> stockSpan(vector<int>& prices) {

    int n = prices.size();

    vector<int> ans(n);
    stack<int> st;

    for(int i = 0; i < n; i++) {

        while(!st.empty() &&
              prices[i] >= prices[st.top()]) {
            st.pop();
        }

        if(st.empty())
            ans[i] = i + 1;
        else
            ans[i] = i - st.top();

        st.push(i);
    }

    return ans;
}
```
