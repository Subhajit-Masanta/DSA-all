# 901. Online Stock Span

| Topic | Difficulty | Pattern                    |
| ----- | ---------- | -------------------------- |
| Stack | Medium     | Monotonic Decreasing Stack |

---

## 📌 Problem Description

Design a data structure that receives stock prices one by one.

For every incoming price, return its **span**.

Span = Number of consecutive days (including today) for which:

```text
previous price <= current price
```

when moving backwards.

---

## 🧠 Intuition

For every new stock price, we need to find:

```text
Nearest Previous Greater Element
```

Why?

Because all prices after that greater element and before today contribute to the span.

Example:

```text
100 80 60 70 60 75
```

Current:

```text
75
```

Previous Greater:

```text
80
```

Index:

```text
1
```

Current Index:

```text
5
```

Span:

```text
5 - 1 = 4
```

# 💡 My Version 1 — Store `{price, span}`

If the **entire array of prices is given**, we don't necessarily need indices.

We can store:

```cpp
{price, span}
```

When the current price is greater than or equal to the top price, we can directly add the top element's already-calculated span.

```cpp
vector<int> stockSpan(vector<int>& prices) {

    int n = prices.size();
    vector<int> ans(n);

    stack<pair<int, int>> st; // {price, span}

    for(int i = 0; i < n; i++) {

        int span = 1;

        while(!st.empty() &&
              prices[i] >= st.top().first) {

            span += st.top().second;
            st.pop();
        }

        ans[i] = span;

        st.push({prices[i], span});
    }

    return ans;
}
```

### Why `span += st.top().second` works

Suppose:

```text
100 80 60 70 60 75
```

When `75` arrives, it removes:

```text
60 → span 1
70 → span 2
60 → span 1
```

Instead of counting all those days individually:

```cpp
span += st.top().second;
```

uses the span already calculated for each popped element.

For `75`:

```text
1 + 1 + 2 = 4
```

So its span is:

```text
4
```

### Important

The comparison must be:

```cpp
prices[i] >= st.top().first
```

not:

```cpp
prices[i] > st.top().first
```

because equal prices are also included.

Example:

```text
100 100
```

The second `100` has span `2`.

# 💡 My Version 2 — Store Only Indices

We can also use the same idea as the Online Stock Spanner class, but when the **whole array is available**, we can store only indices.

```cpp
vector<int> stockSpan(vector<int>& prices) {

    int n = prices.size();

    vector<int> ans(n);
    stack<int> st;

    for(int i = 0; i < n; i++) {

        while(!st.empty() &&
              prices[i] >= prices[st.top()]) {
            st.pop();
        }

        if(st.empty())
            ans[i] = i + 1;
        else
            ans[i] = i - st.top();

        st.push(i);
    }

    return ans;
}
```

### Why index subtraction works

Suppose:

```text
j ................. i
```

where:

* `j` = nearest previous greater element
* `i` = current index

Everything between `j` and `i` belongs to the span.

Therefore:

```cpp
span = i - j;
```

If there is no previous greater element:

```cpp
span = i + 1;
```

because every element from index `0` through `i` is included.

This is basically the same logic as the Online Stock Spanner implementation below.

# ⚙️ Standard Approach — Online Stock Span

When prices arrive **one at a time**, we cannot use an array of all prices.

Maintain a stack storing:

```cpp
{price, index}
```

For each incoming price:

### Step 1

Remove all prices:

```cpp
<= current price
```

because they cannot be Previous Greater Elements.

### Step 2

After popping:

If stack is empty:

```cpp
span = currentIndex + 1
```

Else:

```cpp
span = currentIndex - previousGreaterIndex
```

### Step 3

Push:

```cpp
{price, currentIndex}
```

into stack.

## ⚠️ Common Mistakes

### 1. Creating Stack Inside `next()`

Wrong:

```cpp
int next(int price) {
    stack<pair<int,int>> st;
}
```

The stack becomes empty every function call.

History is lost.

Stack must be a class member.

---

### 2. Using `<` Instead of `<=`

Wrong:

```cpp
price > st.top().first
```

Correct:

```cpp
price >= st.top().first
```

Equal prices are also included in the span.

---

### 3. Confusing Previous Greater With Previous Smaller

Stock Span needs:

```text
Previous Greater
```

So we remove:

```text
smaller OR equal
```

until the top is greater than the current price.

## 💻 Online Stock Span — LeetCode 901

```cpp
class StockSpanner {
private:
    stack<pair<int,int>> st;
    int idx;

public:
    StockSpanner() {
        idx = 0;
    }

    int next(int price) {

        while(!st.empty() &&
              price >= st.top().first) {
            st.pop();
        }

        int span;

        if(st.empty())
            span = idx + 1;
        else
            span = idx - st.top().second;

        st.push({price, idx});
        idx++;

        return span;
    }
};
```

## 🎯 Key Takeaways

* Stock Span = **Previous Greater Element** problem.
* Stack is **monotonically decreasing** from bottom to top.
* Remove all smaller/equal prices.
* The remaining top is the **nearest previous greater**.
* With indices, span = `currentIndex - previousGreaterIndex`.
* If there is no previous greater, span = `currentIndex + 1`.
* If the whole array is given, we can either:

  * store `{price, span}`, or
  * store only indices.
* In the online version, the stack must persist between calls.
* Every element is pushed once and popped at most once.
