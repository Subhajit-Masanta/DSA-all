# 739. Daily Temperatures

| Topic | Difficulty | Pattern                    |
| ----- | ---------- | -------------------------- |
| Stack | Medium     | Monotonic Decreasing Stack |

---

## 📌 Problem Description

Given an array:

```cpp
temperatures[i]
```

Return an array:

```cpp
answer[i]
```

where:

```text
answer[i]
```

represents the number of days until a warmer temperature occurs.

If no warmer day exists:

```text
answer[i] = 0
```

---

## 🧠 Intuition

For each day, we need to find:

```text
First warmer temperature on the right
```

This is essentially:

```text
Next Greater Element
```

But instead of storing the warmer temperature, we store:

```text
Distance (days)
```

between the current day and the warmer day.

---

## 🎯 Pattern Recognition

Keywords:

* Next Greater Element
* First Greater on Right
* Waiting Days
* Monotonic Stack

Key Idea:

```text
Current warmer temperature resolves colder waiting days.
```

---

## ⚙️ Approach

### Step 1

Maintain a stack storing indices.

### Step 2

Traverse temperatures from left to right.

### Step 3

Whenever:

```cpp
temperatures[i] > temperatures[st.top()]
```

the current day becomes the answer for the waiting day.

### Step 4

Calculate:

```cpp
ans[idx] = i - idx;
```

where:

```cpp
idx = st.top();
```

### Step 5

Pop resolved days.

### Step 6

Push the current index.

### Step 7

Days remaining in the stack have no warmer temperature.

Their answer remains:

```text
0
```

## ⚠️ Common Mistakes

### 1. Storing Temperatures Instead of Indices

Wrong:

```cpp
stack<int> st;
```

with values only.

Need indices because answer requires:

```cpp
futureDay - currentDay
```

---

### 2. Storing Temperature Instead of Distance

Wrong:

```cpp
ans[idx] = temperatures[i];
```

Question asks:

```text
Number of days
```

not temperature.

---

### 3. Using if Instead of while

Wrong:

```cpp
if(...)
```

One warmer day may resolve multiple waiting days.

Need:

```cpp
while(...)
```

---

### 4. Forgetting Default Zero

Days with no warmer temperature must remain:

```text
0
```

Initialize:

```cpp
vector<int> ans(n,0);
```

## 🎯 Key Takeaways

* Daily Temperatures is a Next Greater Element problem.
* Stack stores unresolved indices.
* Current warmer temperature resolves previous colder days.
* Store distance, not temperature.
* Use a monotonic decreasing stack.

---

## 💻 Implementation (C++)

```cpp
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {

        int n = temperatures.size();

        stack<int> st;
        vector<int> ans(n, 0);

        for(int i = 0; i < n; i++) {

            while(!st.empty() &&
                  temperatures[i] > temperatures[st.top()]) {

                ans[st.top()] = i - st.top();
                st.pop();
            }

            st.push(i);
        }

        return ans;
    }
};
```
