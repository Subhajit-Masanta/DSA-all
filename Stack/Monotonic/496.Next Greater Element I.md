## 📌 Problem Description

For every element in `nums1`, find its Next Greater Element (NGE) in `nums2`.

The Next Greater Element of `x` is the first element greater than `x` that appears on its right side in `nums2`.

If no greater element exists, return `-1`.

---

## 🧠 Intuition

For an element, we cannot determine its Next Greater Element until we see a larger number on its right.

Therefore, elements whose answer is not yet known must be stored somewhere.

A stack is used to keep track of these unresolved elements.

When a larger element arrives, it resolves one or more waiting elements.

## ⚙️ Approach

### Step 1

Process `nums2` from left to right.

### Step 2

Maintain a stack containing unresolved elements.

### Step 3

Whenever:

```cpp id="g3"
current > stack.top()
```

the current number becomes the Next Greater Element of the stack top.

Store:

```cpp id="g4"
nge[stack.top()] = current
```

and pop.

### Step 4

Continue popping while current element can resolve more elements.

### Step 5

Push current element into stack.

### Step 6

After traversal, remaining elements have no Next Greater Element.

Assign:

```text id="g5"
-1
```

### Step 7

Use the hashmap to build the answer for `nums1`.

## ⚠️ Common Mistakes

### 1. Using if Instead of while

Wrong:

```cpp id="g25"
if(num > st.top())
```

One element may resolve multiple elements.

Example:

```text id="g26"
2 1 5
```

When 5 arrives:

```text id="g27"
1 -> 5
2 -> 5
```

Need:

```cpp id="g28"
while(...)
```

---

### 2. Forgetting Remaining Elements

After traversal:

```text id="g29"
Elements left in stack
```

must be assigned:

```text id="g30"
-1
```

---

### 3. Storing Answers in Stack

Stack stores:

```text id="g31"
Unresolved elements
```

HashMap stores:

```text id="g32"
Final answers
```

## 🎯 Key Takeaways

* Stack stores unresolved elements.
* Current element resolves smaller elements.
* One element can resolve multiple elements.
* Use `while`, not `if`.
* HashMap stores the final Next Greater Element mapping.

## 💻 Implementation (C++)

```cpp
class Solution {
public:
    vector<int> nextGreaterElement(vector<int>& nums1, vector<int>& nums2) {
        unordered_map<int, int> next;
        stack<int> s;

        for(int num : nums2) {
            while(!s.empty() && num > s.top()) {
                next[s.top()] = num;
                s.pop();
            }

            s.push(num);
        }

        while(!s.empty()) {
            next[s.top()] = -1;
            s.pop();
        }

        vector<int> ans;

        for(int num : nums1) {
            ans.push_back(next[num]);
        }

        return ans;
    }
};
```
