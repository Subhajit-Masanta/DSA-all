# 20. Valid Parentheses

| Topic | Difficulty | Pattern           |
| ----- | ---------- | ----------------- |
| Stack | Easy       | Balanced Brackets |

---

## 📌 Problem Description

Given a string containing:

```text
()
{}
[]
```

Determine whether the brackets are balanced.

A valid string must satisfy:

* Every opening bracket has a matching closing bracket.
* Brackets must close in the correct order.

---

## 🧠 Intuition

Opening brackets represent unfinished work.

When a closing bracket appears, it must match the most recently opened bracket.

This "most recent first" behavior is exactly what a Stack provides.

---

## 🎯 Pattern Recognition

Think Stack when you see:

* Balanced Brackets
* Nested Structures
* Syntax Validation
* XML/HTML Tag Matching
* Expression Parsing

Key Idea:

```text
Opening Bracket → Push
Closing Bracket → Match & Pop
```

---

## ⚙️ Approach

1. Create an empty stack.
2. Traverse the string.
3. If current character is an opening bracket:

   * Push it into the stack.
4. Otherwise:

   * If stack is empty → return false.
   * Check whether current closing bracket matches stack top.
   * If not matching → return false.
   * Otherwise pop the top element.
5. After traversal:

   * If stack is empty → valid.
   * Otherwise → invalid.

## ⚠️ Common Mistakes

### 1. Forgetting Empty Check

Wrong:

```cpp
if(st.top() != '(')
```

Input:

```text
)
```

Causes runtime error.

Always check:

```cpp
if(st.empty())
    return false;
```

first.

---

### 2. Forgetting Final Validation

Input:

```text
(((
```

No mismatch occurs.

But stack still contains elements.

Always:

```cpp
return st.empty();
```

---

### 3. Popping Before Matching

Wrong:

```cpp
st.pop();
```

before checking the bracket.

You lose the value you wanted to compare.

## 🎯 Key Takeaways

* Stack follows LIFO.
* Opening brackets are pushed.
* Closing brackets validate and pop.
* Always check for empty stack before using `top()`.
* Final stack must be empty.

---

## 💻 Implementation (C++)

```cpp
class Solution {
public:
    bool isValid(string s) {
        stack<char> st;

        for(char ch : s) {

            if(ch == '(' || ch == '{' || ch == '[') {
                st.push(ch);
            }
            else {

                if(st.empty())
                    return false;

                if(ch == ')' && st.top() != '(')
                    return false;

                if(ch == '}' && st.top() != '{')
                    return false;

                if(ch == ']' && st.top() != '[')
                    return false;

                st.pop();
            }
        }

        return st.empty();
    }
};
```

## ⏱️ Complexity Analysis

### Time Complexity

```text
O(n)
```

Each bracket is pushed and popped at most once.

### Space Complexity

```text
O(n)
```

In the worst case all opening brackets are stored in the stack.

Example:

```text
((((((
```
