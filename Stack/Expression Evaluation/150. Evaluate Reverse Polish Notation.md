# 150. Evaluate Reverse Polish Notation

| Topic | Difficulty | Pattern                                  |
| ----- | ---------- | ---------------------------------------- |
| Stack | Medium     | Stack Simulation / Expression Evaluation |

---

## 📌 Problem Description

Given an arithmetic expression in **Reverse Polish Notation (Postfix)**, evaluate the expression and return the final result.

Valid operators:

* `+`
* `-`
* `*`
* `/`

---

## 🧠 Intuition

In **Postfix notation**, every operator comes **after** its operands.

Example:

```text
2 1 +
```

means

```text
2 + 1
```

Instead of worrying about brackets and precedence, use a stack.

* Numbers → Push
* Operators → Pop two numbers, evaluate, push result back

---

## 🎯 Pattern Recognition

Keywords:

* Postfix Expression
* Reverse Polish Notation
* Expression Evaluation

---

## ⚙️ Approach

Traverse the tokens from left to right.

### If token is a number

Convert it into an integer using:

```cpp
stoi(token)
```

and push it into the stack.

---

### If token is an operator

Pop two numbers:

```cpp
a = st.top();
st.pop();

b = st.top();
st.pop();
```

Compute:

```text
b operator a
```

Push the result back into the stack.

## ⚠️ Common Mistakes

### 1. Wrong Operand Order

Wrong:

```cpp
a - b
```

Correct:

```cpp
b - a
```

The first popped element is the **right operand**.

---

### 2. Same Mistake for Division

Wrong:

```cpp
a / b
```

Correct:

```cpp
b / a
```

---

### 3. Calling stoi() Before Checking Operator

Wrong:

```cpp
stoi("+")
```

This causes a runtime error.

Always check whether the token is an operator first.

---

### 4. Using isdigit()

Negative numbers like:

```text
-11
```

are valid operands.

Checking only the first character with `isdigit()` fails.

Checking for the four operators first is much cleaner.

## 🎯 Key Takeaways

* Numbers are pushed onto the stack.
* Operators combine the top two operands.
* Always compute:

```text
second operator first
```

* Final answer remains on the top of the stack.

---

## 💻 Implementation (C++)

```cpp
class Solution {
public:
    int evalRPN(vector<string>& tokens) {

        stack<int> st;

        for(string token : tokens){

            if(token == "+" ||
               token == "-" ||
               token == "*" ||
               token == "/"){

                int a = st.top();
                st.pop();

                int b = st.top();
                st.pop();

                if(token == "+")
                    st.push(b + a);
                else if(token == "-")
                    st.push(b - a);
                else if(token == "*")
                    st.push(b * a);
                else
                    st.push(b / a);
            }
            else{
                st.push(stoi(token));
            }
        }

        return st.top();
    }
};
```

## ⏱️ Complexity Analysis

### Time Complexity

```text
O(n)
```

Each token is processed exactly once.

---

### Space Complexity

```text
O(n)
```

In the worst case, all operands are stored in the stack.
