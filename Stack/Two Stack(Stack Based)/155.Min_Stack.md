## 📌 Problem Description

Design a stack that supports the following operations in **O(1)** time:

```cpp
push(x)
pop()
top()
getMin()
```

`getMin()` should always return the minimum element currently present in the stack.

---

## 🧠 Intuition

A normal stack can return the top element in O(1), but finding the minimum requires traversing the entire stack.

Example:

```text
5
2
7
1
```

Minimum:

```text
1
```

Without extra information, finding the minimum costs:

```text
O(n)
```

The problem requires:

```text
getMin() -> O(1)
```

So we must keep track of minimum values while pushing and popping.

---

## 🎯 Pattern Recognition

This is not:

* Balanced Parentheses
* Monotonic Stack
* Next Greater Element

This is a:

```text
Stack Design Problem
```

Key Idea:

```text
Use an additional stack to track minimum values.
```

---

## ⚙️ Approach

Maintain two stacks:

### Main Stack

Stores all elements.

```text
5
2
7
1
```

---

### Min Stack

Stores current minimum values.

```text
5
2
1
```

---

### Push

Push element into main stack.

If:

```cpp
minSt.empty() || value <= minSt.top()
```

push it into min stack as well.

---

### Pop

Before removing from main stack:

Check:

```cpp
st.top() == minSt.top()
```

If true:

```cpp
minSt.pop()
```

Then remove from main stack.

---

### getMin

Minimum element is always:

```cpp
minSt.top()
```

## ⚠️ Common Mistakes

### 1. Checking minSt.top() Before Empty Check

Wrong:

```cpp
if(value < minSt.top() || minSt.empty())
```

May cause runtime error.

Correct:

```cpp
if(minSt.empty() || value <= minSt.top())
```

---

### 2. Ignoring Duplicate Minimums

Wrong:

```cpp
value < minSt.top()
```

Example:

```text
push(2)
push(2)
```

Second 2 is lost.

Use:

```cpp
value <= minSt.top()
```

---

### 3. Popping Main Stack First

Wrong:

```cpp
st.pop();

if(st.top() == minSt.top())
```

You lose the value that should be compared.

Always compare first.

## 🎯 Key Takeaways

* Normal Stack cannot provide minimum in O(1).
* Use a second stack to track minimum values.
* Push duplicate minimums as well.
* Compare before popping.
* `getMin()` becomes O(1).

---

## 💻 Implementation (C++)

```cpp
class MinStack {
private:
    stack<int> st;
    stack<int> minSt;

public:
    MinStack() {
    }

    void push(int value) {
        st.push(value);

        if(minSt.empty() || value <= minSt.top())
            minSt.push(value);
    }

    void pop() {
        if(st.top() == minSt.top())
            minSt.pop();

        st.pop();
    }

    int top() {
        return st.top();
    }

    int getMin() {
        return minSt.top();
    }
};
```
