# 1. Stack Using Array

## Idea

Use:

```text
arr[] → stores elements
top   → index of current top element
```

Initially:

```cpp
top = -1;
```

Meaning:

```text
Stack is empty
```

### Push

```text
Check full
    ↓
top++
    ↓
arr[top] = value
```

### Pop

```text
Check empty
    ↓
value = arr[top]
    ↓
top--
    ↓
return value
```

For a fixed-size array:

```text
Full  → top == SIZE - 1
Empty → top == -1
```

---

## Code

```cpp
#include <iostream>
using namespace std;

class Stack {
private:
    static const int SIZE = 5;

    int arr[SIZE];
    int top;

public:
    // Constructor
    Stack() {
        top = -1;
    }

    // Check if stack is empty
    bool isEmpty() {
        return top == -1;
    }

    // Check if stack is full
    bool isFull() {
        return top == SIZE - 1;
    }

    // Push
    void push(int value) {
        if (isFull()) {
            cout << "Stack Overflow\n";
            return;
        }

        arr[++top] = value;
    }

    // Pop
    int pop() {
        if (isEmpty()) {
            cout << "Stack Underflow\n";
            return -1;
        }

        return arr[top--];
    }

    // Peek
    int peek() {
        if (isEmpty()) {
            cout << "Stack is empty\n";
            return -1;
        }

        return arr[top];
    }

    // Display
    void display() {
        if (isEmpty()) {
            cout << "Stack is empty\n";
            return;
        }

        for (int i = top; i >= 0; i--) {
            cout << arr[i] << " ";
        }

        cout << "\n";
    }
};

int main() {

    Stack st;

    st.push(10);
    st.push(20);
    st.push(30);
    st.push(40);

    cout << "Stack: ";
    st.display();

    cout << "Top: " << st.peek() << "\n";

    cout << "Popped: " << st.pop() << "\n";
    cout << "Popped: " << st.pop() << "\n";

    cout << "Stack after pop: ";
    st.display();

    return 0;
}
```

---

## Output

```text
Stack: 40 30 20 10
Top: 40
Popped: 40
Popped: 30
Stack after pop: 20 10
```

---

## Array Stack Complexity

| Operation   | Time | Extra Space |
| ----------- | ---: | ----------: |
| `push()`    | O(1) |        O(1) |
| `pop()`     | O(1) |        O(1) |
| `peek()`    | O(1) |        O(1) |
| `isEmpty()` | O(1) |        O(1) |
| `isFull()`  | O(1) |        O(1) |

Overall storage:

```text
O(n)
```

# 2. Stack Using Linked List

## Idea

Use the **head node as the TOP**.

```text
TOP
 ↓
40 → 30 → 20 → 10 → NULL
```

Why head?

Because insertion and deletion at the head are both:

```text
O(1)
```

---

## Push

Create a new node:

```text
Before:

TOP
 ↓
30 → 20 → 10

push(40)

After:

TOP
 ↓
40 → 30 → 20 → 10
```

Logic:

```cpp
newNode->next = top;
top = newNode;
```

---

## Pop

Remove the head:

```text
Before:

TOP
 ↓
40 → 30 → 20 → 10

pop()

After:

TOP
 ↓
30 → 20 → 10
```

Logic:

```cpp
Node* temp = top;
top = top->next;
delete temp;
```

---

## Code

```cpp
#include <iostream>
using namespace std;

class Stack {

private:

    struct Node {
        int data;
        Node* next;

        Node(int value) {
            data = value;
            next = nullptr;
        }
    };

    Node* top;

public:

    // Constructor
    Stack() {
        top = nullptr;
    }

    // Destructor
    ~Stack() {
        while (!isEmpty()) {
            pop();
        }
    }

    // Check if stack is empty
    bool isEmpty() {
        return top == nullptr;
    }

    // Push
    void push(int value) {

        Node* newNode = new Node(value);

        newNode->next = top;
        top = newNode;
    }

    // Pop
    int pop() {

        if (isEmpty()) {
            cout << "Stack Underflow\n";
            return -1;
        }

        Node* temp = top;

        int value = top->data;

        top = top->next;

        delete temp;

        return value;
    }

    // Peek
    int peek() {

        if (isEmpty()) {
            cout << "Stack is empty\n";
            return -1;
        }

        return top->data;
    }

    // Display
    void display() {

        if (isEmpty()) {
            cout << "Stack is empty\n";
            return;
        }

        Node* current = top;

        while (current != nullptr) {

            cout << current->data << " ";

            current = current->next;
        }

        cout << "\n";
    }
};

int main() {

    Stack st;

    st.push(10);
    st.push(20);
    st.push(30);
    st.push(40);

    cout << "Stack: ";
    st.display();

    cout << "Top: " << st.peek() << "\n";

    cout << "Popped: " << st.pop() << "\n";
    cout << "Popped: " << st.pop() << "\n";

    cout << "Stack after pop: ";
    st.display();

    return 0;
}
```

---

## Output

```text
Stack: 40 30 20 10
Top: 40
Popped: 40
Popped: 30
Stack after pop: 20 10
```

# 3. Linked List Stack Complexity

| Operation   | Time | Extra Space |
| ----------- | ---: | ----------: |
| `push()`    | O(1) |        O(1) |
| `pop()`     | O(1) |        O(1) |
| `peek()`    | O(1) |        O(1) |
| `isEmpty()` | O(1) |        O(1) |

Overall storage:

```text
O(n)
```

Each node additionally requires memory for the `next` pointer.

---

# 4. Array vs Linked List

|                | Array Stack      | Linked List Stack |
| -------------- | ---------------- | ----------------- |
| Top tracking   | Index            | Pointer           |
| Empty          | `top == -1`      | `top == nullptr`  |
| Push           | `arr[++top] = x` | Add node at head  |
| Pop            | `arr[top--]`     | Remove head       |
| Size           | Fixed normally   | Dynamic           |
| Push           | O(1)             | O(1)              |
| Pop            | O(1)             | O(1)              |
| Extra pointer  | No               | Yes               |
| Cache locality | Better           | Worse             |
| Capacity       | Fixed normally   | Dynamic           |

# 6. EY Interview Questions From These Implementations

Be able to explain:

### Q1. Why is `top = -1` initially?

Because array indexing starts at `0`, and `-1` represents an empty stack.

### Q2. Why is the linked-list head used as `top`?

Because insertion and deletion at the head are O(1).

### Q3. Why not insert at the tail?

A singly linked list would need traversal to reach the tail:

```text
O(n)
```

That would make `push()` unnecessarily expensive.

### Q4. When does array stack overflow?

```text
top == SIZE - 1
```

### Q5. When does linked-list stack overflow?

There is no fixed capacity. Allocation fails when available memory is exhausted.

### Q6. Why do we `delete temp` after pop?

To release the dynamically allocated node and avoid a memory leak.

### Q7. What happens to the old array value after `pop()`?

The value remains physically in the array, but it is no longer considered part of the stack because `top` moved down.

### Q8. Can push/pop be O(1) in both implementations?

Yes.

```text
Array       → O(1)
Linked List → O(1)
```
