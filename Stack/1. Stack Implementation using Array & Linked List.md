# Stack — Basic Implementations

## 1. Implement Stack Using Array

### Idea

Use:

```cpp
int arr[MAX];
int top = -1;
```

`top` stores the index of the current top element.

```text
Initially:

top = -1

Empty stack
```

### Push

```text
top++;
arr[top] = value;
```

### Pop

```text
arr[top]
top--;
```

### Conditions

```text
Empty:
top == -1

Full:
top == MAX - 1
```

---

## Code

```cpp
#include <iostream>
using namespace std;

class Stack {
private:
    int arr[100];
    int top;

public:
    Stack() {
        top = -1;
    }

    void push(int x) {
        if (top == 99) {
            cout << "Stack Overflow\n";
            return;
        }

        top++;
        arr[top] = x;
    }

    void pop() {
        if (top == -1) {
            cout << "Stack Underflow\n";
            return;
        }

        top--;
    }

    int peek() {
        if (top == -1) {
            cout << "Stack is Empty\n";
            return -1;
        }

        return arr[top];
    }

    bool isEmpty() {
        return top == -1;
    }
};

int main() {
    Stack st;

    st.push(10);
    st.push(20);
    st.push(30);

    cout << "Top: " << st.peek() << endl;

    st.pop();

    cout << "Top: " << st.peek() << endl;

    return 0;
}
```

### Output

```text
Top: 30
Top: 20
```

---

## Complexity

| Operation | Time | Space |
| --------- | ---: | ----: |
| Push      | O(1) |  O(1) |
| Pop       | O(1) |  O(1) |
| Peek      | O(1) |  O(1) |
| isEmpty   | O(1) |  O(1) |

Overall stack storage:

```text
O(n)
```

# 2. Implement Stack Using Linked List

### Idea

Use the **head node as TOP**.

```text
TOP
 ↓
30 → 20 → 10 → NULL
```

Why head?

Because insertion and deletion at the head are:

```text
O(1)
```

---

## Node Structure

```cpp
struct Node {
    int data;
    Node* next;
};
```

`top` points to the first node.

```cpp
Node* top = nullptr;
```

---

## Push

Insert at the beginning.

```text
Before:

TOP
 ↓
20 → 10 → NULL


push(30)


After:

TOP
 ↓
30 → 20 → 10 → NULL
```

---

## Pop

Delete the first node.

```text
Before:

TOP
 ↓
30 → 20 → 10 → NULL


pop()


After:

TOP
 ↓
20 → 10 → NULL
```

---

## Code

```cpp
#include <iostream>
using namespace std;

struct Node {
    int data;
    Node* next;

    Node(int x) {
        data = x;
        next = nullptr;
    }
};

class Stack {
private:
    Node* top;

public:
    Stack() {
        top = nullptr;
    }

    void push(int x) {
        Node* newNode = new Node(x);

        newNode->next = top;
        top = newNode;
    }

    void pop() {
        if (top == nullptr) {
            cout << "Stack Underflow\n";
            return;
        }

        Node* temp = top;
        top = top->next;

        delete temp;
    }

    int peek() {
        if (top == nullptr) {
            cout << "Stack is Empty\n";
            return -1;
        }

        return top->data;
    }

    bool isEmpty() {
        return top == nullptr;
    }
};

int main() {
    Stack st;

    st.push(10);
    st.push(20);
    st.push(30);

    cout << "Top: " << st.peek() << endl;

    st.pop();

    cout << "Top: " << st.peek() << endl;

    return 0;
}
```

### Output

```text
Top: 30
Top: 20
```

# 3. Array vs Linked List Implementation

|              | Array Stack        | Linked List Stack          |
| ------------ | ------------------ | -------------------------- |
| TOP          | Index              | Pointer                    |
| Push         | `top++`            | Add at head                |
| Pop          | `top--`            | Delete head                |
| Push         | O(1)               | O(1)                       |
| Pop          | O(1)               | O(1)                       |
| Size         | Fixed normally     | Dynamic                    |
| Extra memory | Low                | Pointer per node           |
| Overflow     | When array is full | When memory is unavailable |

### Simple rule

```text
Known/fixed maximum size
        ↓
      Array

Unknown/dynamic size
        ↓
   Linked List
```

# 4. What You Must Be Able to Write From Memory

### Array

```cpp
top = -1;

push:
top++;
arr[top] = x;

pop:
top--;

peek:
arr[top];
```

### Linked List

```cpp
push:
newNode->next = top;
top = newNode;

pop:
temp = top;
top = top->next;
delete temp;
```

### Conditions

```text
Array:

empty → top == -1
full  → top == MAX - 1


Linked List:

empty → top == nullptr
```

# 5. EY Interview Explanation

If the interviewer asks:

> "How would you implement a stack?"

Say:

> "I can implement it using an array or linked list. With an array, I maintain a `top` index initialized to `-1`. Push increments `top` and inserts the element, while pop removes the element at `top` and decrements it. Both operations are O(1). With a linked list, I use the head as the top and insert or delete at the head, which also gives O(1) push and pop."

That's enough. Don't over-explain unless they ask.
