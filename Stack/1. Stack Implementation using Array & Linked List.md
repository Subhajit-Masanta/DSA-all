# Stack Implementation — Array & Linked List

## 1. Stack Using Array

### Idea

Use:

```cpp
int arr[capacity];
int top = -1;
```

`top` stores the **index of the current top element**.

Initially:

```text
top = -1
```

because the stack is empty.

### Array Representation

```text
capacity = 5

Index:    0    1    2    3    4
         [10] [20] [30] [40] [  ]
                         ↑
                        top

top = 3
```

---

## Push

To insert an element:

1. Check if stack is full.
2. Increment `top`.
3. Insert at `arr[top]`.

```cpp
top++;
arr[top] = x;
```

Short form:

```cpp
arr[++top] = x;
```

### Example

```text
Initially:

top = -1

push(10)

top++  → 0
arr[0] = 10

push(20)

top++  → 1
arr[1] = 20

push(30)

top++  → 2
arr[2] = 30
```

Result:

```text
Index:    0    1    2
         [10] [20] [30]
                    ↑
                   top
```

### Complexity

```text
Time  → O(1)
Space → O(1) auxiliary
```

---

## Pop

To remove the top element:

1. Check if stack is empty.
2. Store `arr[top]`.
3. Decrement `top`.

```cpp
int x = arr[top];
top--;
return x;
```

Short form:

```cpp
return arr[top--];
```

### Example

```text
Before:

[10] [20] [30]
          ↑
         top

pop()

x = arr[2] → 30
top--      → 1
```

Now:

```text
[10] [20]
      ↑
     top
```

The value `30` is logically removed because `top` no longer points to it.

### Complexity

```text
Time  → O(1)
Space → O(1)
```

---

## Peek

Return the top element without removing it.

```cpp
return arr[top];
```

```text
[10] [20] [30]
          ↑
        top()

returns 30

Stack remains unchanged.
```

Complexity:

```text
O(1)
```

---

## IsEmpty

```cpp
return top == -1;
```

---

## IsFull

For capacity `n`:

```cpp
return top == n - 1;
```

---

# Complete Array Implementation

```cpp
#include <iostream>
using namespace std;

class Stack {
private:
    int *arr;
    int capacity;
    int top;

public:
    Stack(int size) {
        capacity = size;
        arr = new int[capacity];
        top = -1;
    }

    // Push element
    void push(int x) {
        // Overflow condition
        if (top == capacity - 1) {
            cout << "Stack Overflow\n";
            return;
        }

        // Increment top, then insert
        top++;
        arr[top] = x;
    }

    // Pop element
    int pop() {
        // Underflow condition
        if (top == -1) {
            cout << "Stack Underflow\n";
            return -1;
        }

        // Store top element
        int x = arr[top];

        // Move top down
        top--;

        return x;
    }

    // Return top element
    int peek() {
        if (top == -1) {
            cout << "Stack is Empty\n";
            return -1;
        }

        return arr[top];
    }

    // Check empty
    bool isEmpty() {
        return top == -1;
    }

    // Check full
    bool isFull() {
        return top == capacity - 1;
    }

    // Current size
    int size() {
        return top + 1;
    }

    ~Stack() {
        delete[] arr;
    }
};

int main() {

    Stack st(5);

    st.push(10);
    st.push(20);
    st.push(30);
    st.push(40);
    st.push(50);

    cout << "Top: " << st.peek() << endl;

    cout << "Popped: " << st.pop() << endl;

    cout << "Top: " << st.peek() << endl;

    cout << "Size: " << st.size() << endl;

    return 0;
}
```

# 2. Stack Using Linked List

### Idea

Use the **head of the linked list as TOP**.

```text
TOP
 ↓
30 → 20 → 10 → NULL
```

Why head?

Because insertion and deletion at the head are both `O(1)`.

---

# Node Structure

```cpp
class Node {
public:
    int data;
    Node* next;

    Node(int x) {
        data = x;
        next = nullptr;
    }
};
```

---

# Push

To push `30`:

```text
Before:

TOP
 ↓
20 → 10 → NULL
```

Create:

```text
30
```

Connect it:

```text
30 → 20 → 10 → NULL
```

Update `top`:

```text
TOP
 ↓
30 → 20 → 10 → NULL
```

### Code

```cpp
Node* temp = new Node(x);

temp->next = top;
top = temp;
```

### The 2 important lines

```cpp
temp->next = top;
top = temp;
```

Remember:

> **New node points to old top → top moves to new node**

Complexity:

```text
O(1)
```

---

# Pop

Before:

```text
TOP
 ↓
30 → 20 → 10 → NULL
```

Steps:

```cpp
Node* temp = top;
top = top->next;
delete temp;
```

After:

```text
TOP
 ↓
20 → 10 → NULL
```

### Logic

```text
1. Save old top
2. Move top to next node
3. Delete old top
```

Complexity:

```text
O(1)
```

---

# Peek

```cpp
return top->data;
```

No node is removed.

Complexity:

```text
O(1)
```

---

# IsEmpty

```cpp
return top == nullptr;
```

---

# Complete Linked List Implementation

```cpp
#include <iostream>
using namespace std;

class Node {
public:
    int data;
    Node* next;

    Node(int x) {
        data = x;
        next = nullptr;
    }
};

class Stack {
private:
    Node* top;
    int count;

public:
    Stack() {
        top = nullptr;
        count = 0;
    }

    // Push element
    void push(int x) {

        Node* temp = new Node(x);

        // New node points to old top
        temp->next = top;

        // New node becomes top
        top = temp;

        count++;
    }

    // Pop element
    int pop() {

        // Underflow
        if (top == nullptr) {
            cout << "Stack Underflow\n";
            return -1;
        }

        // Store old top
        Node* temp = top;

        // Move top to next node
        top = top->next;

        // Store value before deleting node
        int x = temp->data;

        // Free memory
        delete temp;

        count--;

        return x;
    }

    // Return top element
    int peek() {

        if (top == nullptr) {
            cout << "Stack is Empty\n";
            return -1;
        }

        return top->data;
    }

    // Check empty
    bool isEmpty() {
        return top == nullptr;
    }

    // Current size
    int size() {
        return count;
    }
};

int main() {

    Stack st;

    st.push(10);
    st.push(20);
    st.push(30);
    st.push(40);

    cout << "Top: " << st.peek() << endl;

    cout << "Popped: " << st.pop() << endl;

    cout << "Top: " << st.peek() << endl;

    cout << "Size: " << st.size() << endl;

    return 0;
}
```

# 3. Array vs Linked List — Code Logic

## Array

### Push

```cpp
if (top == capacity - 1)
    overflow;

top++;
arr[top] = x;
```

Think:

```text
CHECK → top++ → INSERT
```

### Pop

```cpp
if (top == -1)
    underflow;

x = arr[top];
top--;
return x;
```

Think:

```text
READ → top--
```

---

## Linked List

### Push

```cpp
Node* temp = new Node(x);

temp->next = top;
top = temp;
```

Think:

```text
CREATE → CONNECT → MOVE TOP
```

### Pop

```cpp
Node* temp = top;

top = top->next;

delete temp;
```

Think:

```text
SAVE → MOVE TOP → DELETE
```

---

# 4. Complexity

| Operation | Array | Linked List |
| --------- | ----: | ----------: |
| Push      |  O(1) |        O(1) |
| Pop       |  O(1) |        O(1) |
| Peek      |  O(1) |        O(1) |
| IsEmpty   |  O(1) |        O(1) |
| Size      |  O(1) |       O(1)* |
| Memory    |  O(n) |        O(n) |

`size()` is `O(1)` here because we maintain `count`.

You don't need to memorize the entire class. Understand these.

## Array

```cpp
// PUSH

top--;

arr[top];
```

Or:

```cpp
arr[++top] = x;
return arr[top--];
```

---

## Linked List

```cpp
// PUSH
Node* temp = new Node(x);
temp->next = top;
top = temp;
```

```cpp
// POP
Node* temp = top;
top = top->next;
int x = temp->data;
delete temp;
return x;
```

# 6. EY Focus

For EY, you should be able to **write both implementations from scratch without looking**.

### Must know

```text
✓ Array implementation
✓ Linked List implementation
✓ push()
✓ pop()
✓ peek()
✓ isEmpty()
✓ Overflow / Underflow
✓ O(1) push/pop
✓ Why Linked List uses head as TOP
✓ Why top starts at -1 in array
```

The standard interview implementations also use `top = -1` for an empty array stack and insert with `++top`; linked-list implementations use a pointer to the top node and push at the head.

### Your key mental model

```text
ARRAY STACK

top = -1

PUSH:
top++
arr[top] = x

POP:
x = arr[top]
top--


LINKED LIST STACK

PUSH:
new node
new->next = top
top = new

POP:
temp = top
top = top->next
delete temp
```

If you can reproduce **those two blocks** on a whiteboard/editor, the implementation part of Stack is done.
