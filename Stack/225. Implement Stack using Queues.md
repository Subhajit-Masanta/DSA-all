# 225. Implement Stack using Queues

| Topic | Difficulty | Pattern                         |
| ----- | ---------- | ------------------------------- |
| Stack | Easy       | Stack Simulation / Queue Design |

---

## 📌 Problem Description

Implement a **Stack (LIFO)** using only **Queues (FIFO)**.

Implement the following operations:

* `push(x)`
* `pop()`
* `top()`
* `empty()`

Only standard queue operations are allowed.

---

## 🧠 Intuition

A queue removes elements from the **front**.

A stack removes elements from the **top (last inserted)**.

To simulate a stack, every new element should become the **front** of the queue.

## ⚙️ Approach (Two Queues)

Maintain two queues:

```cpp
q1
q2
```

### Push

1. Push new element into `q2`.
2. Move all elements of `q1` into `q2`.
3. Swap `q1` and `q2`.

Now the newest element is always at the front of `q1`.

---

### Pop

Simply remove the front of `q1`.

---

### Top

Return the front of `q1`.

---

### Empty

Return:

```cpp
q1.empty()
```

## ⚠️ Common Mistakes

### 1. Forgetting to Move Existing Elements

Wrong:

```cpp
q2.push(x);
swap(q1,q2);
```

Existing elements must also be moved into `q2`.

---

### 2. Forgetting to Swap

After moving elements:

```cpp
swap(q1,q2);
```

Otherwise `q1` remains empty.

---

### 3. Using Stack Internally

The problem only allows queues.

## 🎯 Key Takeaways

* Convert FIFO into LIFO by reordering during insertion.
* Keep the newest element at the front.
* Pop and Top become **O(1)**.
* Push becomes **O(n)**.

---

## 💻 Implementation (C++)

```cpp
class MyStack {
public:
    queue<int> q1;
    queue<int> q2;

    MyStack() {}

    void push(int x) {

        q2.push(x);

        while(!q1.empty()) {
            q2.push(q1.front());
            q1.pop();
        }

        swap(q1, q2);
    }

    int pop() {
        int val = q1.front();
        q1.pop();
        return val;
    }

    int top() {
        return q1.front();
    }

    bool empty() {
        return q1.empty();
    }
};
```
