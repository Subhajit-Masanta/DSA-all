# CYCLE DETECTION — EY GDS

## 1. What is a Cycle?

A **cycle** exists when we can start from a vertex and follow edges to eventually come back to that vertex.

Example:

```text
A → B → C → A
```

This is a cycle.

---

# 2. Undirected Graph

Example:

```text
A ----- B
|       |
|       |
C ----- D
```

There is a cycle:

```text
A → B → D → C → A
```

### DFS Idea

While doing DFS, keep track of the **parent** of the current node.

Suppose:

```text
A
|
B
```

When DFS goes:

```text
A → B
```

B sees A as already visited.

But that's **not a cycle** because A is simply B's parent.

So:

```text
visited[neighbor] == true
AND
neighbor != parent
```

means:

```text
CYCLE FOUND
```

### Core Logic

```text
DFS(node, parent)

for every neighbor:

    if neighbor is not visited:
        DFS(neighbor, node)

    else if neighbor != parent:
        cycle exists
```

### Why parent is needed?

Because in an undirected graph:

```text
A -- B
```

is stored as:

```text
A → B
B → A
```

So when B sees A again, that's just the same edge going backwards.

---

# 3. Directed Graph

Example:

```text
A → B → C
    ↑   |
    |___|
```

Cycle:

```text
B → C → B
```

Here **parent tracking is not enough**.

We need to know whether a node is currently part of the **active DFS path**.

Use 3 states:

```text
0 → Unvisited
1 → Currently in DFS path
2 → Completely processed
```

### DFS Idea

Suppose:

```text
A → B → C → A
```

During DFS:

```text
A = 1
B = 1
C = 1
```

C sees:

```text
A = 1
```

A is already in the **current DFS path**.

Therefore:

```text
CYCLE FOUND
```

### Core Logic

```text
DFS(node)

state[node] = 1

for every neighbor:

    if state[neighbor] == 0:
        DFS(neighbor)

    else if state[neighbor] == 1:
        cycle exists

state[node] = 2
```

---

# 4. Undirected vs Directed

|                   | Undirected                | Directed                     |
| ----------------- | ------------------------- | ---------------------------- |
| Main idea         | Track parent              | Track current DFS path       |
| Extra information | `parent`                  | 3 states / recursion stack   |
| Cycle condition   | Visited neighbor ≠ parent | Neighbor is currently active |
| Typical method    | DFS / DSU                 | DFS                          |

# 5. DSU Method — Undirected Graph

DSU can also detect cycles in an **undirected graph**.

For every edge:

```text
u -- v
```

Check:

```text
find(u) == find(v)
```

If true:

```text
u and v are already connected
→ adding this edge creates a cycle
```

Otherwise:

```text
union(u, v)
```

### Example

```text
A -- B
B -- C
A -- C
```

After processing:

```text
A-B → union
B-C → union
A-C → A and C already in same set
       ↓
     CYCLE
```

# 6. EY Memory Trick

```text
UNDIRECTED
→ DFS + Parent
→ or DSU

DIRECTED
→ DFS + 3 States
→ active node (state 1) = cycle
```

### One-line rule

```text
Undirected: visited + not parent → cycle

Directed: edge to currently visiting node → cycle
```
