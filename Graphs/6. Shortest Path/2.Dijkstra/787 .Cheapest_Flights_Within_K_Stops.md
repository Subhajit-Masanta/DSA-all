# 📌 Problem Description

You are given

```cpp
n
```

cities connected by directed flights.

Each flight is represented as

```cpp
from → to (price)
```

You are given

- Source city
- Destination city
- Maximum number of stops `k`

Return the **minimum cost** required to travel from

```text
src
```

to

```text
dst
```

using **at most `k` stops**.

If no such path exists,

return

```text
-1
```

# 🧠 Intuition

At first glance,

this looks like a normal Dijkstra problem because

- Weighted Graph
- Minimum Cost

But there is an extra constraint.

```text
Maximum K Stops
```

Normal Dijkstra only minimizes

```text
Cost
```

This problem asks us to minimize

```text
Cost

Subject to

Stops ≤ K
```

Instead of processing nodes by **minimum cost**,

we process states by

```text
Number of Stops Used
```

using BFS.

---

# Key Observation

BFS naturally explores

```text
0 Stops

↓

1 Stop

↓

2 Stops

↓

3 Stops
```

Each BFS level represents

```text
One More Stop
```

Therefore,

we store inside the queue

```text
(Stops Used, Node, Current Cost)
```

Example

```cpp
(2,4,350)
```

means

```text
Reached Node 4

Cost = 350

Stops Used = 2
```

---

We still maintain

```cpp
dist[node]
```

which stores

```text
Minimum Cost Found So Far
```

Whenever

```cpp
newCost < dist[neighbour]
```

we update

```cpp
dist[neighbour]
```

and push the new state.

---

# Algorithm

```text
Build Adjacency List

↓

Distance Array = INF

↓

dist[src] = 0

↓

Push (0,src,0)

↓

While Queue Not Empty

↓

Pop Front

↓

Stops > K ?

↓

Continue

↓

Traverse All Neighbours

↓

newCost = cost + edgeWeight

↓

Better than dist?

↓

Update Distance

↓

Push

(stops+1, neighbour, newCost)

↓

Queue Empty

↓

Return dist[dst]

Otherwise

↓

Return -1
```

# Code

```cpp
class Solution {
public:

    int findCheapestPrice(int n,
                          vector<vector<int>>& flights,
                          int src,
                          int dst,
                          int k)
    {
        vector<vector<pair<int,int>>> adj(n);

        for(auto &flight : flights)
        {
            int u = flight[0];
            int v = flight[1];
            int cost = flight[2];

            adj[u].push_back({v,cost});
        }

        vector<int> dist(n, INT_MAX);

        dist[src] = 0;

        queue<tuple<int,int,int>> q;

        q.push({0,src,0});

        while(!q.empty())
        {
            auto [stops,node,cost] = q.front();
            q.pop();

            if(stops > k)
                continue;

            for(auto [neighbour,wt] : adj[node])
            {
                int newCost = cost + wt;

                if(newCost < dist[neighbour])
                {
                    dist[neighbour] = newCost;

                    q.push({stops+1,
                            neighbour,
                            newCost});
                }
            }
        }

        return dist[dst] == INT_MAX ? -1 : dist[dst];
    }
};
```

# Why BFS Works?

The restriction is

```text
At Most K Stops
```

BFS naturally processes nodes

```text
Level by Level
```

where each level represents one additional stop.

Unlike normal BFS,

we **do not use visited[]**

because a node can later be reached with a lower cost.

Instead,

we only continue exploring if

```cpp
newCost < dist[neighbour]
```

Thus,

BFS guarantees that every valid stop count is explored,

while

```cpp
dist[]
```

keeps only the cheapest path found so far.

# Common Mistakes

## ❌ Using Priority Queue

This problem is solved using **Queue (BFS)** because the constraint is on **stops**, not on cost.

---

## ❌ Using visited[]

Wrong

```cpp
visited[node]=true;
```

A cheaper path may reach the same node later.

---

## ❌ Returning Immediately When Destination Appears

Wrong

```cpp
if(node==dst)
    return cost;
```

Queue is **not sorted by cost**.

A later state may have a smaller cost.

---

## ❌ Incrementing Stops Variable

Wrong

```cpp
stops++;

q.push({stops,...});
```

Correct

```cpp
q.push({stops+1,
        neighbour,
        newCost});
```

---

## ❌ Pushing Outside Relaxation

Wrong

```cpp
if(newCost < dist[v])
    dist[v]=newCost;

q.push(...);
```

Correct

```cpp
if(newCost < dist[v])
{
    dist[v]=newCost;

    q.push(...);
}
```

# Complexity

| Complexity | Value |
|------------|-------|
| Time | **O(E × K)** |
| Auxiliary Space | **O(V + E)** |

### Why?

- Each flight can be relaxed at most `K + 1` times.
- Queue stores valid states only.
- Adjacency list stores all edges.

---

# Key Takeaways

- This is **not normal Dijkstra**.
- BFS explores paths **level by level (stops)**.
- Queue stores

```cpp
(Stops, Node, Cost)
```

- `dist[node]` stores the **minimum cost** found so far.
- Do **not** use `visited[]`.
- Do **not** return immediately after reaching the destination.
- Relax neighbours exactly like Dijkstra.
- Ignore any state where

```cpp
stops > k
```

- Return

```cpp
dist[dst]
```

if reachable; otherwise return

```cpp
-1
```
