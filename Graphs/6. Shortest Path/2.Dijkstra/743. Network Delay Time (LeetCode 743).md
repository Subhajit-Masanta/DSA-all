| Topic | Difficulty | Pattern |
|--------|------------|---------|
| Graph | Medium | Dijkstra (Directed Graph) |

# Problem

Given a **directed weighted graph**, a signal starts from node `k`.

Return the **minimum time** required for **all nodes** to receive the signal.

If any node cannot be reached,

```text
return -1
```

---

# Key Observation

The signal starts from

```text
Source = k
```

Dijkstra gives

```text
Shortest Time

from k

to every node
```

The network finishes only when

```text
The Last Node

receives the signal.
```

Therefore,

```text
Answer

=

Maximum Shortest Distance
```

---

# Why Maximum Distance?

Suppose Dijkstra returns

```text
Node 1 → 0

Node 2 → 2

Node 3 → 4

Node 4 → 7
```

Timeline

```text
t = 0

Node 1
```

```text
t = 2

Node 2
```

```text
t = 4

Node 3
```

```text
t = 7

Node 4
```

When has **every node** received the signal?

```text
7
```

So

```text
Answer = max(dist[])
```

---

# What if Some Node is Unreachable?

Example

```text
dist =

0

2

INF

5
```

`INF` means

```text
Never Reached
```

So the answer is

```text
-1
```

---

# Algorithm

```text
Build Directed Adjacency List

↓

Run Dijkstra

↓

If any node has distance = INF

↓

Return -1

↓

Otherwise

↓

Return Maximum Distance
```

# Implementation Pattern

```cpp
vector<vector<pair<int,int>>> adj(n+1);

for(auto edge : times)
{
    adj[edge[0]].push_back({edge[1], edge[2]});
}

vector<int> dist(n+1, INT_MAX);

dist[k] = 0;

priority_queue<
pair<int,int>,
vector<pair<int,int>>,
greater<pair<int,int>>
> pq;

pq.push({0,k});

while(!pq.empty())
{
    auto [currDist,node] = pq.top();
    pq.pop();

    if(currDist > dist[node])
        continue;

    for(auto [neigh,wt] : adj[node])
    {
        if(dist[neigh] > currDist + wt)
        {
            dist[neigh] = currDist + wt;
            pq.push({dist[neigh], neigh});
        }
    }
}

int ans = 0;

for(int i=1;i<=n;i++)
{
    if(dist[i] == INT_MAX)
        return -1;

    ans = max(ans, dist[i]);
}

return ans;
```

# Common Mistakes

## ❌ Creating graph of size `n`

Nodes are

```text
1 ... n
```

Always create

```cpp
vector<vector<pair<int,int>>> adj(n+1);

vector<int> dist(n+1);
```

---

## ❌ Forgetting

```cpp
pq.pop();
```

Always pop after reading the top element.

---

## ❌ Wrong stale check

Correct

```cpp
if(currDist > dist[node])
    continue;
```

Not

```cpp
if(dist[node] > currDist)
```

---

## ❌ Returning Maximum Directly

If any node has

```text
INT_MAX
```

return

```text
-1
```

before computing the maximum.

---

## ❌ Treating Graph as Undirected

Only add

```cpp
adj[u].push_back({v,wt});
```

Do **not** add

```cpp
adj[v].push_back({u,wt});
```

because the graph is directed.

---

# Key Takeaways

- This is a direct application of Dijkstra.
- The graph is **directed**.
- Dijkstra gives the shortest time to every node.
- The answer is the **maximum** shortest distance.
- If any node is unreachable (`INT_MAX`), return `-1`.
- Skip stale priority queue entries using

```cpp
if(currDist > dist[node])
    continue;
```

- Time Complexity:

```text
O((V + E) log V)
```
