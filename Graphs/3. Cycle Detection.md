# 📌 Problem Description

You are given an **undirected graph**.

The graph is already stored as an **adjacency list**.

```cpp
graph[u]
```

means

```text
Neighbours of node u
```

Example

```cpp
graph = [[1,3],[0,2],[1,3],[0,2]]
```

means

```text
0 → 1,3

1 → 0,2

2 → 1,3

3 → 0,2
```

Graph

```text
        0
      /   \
     1     3
      \   /
        2
```

---

# What is Bipartite?

A graph is Bipartite if we can divide all nodes into **two groups**

```text
Group A

Group B
```

such that

```text
Every Edge

A ←→ B
```

and never

```text
A ←→ A

or

B ←→ B
```

Instead of thinking about groups,

think about

```text
Red

Blue
```

Every neighbour must have

```text
Opposite Color
```

Instead of

```text

```



- Visited
- Color

# DFS Algorithm

```text
Start DFS

↓

Current Node already has color

↓

Visit every neighbour

↓

Neighbour not colored?

↓

Give opposite color

↓

DFS

↓

Neighbour already colored?

↓

Same Color?

↓

Return false

↓

Finished all nodes

↓

Return true
```

---

# DFS Code

```cpp
class Solution {
public:

    bool dfs(int node,
             vector<vector<int>>& graph,
             vector<int>& color)
    {
        for(int neighbour : graph[node])
        {
            if(color[neighbour] == -1)
            {
                color[neighbour] = 1 - color[node];

                if(!dfs(neighbour, graph, color))
                    return false;
            }
            else
            {
                if(color[neighbour] == color[node])
                    return false;
            }
        }

        return true;
    }

    bool isBipartite(vector<vector<int>>& graph)
    {
        int n = graph.size();

        vector<int> color(n,-1);

        for(int i=0;i<n;i++)
        {
            if(color[i] == -1)
            {
                color[i] = 0;

                if(!dfs(i, graph, color))
                    return false;
            }
        }

        return true;
    }
};
```

# BFS Algorithm

```text
Choose one node

↓

Color Red

↓

Push into Queue

↓

Pop

↓

Visit neighbours

↓

Neighbour not colored?

↓

Give opposite color

↓

Push

↓

Neighbour already colored?

↓

Same Color?

↓

Return false

↓

Queue Empty

↓

Next Component

↓

Return true
```

---

# BFS Code

```cpp
class Solution {
public:

    bool bfs(int start,
             vector<vector<int>>& graph,
             vector<int>& color)
    {
        queue<int> q;

        q.push(start);

        color[start] = 0;

        while(!q.empty())
        {
            int node = q.front();
            q.pop();

            for(int neighbour : graph[node])
            {
                if(color[neighbour] == -1)
                {
                    color[neighbour] = 1 - color[node];

                    q.push(neighbour);
                }
                else
                {
                    if(color[neighbour] == color[node])
                        return false;
                }
            }
        }

        return true;
    }

    bool isBipartite(vector<vector<int>>& graph)
    {
        int n = graph.size();

        vector<int> color(n,-1);

        for(int i=0;i<n;i++)
        {
            if(color[i] == -1)
            {
                if(!bfs(i, graph, color))
                    return false;
            }
        }

        return true;
    }
};
```

# Common Mistakes

## ❌ Using visited[]

Need colors, not just visited.

---

## ❌ Using bool for color

```cpp
vector<bool>
```

cannot represent

```text
Not Visited

Red

Blue
```

Need

```cpp
vector<int> color(n,-1);
```

---

## ❌ Forgetting disconnected graph

Always use

```cpp
for(int i=0;i<n;i++)
```

---

## ❌ Coloring current node again

Current node is already colored.

Only color

```text
Neighbours
```

---

## ❌ Same color check

Wrong

```text
Red ----- Red
```

Immediately return

```text
false
```

# Complexity

| Complexity | Value |
|------------|-------|
| Time | **O(V + E)** |
| Auxiliary Space (DFS) | **O(V)** |
| Auxiliary Space (BFS) | **O(V)** |

Reason

- Every node is visited once.
- Every edge is checked once.

---

# DFS vs BFS

| DFS | BFS |
|------|-----|
| Uses Recursion | Uses Queue |
| Colors neighbour before recursion | Colors neighbour before pushing |
| Easy to write | Easy to visualize |
| Same Time Complexity | Same Time Complexity |

---

# Key Takeaways

- This is a **Graph Coloring** problem.
- `color[]` replaces `visited[]`.
- `-1` → Not Colored.
- `0` and `1` are the two colors.
- Every neighbour must receive the opposite color.
- If two adjacent nodes have the same color → Not Bipartite.
- The graph may be disconnected, so always check every component.
