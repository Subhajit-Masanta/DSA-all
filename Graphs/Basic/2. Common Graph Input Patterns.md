# Common Graph Input Patterns

> **Interview Rule**
>
> Before solving any graph problem, first identify **how the graph is given**.
>
> There are only **6 common input patterns**. These cover almost all placement questions.

---

# Pattern 1 — Edge List ⭐⭐⭐⭐⭐ (Most Common)

## Input

```text
5 4
0 1
0 2
1 3
2 4
```

Meaning

```text
n = 5 nodes
m = 4 edges
```

## Take Input

```cpp
int n, m;
cin >> n >> m;

vector<vector<int>> adj(n);

for(int i = 0; i < m; i++)
{
    int u, v;
    cin >> u >> v;

    adj[u].push_back(v);
    adj[v].push_back(u);      // remove for directed graph
}
```

Weighted

```text
4 4
0 1 5
0 2 3
1 3 2
2 3 4
```

```cpp
vector<vector<pair<int,int>>> adj(n);

for(int i = 0; i < m; i++)
{
    int u,v,wt;
    cin>>u>>v>>wt;

    adj[u].push_back({v,wt});
    adj[v].push_back({u,wt});
}
```

## Seen In

* DFS
* BFS
* Cycle Detection
* Dijkstra
* Bellman Ford
* Prim
* Kruskal
* Most GFG Graph Problems

---

# Pattern 2 — Adjacency Matrix ⭐⭐⭐⭐

## Input

```text
3

0 1 1
1 0 0
1 0 0
```

Meaning

```text
matrix[i][j] = 1

edge i → j exists
```

## Take Input

```cpp
int n;
cin >> n;

vector<vector<int>> matrix(n, vector<int>(n));

for(int i=0;i<n;i++)
{
    for(int j=0;j<n;j++)
    {
        cin>>matrix[i][j];
    }
}
```

Usually convert to adjacency list

```cpp
vector<vector<int>> adj(n);

for(int i=0;i<n;i++)
{
    for(int j=0;j<n;j++)
    {
        if(matrix[i][j])
            adj[i].push_back(j);
    }
}
```

Weighted Matrix

```text
0 4 2
4 0 0
2 0 0
```

Meaning

```text
matrix[i][j]

stores weight
```

## Seen In

* Number of Provinces
* Dense Graph problems

---

# Pattern 3 — Adjacency List Already Given ⭐⭐⭐⭐

Input

```cpp
graph =
{
    {1,2},
    {2},
    {3},
    {}
};
```

Meaning

```text
0 → 1,2

1 → 2

2 → 3
```

No graph construction.

Directly use

```cpp
graph[node]
```

as neighbours.

## Seen In

* Course Schedule
* All Paths From Source to Target
* Eventual Safe States

---

# Pattern 4 — Grid / Matrix ⭐⭐⭐⭐⭐

Input

```text
1 1 0
1 0 1
0 1 1
```

No adjacency list.

Each cell is a node.

Neighbours are generated using

```text
UP
DOWN
LEFT
RIGHT
```

or

```text
8 Directions
```

Take Input

```cpp
int rows, cols;
cin >> rows >> cols;

vector<vector<int>> grid(rows, vector<int>(cols));

for(int i=0;i<rows;i++)
{
    for(int j=0;j<cols;j++)
    {
        cin>>grid[i][j];
    }
}
```

or

```cpp
vector<string> grid(rows);

for(int i=0;i<rows;i++)
{
    cin>>grid[i];
}
```

## Seen In

* Number of Islands
* Flood Fill
* Rotting Oranges
* 01 Matrix
* Binary Maze
* Surrounded Regions

---

# Pattern 5 — Node Objects ⭐⭐⭐

Input

```cpp
class Node
{
public:
    int val;
    vector<Node*> neighbors;
};
```

Graph already exists.

No construction.

Simply traverse.

## Seen In

* LeetCode 133 — Clone Graph

---

# Pattern 6 — Implicit Graph ⭐⭐⭐

No graph is given.

Neighbours are generated dynamically.

Example

```text
hit

↓

hot

↓

dot

↓

dog
```

You generate neighbours instead of storing them.

No adjacency list.

## Seen In

* Word Ladder
* Open the Lock
* Minimum Multiplications
* Sliding Puzzle

---

# Recognition Cheat Sheet

| Input Given                 | What To Do                       |
| --------------------------- | -------------------------------- |
| `n m` + edges               | Build adjacency list             |
| Matrix                      | Read matrix, convert if required |
| `vector<vector<int>> graph` | Already adjacency list           |
| Grid                        | Treat cells as nodes             |
| `Node*`                     | Traverse directly                |
| States/Strings              | Generate neighbours dynamically  |

---

# Which Representation Is Used?

| Representation   | Used In                                  |
| ---------------- | ---------------------------------------- |
| Edge List        | DFS, BFS, Dijkstra, MST, Cycle Detection |
| Adjacency Matrix | Number of Provinces, Dense Graphs        |
| Adjacency List   | Course Schedule, Safe States             |
| Grid             | Islands, Flood Fill, Rotting Oranges     |
| Node Objects     | Clone Graph                              |
| Implicit Graph   | Word Ladder, Open Lock                   |

# Interview Strategy

```text
Question

↓

How is the graph given?

↓

Edge List?
    → Build adj[]

Adjacency Matrix?
    → Convert if needed

Adjacency List?
    → Direct DFS/BFS

Grid?
    → Generate neighbours using directions

Node Objects?
    → Traverse directly

States?
    → Generate neighbours dynamically
```
