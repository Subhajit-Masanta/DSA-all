# 547. Number of Provinces

| Topic | Difficulty | Pattern |
|-------|------------|---------|

# 📌 Problem Description

There are **n** cities.

Some cities are directly connected.

If city **A** is connected to **B**, and **B** is connected to **C**, then **A** is also indirectly connected to **C**.

A **province** is a group of directly or indirectly connected cities.

You are given an **n × n adjacency matrix** `isConnected`.

```text
isConnected[i][j] = 1
```

means

```text
City i is directly connected to City j
```

Return the total number of provinces.

# 🧠 Intuition

This is exactly the **Connected Components** problem.

The only difference is:

```text
Connected Components

↓

Input = Edge List

↓

Build Adjacency List
```

Here,

```text
Number of Provinces

↓

Input = Adjacency Matrix

↓

No Graph Construction Needed
```

Simply perform DFS directly on the matrix.

Every new DFS call discovers one new province.

---

# Key Observation

Each **row** of the matrix represents the neighbours of one city.

Example

```text
      0 1 2

0 -> [1 1 0]
```

Meaning

```text
City 0

↓

Connected to

0

1
```

To find neighbours of city `0`, scan the entire row.

# Step 2

Loop Through Every City

```text

↓
```

The outer loop is necessary because the graph may be disconnected.

# DFS Logic

Current City

↓

Mark Visited

↓

Scan Entire Row

↓

If another city is connected

AND

Not Visited

↓

DFS(Neighbour)

Memory Trick

```text
MARK

↓

SCAN ROW

↓

RECURSE
```

# Algorithm

```text
Adjacency Matrix

↓

Visited Array

↓

Loop Through Every City

↓

Unvisited City ?

↓

DFS

↓

Province++

↓

Return Provinces
```

# Code

```cpp
class Solution {
public:

    void dfs(int node,
             vector<vector<int>>& isConnected,
             vector<int>& visited,
             int n)
    {
        visited[node] = 1;

        for(int neighbour = 0; neighbour < n; neighbour++)
        {
            if(isConnected[node][neighbour] == 1 &&
               !visited[neighbour])
            {
                dfs(neighbour, isConnected, visited, n);
            }
        }
    }

    int findCircleNum(vector<vector<int>>& isConnected)
    {
        int n = isConnected.size();

        vector<int> visited(n, 0);

        int provinces = 0;

        for(int city = 0; city < n; city++)
        {
            if(!visited[city])
            {
                dfs(city, isConnected, visited, n);
                provinces++;
            }
        }

        return provinces;
    }
};
```

# Common Mistakes

## ❌ Incrementing Province Outside the `if`

Wrong

```cpp
if(!visited[i])
{
    dfs(i);
}

provinces++;
```

Correct

```cpp
if(!visited[i])
{
    dfs(i);
    provinces++;
}
```

---

## ❌ Forgetting Visited

Causes repeated DFS calls.

---

## ❌ Using Only

```cpp
dfs(0);
```

Fails for disconnected graphs.

Always use the outer loop.

---

## ❌ Using `node != neighbour`

Not required.

```cpp
visited[node] = 1;
```

already prevents revisiting itself.

# Complexity

| Complexity | Value |
|-----------|-------|
| Time | **O(n²)** |
| Auxiliary Space | **O(n)** |

### Time

Each visited city scans its entire row.

```text
n rows

×

n columns

=

O(n²)
```

### Auxiliary Space

- Visited array → **O(n)**
- DFS recursion stack → **O(n)**

Total Auxiliary Space

```text
O(n)
```

# Key Takeaways

- This is the **Connected Components** problem on an **adjacency matrix**.
- No need to convert the matrix into an adjacency list.
- The outer loop finds new provinces.
- DFS scans one complete row to find neighbours.
- Every new DFS call represents one new province.
