# 130. Surrounded Regions

| Topic | Difficulty | Pattern |
|--------|------------|---------|
| Graph | Medium | Boundary DFS |

---

# 📌 Problem Description

You are given an **m × n** board containing:

- `'X'`
- `'O'`

Capture all regions surrounded by `'X'`.

A region is formed by connecting adjacent `'O'` cells using only:

- Up
- Down
- Left
- Right

A region is **captured** if **none** of its cells touches the boundary.

Replace every surrounded `'O'` with `'X'`.

Modify the board in-place.

---

## Example

Input

```text
X X X X
X O O X
X X O X
X O X X
```

Output

```text
X X X X
X X X X
X X X X
X O X X
```

Explanation

The three middle `'O'` cells are completely surrounded.

The bottom `'O'` touches the boundary, so it remains unchanged.

---

# 🧠 Intuition

Instead of finding the regions to remove,

find the regions that **cannot** be removed.

Which cells are always safe?

```text
Boundary O's
```

Any `'O'` connected to a boundary `'O'` is also safe.

So,

```text
Boundary O

↓

DFS

↓

Mark Safe

↓

Convert Remaining O → X

↓

Restore Safe Cells
```

---

# Key Observation

Never start DFS from every `'O'`.

Start DFS **only from boundary `'O'` cells**.

Boundary means

```text
Top Row

Bottom Row

Left Column

Right Column
```

---

# Algorithm

```text
Boundary Traversal

↓

Boundary O ?

↓

DFS

↓

Mark Safe (#)

↓

Traverse Entire Board

↓

O → X

↓

# → O
```

---

# Why Use '#'

During DFS,

```text
O

↓

#
```

means

```text
Safe

Do Not Capture
```

Later,

```text
#

↓

O
```

is restored.

# Code

```cpp
class Solution {
public:

    void dfs(int row, int col, vector<vector<char>>& board)
    {
        int rows = board.size();
        int cols = board[0].size();

        if(row < 0 || row >= rows ||
           col < 0 || col >= cols ||
           board[row][col] != 'O')
        {
            return;
        }

        board[row][col] = '#';

        dfs(row - 1, col, board);
        dfs(row + 1, col, board);
        dfs(row, col - 1, board);
        dfs(row, col + 1, board);
    }

    void solve(vector<vector<char>>& board)
    {
        int rows = board.size();
        int cols = board[0].size();

        // Top Row
        for(int col = 0; col < cols; col++)
            dfs(0, col, board);

        // Bottom Row
        for(int col = 0; col < cols; col++)
            dfs(rows - 1, col, board);

        // Left Column
        for(int row = 0; row < rows; row++)
            dfs(row, 0, board);

        // Right Column
        for(int row = 0; row < rows; row++)
            dfs(row, cols - 1, board);

        // Final Conversion
        for(int row = 0; row < rows; row++)
        {
            for(int col = 0; col < cols; col++)
            {
                if(board[row][col] == '#')
                    board[row][col] = 'O';

                else if(board[row][col] == 'O')
                    board[row][col] = 'X';
            }
        }
    }
};
```

# Common Mistakes

## ❌ Starting DFS From Every 'O'

Wrong.

DFS should start **only from boundary `'O'` cells**.

---

## ❌ Forgetting to Restore '#'

Always convert

```text
# → O
```

at the end.

---

## ❌ Using Diagonal Directions

Only

```text
Up

Down

Left

Right
```

---

## ❌ Wrong Boundary Traversal

Top Row

```cpp
dfs(0, col)
```

Bottom Row

```cpp
dfs(rows - 1, col)
```

Left Column

```cpp
dfs(row, 0)
```

Right Column

```cpp
dfs(row, cols - 1)
```

| Complexity | Value |
|------------|-------|
| Time | **O(m × n)** |
| Auxiliary Space | **O(m × n)** |

### Time

Each cell is visited at most once.

```text
Rows × Columns

↓

O(m × n)
```

### Auxiliary Space

Worst-case recursion depth

```text
O(m × n)
```

# Key Takeaways

- This is the first **Boundary DFS** problem.
- Never start DFS from every `'O'`.
- Start only from boundary `'O'` cells.
- Mark safe cells using `'#'`.
- Convert remaining `'O'` to `'X'`.
- Restore `'#'` back to `'O'`.
