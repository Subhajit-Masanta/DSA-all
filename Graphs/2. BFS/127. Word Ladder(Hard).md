# 📌 Problem Description

You are given

- `beginWord`
- `endWord`
- `wordList`

You can transform one word into another by changing **exactly one letter**.

Rules:

- Change **only one character** at a time.
- Every intermediate word **must exist in `wordList`**.
- Return the **length of the shortest transformation sequence**.
- Return **0** if transformation is impossible.

# Algorithm

```text
Check endWord exists

↓

Store Dictionary in Hash Set

↓

Queue ← beginWord

↓

Level = 1

↓

BFS

↓

Generate Every One-Letter Change

↓

Word Exists?

↓

Push

↓

Erase From Set

↓

After One Level

↓

Level++

↓

Found endWord?

↓

Return Level

↓

Queue Empty

↓

Return 0
```

# Code

```cpp
class Solution {
public:

    int ladderLength(string beginWord,
                     string endWord,
                     vector<string>& wordList)
    {
        bool found = false;

        for(string word : wordList)
        {
            if(word == endWord)
            {
                found = true;
                break;
            }
        }

        if(!found)
            return 0;

        unordered_set<string> dict;

        for(string word : wordList)
            dict.insert(word);

        queue<string> q;

        q.push(beginWord);

        int level = 1;

        while(!q.empty())
        {
            int size = q.size();

            while(size--)
            {
                string curr = q.front();
                q.pop();

                if(curr == endWord)
                    return level;

                for(int i=0;i<curr.size();i++)
                {
                    char original = curr[i];

                    for(char ch='a'; ch<='z'; ch++)
                    {
                        if(ch == original)
                            continue;

                        curr[i] = ch;

                        if(dict.count(curr))
                        {
                            q.push(curr);
                            dict.erase(curr);
                        }
                    }

                    curr[i] = original;
                }
            }

            level++;
        }

        return 0;
    }
};
```

# Common Mistakes

## ❌ Comparing every dictionary word

Works but slower.

Expected solution generates neighbours.

---

## ❌ Forgetting to restore character

```cpp
curr[i] = original;
```

Otherwise next position starts with a modified word.

---

## ❌ Forgetting to erase

```cpp
dict.erase(curr);
```

Otherwise same word enters queue multiple times.

---

## ❌ Returning level before popping

Return when

```cpp
curr == endWord
```

# Complexity

| Complexity | Value |
|------------|-------|
| Time | **O(N × L × 26)** ≈ **O(N × L)** |
| Auxiliary Space | **O(N)** |

Where

- `N` = Number of words
- `L` = Length of each word

Each word is visited at most once.

For each word,

- Try every position (`L`)
- Try every character (`26`)

Since `26` is constant,

```text
O(N × L)
```

---

# Key Takeaways

- Hidden Graph Problem.
- Every word is a graph node.
- Edge exists if two words differ by one letter.
- Use **BFS** because shortest path is required.
- `unordered_set` acts as both dictionary and visited.
- Generate neighbours by changing one letter at a time.
- After pushing a word, immediately remove it from the set.
