# 📌 Problem Description

You are given an **m × n** binary matrix.

- `0` → Source
- `1` → Cell whose answer we need

For **every cell**, find the **shortest distance to the nearest 0**.

You can move only

- Up
- Down
- Left
- Right

Each move has cost **1**.

Return the distance matrix.

---

## Example 1

Input

```text
0 0 0
0 1 0
0 0 0
```

Output

```text
0 0 0
0 1 0
0 0 0
```

The middle cell is one step away from a 0.

# 🧠 Intuition

This is almost the same as **Rotting Oranges**.

Instead of spreading infection,

we spread **distance**.

Every **0** already knows

```text
Distance = 0
```

Start BFS from all 0's simultaneously.

---

# Why Multi-Source BFS?

Initially,

all 0's are pushed into the queue.

Example

```text
0 1 1

1 1 0

1 1 1
```

Queue

```text
(0,0)

(1,2)
```

Both start spreading together.

# Algorithm

```text
Create dist Matrix

↓

Initialize with -1

↓

Traverse Grid

↓

Push Every 0 into Queue

↓

dist = 0

↓

BFS

↓

Visit 4 Neighbours

↓

Neighbour Distance

=

Current Distance + 1

↓

Push Neighbour

↓

Return dist Matrix
```

# Code (Direction Arrays)

```cpp
class Solution {
public:

    vector<vector<int>> updateMatrix(vector<vector<int>>& mat)
    {
        int rows = mat.size();
        int cols = mat[0].size();

        vector<vector<int>> dist(rows, vector<int>(cols, -1));

        queue<pair<int,int>> q;

        for(int row = 0; row < rows; row++)
        {
            for(int col = 0; col < cols; col++)
            {
                if(mat[row][col] == 0)
                {
                    dist[row][col] = 0;
                    q.push({row,col});
                }
            }
        }

        int dr[] = {-1,1,0,0};
        int dc[] = {0,0,-1,1};

        while(!q.empty())
        {
            int size = q.size();

            while(size--)
            {
                int row = q.front().first;
                int col = q.front().second;
                q.pop();

                for(int i = 0; i < 4; i++)
                {
                    int newRow = row + dr[i];
                    int newCol = col + dc[i];

                    if(newRow >= 0 &&
                       newRow < rows &&
                       newCol >= 0 &&
                       newCol < cols &&
                       dist[newRow][newCol] == -1)
                    {
                        dist[newRow][newCol] =
                            dist[row][col] + 1;

                        q.push({newRow,newCol});
                    }
                }
            }
        }

        return dist;
    }
};
```

# Code (4 If Statements)

```cpp
class Solution {
public:

    vector<vector<int>> updateMatrix(vector<vector<int>>& mat)
    {
        int rows = mat.size();
        int cols = mat[0].size();

        vector<vector<int>> dist(rows, vector<int>(cols, -1));

        queue<pair<int,int>> q;

        for(int row = 0; row < rows; row++)
        {
            for(int col = 0; col < cols; col++)
            {
                if(mat[row][col] == 0)
                {
                    dist[row][col] = 0;
                    q.push({row,col});
                }
            }
        }

        while(!q.empty())
        {
            int size = q.size();

            while(size--)
            {
                int row = q.front().first;
                int col = q.front().second;
                q.pop();

                // Up
                if(row > 0 &&
                   dist[row-1][col] == -1)
                {
                    dist[row-1][col] =
                        dist[row][col] + 1;

                    q.push({row-1,col});
                }

                // Down
                if(row < rows-1 &&
                   dist[row+1][col] == -1)
                {
                    dist[row+1][col] =
                        dist[row][col] + 1;

                    q.push({row+1,col});
                }

                // Left
                if(col > 0 &&
                   dist[row][col-1] == -1)
                {
                    dist[row][col-1] =
                        dist[row][col] + 1;

                    q.push({row,col-1});
                }

                // Right
                if(col < cols-1 &&
                   dist[row][col+1] == -1)
                {
                    dist[row][col+1] =
                        dist[row][col] + 1;

                    q.push({row,col+1});
                }
            }
        }

        return dist;
    }
};
```

# Common Mistakes

## ❌ Starting BFS from every 1

Wrong.

Start BFS from **all 0's**.

---

## ❌ Using DFS

DFS cannot guarantee shortest distance.

---

## ❌ Using mat as visited

Wrong.

Use

```cpp
dist == -1
```

to identify unvisited cells.

---

## ❌ Visiting same cell twice

Once

```text
dist != -1
```

never push that cell again.

# Complexity

| Complexity | Value |
|------------|-------|
| Time | **O(m × n)** |
| Auxiliary Space | **O(m × n)** |

### Time

Every cell enters the queue at most once.

```text
O(m × n)
```

### Auxiliary Space

- Distance matrix → **O(m × n)**
- Queue (worst case) → **O(m × n)**

Overall

```text
O(m × n)
```

| Rotting Oranges | 01 Matrix |
|-----------------|-----------|
| Source = all `2`s | Source = all `0`s |
| Spread Rotten | Spread Distance |
| `grid[new] = 2` | `dist[new] = dist[curr] + 1` |
| Count Minutes | Store Distance |
| Return Minutes | Return Distance Matrix |

# Key Takeaways

- This is a **Multi-Source BFS** problem.
- Push **all 0's** into the queue initially.
- `dist[row][col]` stores the shortest distance to a 0.
- `dist == -1` means **not visited**.
- First time a cell is visited in BFS gives the shortest distance.
- This is almost the same pattern as **Rotting Oranges**.
