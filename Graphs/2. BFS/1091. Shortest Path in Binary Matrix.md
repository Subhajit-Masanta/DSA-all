# 📌 Problem Description

Given an **n × n** binary matrix.

- `0` → Open Cell
- `1` → Blocked Cell

Find the **shortest path** from

```text
(0,0)

↓

(n-1,n-1)
```

You can move in **8 directions**.

```text
↖  ↑  ↗

←  ●  →

↙  ↓  ↘
```

The path length is

```text
Number of Visited Cells
```

Return

- Shortest Path Length
- `-1` if no path exists.

# Algorithm

```text
Check Start / End

↓

Blocked?

↓

Return -1

↓

dist[0][0] = 1

↓

Push (0,0)

↓

BFS

↓

Visit 8 Neighbours

↓

Neighbour Distance

=

Current Distance + 1

↓

Reached Destination?

↓

Return Distance

↓

Queue Empty?

↓

Return -1
```

# Code (Distance Matrix Version - Recommended)

```cpp
class Solution {
public:

    int shortestPathBinaryMatrix(vector<vector<int>>& grid)
    {
        int n = grid.size();

        if(grid[0][0] == 1 || grid[n-1][n-1] == 1)
            return -1;

        vector<vector<int>> dist(n, vector<int>(n,-1));

        queue<pair<int,int>> q;

        dist[0][0] = 1;

        q.push({0,0});

        int dr[] = {-1,-1,-1,0,0,1,1,1};
        int dc[] = {-1,0,1,-1,1,-1,0,1};

        while(!q.empty())
        {
            int row = q.front().first;
            int col = q.front().second;
            q.pop();

            if(row == n-1 && col == n-1)
                return dist[row][col];

            for(int i=0;i<8;i++)
            {
                int newRow = row + dr[i];
                int newCol = col + dc[i];

                if(newRow>=0 &&
                   newRow<n &&
                   newCol>=0 &&
                   newCol<n &&
                   grid[newRow][newCol]==0 &&
                   dist[newRow][newCol]==-1)
                {
                    dist[newRow][newCol] =
                        dist[row][col] + 1;

                    q.push({newRow,newCol});
                }
            }
        }

        return -1;
    }
};
```

# Alternative (Using BFS Levels)

Instead of storing distance inside `dist[][]`,
store only visited information.

```cpp
vector<vector<int>> visited(n, vector<int>(n,0));
```

Queue

```cpp
queue<pair<int,int>> q;
```

Initialize

```cpp
q.push({0,0});

visited[0][0]=1;

int distance=1;
```

Now every BFS level represents

```text
Current Distance
```

```cpp
while(!q.empty())
{
    int size=q.size();

    while(size--)
    {
        auto curr=q.front();
        q.pop();

        if(curr.first==n-1 && curr.second==n-1)
            return distance;

        ...
    }

    distance++;
}
```

Here

```text
Level

↓

Distance
```

So `size` is required.

# Which Version Should I Use?

## Version 1 ✅ (Recommended)

```cpp
dist[][]
```

Advantages

- Same as 01 Matrix
- Easy to debug
- Easy to understand
- Reusable

No level counting needed.

---

## Version 2

```cpp
visited[][]

+

distance variable
```

Advantages

- Less memory than `dist[][]`

Needs

```cpp
size=q.size()
```

because every level represents one distance.

# Common Mistakes

## ❌ Forgetting to check

```cpp
grid[0][0]
```

or

```cpp
grid[n-1][n-1]
```

If blocked

```text
Return -1
```

---

## ❌ Using only 4 directions

Need

```text
8 Directions
```

---

## ❌ Returning

```cpp
grid[n-1][n-1]
```

Return

```cpp
dist[n-1][n-1]
```

or return immediately after reaching destination.

---

## ❌ Visiting the same cell twice

Check

```cpp
dist[newRow][newCol]==-1
```

before pushing.

# Complexity

| Complexity | Value |
|------------|-------|
| Time | **O(n²)** |
| Auxiliary Space | **O(n²)** |

Every cell enters the queue at most once.

# Comparison

| Version | Queue Stores | Extra Array | Need `size`? |
|----------|-------------|-------------|---------------|
| Distance Matrix | `(row,col)` | `dist[][]` | ❌ No |
| Level BFS | `(row,col)` | `visited[][]` | ✅ Yes |

---

# Key Takeaways

- Source is **only `(0,0)`**.
- Destination is **`(n-1,n-1)`**.
- Use **8 directions**.
- `dist[][]` stores shortest distance from the start.
- If using `dist[][]`, **no level counting is required**.
- If using a single `distance` variable, **every BFS level represents one distance**, so `size=q.size()` is required.
