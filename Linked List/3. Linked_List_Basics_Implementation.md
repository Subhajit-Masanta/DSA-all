# Linked List Basics Implementation

## Prerequisites

```cpp
class Node
{
public:
    int data;
    Node* next;

    Node(int val)
    {
        data = val;
        next = nullptr;
    }
};

Node* head = nullptr;
```

---

# 1. Traversal

## Purpose

Visit every node from head to NULL.

## Algorithm

```
temp = head

while(temp != NULL)
{
    process node
    temp = temp->next
}
```

## Code

```cpp
void traverse()
{
    if(head == nullptr)
    {
        cout << "Linked List is empty" << endl;
        return;
    }

    Node* temp = head;

    while(temp != nullptr)
    {
        cout << temp->data << " ";
        temp = temp->next;
    }

    cout << endl;
}
```

## Complexity

```
Time  : O(n)
Space : O(1)
```

# 2. Insert at Front

## Pattern

```
new->next = head
head = new
```

## Visualization

Before

```

```

After inserting 5

```
head

5 -> 10 -> 20 -> 30
```

## Code

```cpp
void insert_front(int x)
{
    Node* newnode = new Node(x);

    newnode->next = head;
    head = newnode;
}
```

## Complexity

```
Time  : O(1)
Space : O(1)
```

# 3. Insert at End

## Pattern

Traverse until last node.

```
last->next = newnode
```

## Visualization

Before

```
10 -> 20 -> 30
```

After

```
10 -> 20 -> 30 -> 40
```

## Code

```cpp
void insert_last(int x)
{
    Node* newnode = new Node(x);

    if(head == nullptr)
    {
        head = newnode;
        return;
    }

    Node* temp = head;

    while(temp->next != nullptr)
    {
        temp = temp->next;
    }

    temp->next = newnode;
}
```

## Complexity

```
Time  : O(n)
Space : O(1)
```

# 4. Insert at Position

## Pattern

Need previous node.

```
new->next = prev->next
prev->next = new
```

## Visualization

Before

```
10 -> 20 -> 30 -> 40
```

Insert 25 at position 3

```
10 -> 20 -> 25 -> 30 -> 40
```

## Code

```cpp
void insert_position(int x, int pos)
{
    Node* newnode = new Node(x);

    if(pos < 1)
    {
        cout << "Invalid position" << endl;
        return;
    }

    if(pos == 1)
    {
        newnode->next = head;
        head = newnode;
        return;
    }

    Node* temp = head;

    for(int i = 0; i < pos - 2; i++)
    {
        if(temp == nullptr)
        {
            cout << "Invalid position" << endl;
            return;
        }

        temp = temp->next;
    }

    if(temp == nullptr)
    {
        cout << "Invalid position" << endl;
        return;
    }

    newnode->next = temp->next;
    temp->next = newnode;
}
```

## Complexity

```
Time  : O(n)
Space : O(1)
```

# 6. Delete End

## Pattern

Find second last node.

```
secondLast->next = NULL
delete last
```

## Visualization

Before

```
10 -> 20 -> 30
```

After

```
10 -> 20
```

## Code

```cpp
void delete_last()
{
    if(head == nullptr)
    {
        cout << "Linked List is empty" << endl;
        return;
    }

    if(head->next == nullptr)
    {
        delete head;
        head = nullptr;
        return;
    }

    Node* temp = head;

    while(temp->next->next != nullptr)
    {
        temp = temp->next;
    }

    Node* last = temp->next;

    temp->next = nullptr;

    delete last;
}
```

## Complexity

```
Time  : O(n)
Space : O(1)
```

# 7. Delete at Position

## Pattern

Need previous node and current node.

```
prev->next = curr->next
delete curr
```

## Visualization

Before

```
10 -> 20 -> 30 -> 40
```

Delete position 3

```
10 -> 20 -> 40
```

## Code

```cpp
void delete_position(int pos)
{
    if(head == nullptr)
    {
        cout << "Linked List is empty" << endl;
        return;
    }

    if(pos < 1)
    {
        cout << "Invalid position" << endl;
        return;
    }

    if(pos == 1)
    {
        Node* temp = head;
        head = head->next;
        delete temp;
        return;
    }

    Node* prev = head;

    for(int i = 0; i < pos - 2; i++)
    {
        if(prev == nullptr || prev->next == nullptr)
        {
            cout << "Invalid position" << endl;
            return;
        }

        prev = prev->next;
    }

    if(prev->next == nullptr)
    {
        cout << "Invalid position" << endl;
        return;
    }

    Node* curr = prev->next;

    prev->next = curr->next;

    delete curr;
}
```

## Complexity

```
Time  : O(n)
Space : O(1)
```

# Edge Cases Checklist

Always check these first:

```
✓ Empty list
✓ Single node
✓ Position = 1
✓ Invalid position
✓ Last node
```

# Interview Takeaways

* A Linked List problem is usually **pointer manipulation**, not a complex algorithm.
* Always draw the list before coding.
* Think in terms of **previous node, current node, and next node**.
* Never lose a node's address before reconnecting pointers.
* Always handle:

  * Empty list
  * Single node
  * Invalid position

# Notebook One-Liner

> **Linked Lists are solved by changing addresses (pointers), not by moving data. Master the pointer patterns, and most interview problems become straightforward.**
