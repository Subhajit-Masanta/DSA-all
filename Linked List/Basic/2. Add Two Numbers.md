# Add Two Numbers

| Topic | Difficulty | Pattern |
| :----- | :--------- | :------ |
| Linked List | Medium | Dummy Node + Carry Simulation |

---

# 📌 Problem Description

Two non-empty linked lists represent two non-negative integers.

Digits are stored in **reverse order**, where each node contains a single digit.

Return their sum as a linked list.

Example

```text
l1 = 2 -> 4 -> 3

l2 = 5 -> 6 -> 4
```

represents

```text
342 + 465 = 807
```

Return

```text
7 -> 0 -> 8
```

---

# 🧠 Core Insight

The digits are **already stored in reverse order**.

```text
2 -> 4 -> 3

↓

342
```

The traversal order is

```text
Units

↓

Tens

↓

Hundreds
```

which is exactly how elementary addition works.

Therefore,

```text
No reversing

No stack
```

is required.

---

# ⚙️ Algorithm

### Step 1

Create a dummy node.

```text
dummy

↓

0
```

Maintain

```text
tail
```

to build the answer.

---

### Step 2

Maintain

```text
carry = 0
```

---

### Step 3

Repeat while

```cpp
l1 || l2 || carry
```

---

### Step 4

Compute

```cpp
sum = carry;

if(l1)
    sum += l1->val;

if(l2)
    sum += l2->val;
```

---

### Step 5

Store

```cpp
digit = sum % 10;
```

Update

```cpp
carry = sum / 10;
```

Append

```cpp
tail->next = new ListNode(digit);
```

Move

```cpp
tail = tail->next;
```

# ⚠️ Common Mistakes

### Mistake 1

Using

```cpp
while(l1 && l2)
```

Wrong.

One list may be longer.

Correct

```cpp
while(l1 || l2 || carry)
```

---

### Mistake 2

Forgetting the final carry.

Example

```text
999 + 1

↓

1000
```

Need one extra node.

---

### Mistake 3

Thinking the list should be reversed.

The problem already stores digits in reverse order.

# 🎯 Interview One-Liner

Traverse both linked lists simultaneously, simulate elementary addition using a carry variable, and build the answer using a dummy node.

---

# 💻 Code (C++)

```cpp
class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {

        int carry = 0;

        ListNode* dummy = new ListNode(0);
        ListNode* tail = dummy;

        while(l1 || l2 || carry)
        {
            int sum = carry;

            if(l1)
            {
                sum += l1->val;
                l1 = l1->next;
            }

            if(l2)
            {
                sum += l2->val;
                l2 = l2->next;
            }

            int digit = sum % 10;
            carry = sum / 10;

            tail->next = new ListNode(digit);
            tail = tail->next;
        }

        return dummy->next;
    }
};
```
