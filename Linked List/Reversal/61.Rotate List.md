# Rotate List

| Topic       | Difficulty | Pattern                                     |
| :---------- | :--------- | :------------------------------------------ |
| Linked List | Medium     | Circular Linked List / Pointer Manipulation |

---

# 📌 Problem Description

Given the head of a linked list, rotate the list to the **right** by `k` places.

Example:

```text
Input:
1 -> 2 -> 3 -> 4 -> 5
k = 2

Output:
4 -> 5 -> 1 -> 2 -> 3
```

---

# 🧠 Core Insight

Instead of moving the last node to the front `k` times,

make the linked list **circular**, find the new tail, and break the circle.

```text
1 -> 2 -> 3 -> 4 -> 5
^                   |
|___________________|
```

---

# ⚙️ Algorithm

### Step 1

Find the length of the linked list.

```text
length = n
```

Also keep a pointer to the last node.

---

### Step 2

Reduce unnecessary rotations.

```cpp
k = k % n;
```

Because rotating `n` times gives the original list.

---

### Step 3

If

```cpp
k == 0
```

return the original head.

---

### Step 4

Connect

```text
tail -> head
```

making the linked list circular.

---

### Step 5

Find the new tail.

It will be at

```text
n - k
```

position from the beginning.

Move

```text
n - k - 1
```

steps from head.

---

### Step 6

New head is

```cpp
newTail->next
```

Break the circle.

```cpp
newTail->next = nullptr;
```

Return the new head.

---

# ⏱ Time Complexity

```text
O(n)
```

One traversal to find length and one traversal to find the new tail.

---

# 📦 Space Complexity

```text
O(1)
```

Only pointer variables are used.

---

# ⚠️ Common Mistakes

### Mistake 1

Wrong modulo.

❌

```cpp
k = n % k;
```

✅

```cpp
k = k % n;
```

---

### Mistake 2

Forgetting to handle

```cpp
k == 0
```

which causes unnecessary circular linking.

---

### Mistake 3

Forgetting to break the circle.

```cpp
newTail->next = nullptr;
```

Without this, the linked list becomes an infinite loop.

---

### Mistake 4

Finding the wrong new tail.

Move

```text
n - k - 1
```

steps from head.

---

# 🔥 Key Insight

Think of the linked list as a **circle**.

```text
Make Circle

↓

Find New Tail

↓

New Head = NewTail->next

↓

Break Circle
```

Instead of rotating one node at a time.

---

# 🎯 Interview One-Liner

Convert the linked list into a circular list, locate the new tail using `n - k`, set the next node as the new head, and break the circle.

---

# 💻 Code (C++)

```cpp
class Solution {
public:
    ListNode* rotateRight(ListNode* head, int k) {

        if (!head || !head->next || k == 0)
            return head;

        ListNode* temp = head;
        int n = 1;

        while (temp->next) {
            n++;
            temp = temp->next;
        }

        k = k % n;

        if (k == 0)
            return head;

        temp->next = head;

        int place = n - k;

        ListNode* newTail = head;

        for (int i = 1; i < place; i++) {
            newTail = newTail->next;
        }

        ListNode* newHead = newTail->next;

        newTail->next = nullptr;

        return newHead;
    }
};
```

Find Length

Find New Tail
