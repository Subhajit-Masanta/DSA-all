# Reorder List

| Topic       | Difficulty | Pattern                                         |
| :---------- | :--------- | :---------------------------------------------- |
| Linked List | Medium     | Fast & Slow Pointer + Reverse + Alternate Merge |

---

# 📌 Problem Description

Given the head of a singly linked list, reorder it into the following form:

```text
L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → ...
```

Only the node connections may be changed.

Node values cannot be modified.

Example:

```text
Input:
1 -> 2 -> 3 -> 4

Output:
1 -> 4 -> 2 -> 3
```

---

# 🧠 Core Insight

This problem is **not a new pattern**.

It is simply a combination of three problems:

```text
876 Middle of Linked List

↓

206 Reverse Linked List

↓

Alternate Merge
```

Instead of repeatedly taking the last node (O(n²)), split the list into two halves, reverse the second half, and merge them alternately.

---

# ⚙️ Algorithm

### Step 1

Find the middle using Fast & Slow pointers.

```text
slow

↓

1 -> 2 -> 3 -> 4 -> 5
          ^
```

---

### Step 2

Split the linked list into two halves.

```cpp
curr = slow->next;
slow->next = nullptr;
```

Result

```text
First Half

1 -> 2 -> 3

Second Half

4 -> 5
```

---

### Step 3

Reverse the second half.

```text
4 -> 5

↓

5 -> 4
```

---

### Step 4

Merge both halves alternately.

```text
First Half

1 -> 2 -> 3

Second Half

5 -> 4

↓

1 -> 5 -> 2 -> 4 -> 3
```

# ⚠️ Common Mistakes

### Mistake 1

Forgetting to split the list.

Wrong

```cpp
curr = slow->next;
```

Correct

```cpp
curr = slow->next;
slow->next = nullptr;
```

Otherwise both halves remain connected and cycles may be created during merging.

---

### Mistake 2

Not saving next pointers before merging.

Wrong

```cpp
first->next = second;
first = first->next;
```

Original links are lost.

Always save

```cpp
temp1 = first->next;
temp2 = second->next;
```

before reconnecting.

---

### Mistake 3

Trying to compare values while merging.

This is **not Merge Two Sorted Lists**.

No comparison is needed.

Simply alternate nodes.

---

### Mistake 4

Trying to repeatedly take the last node.

```text
Take Last

↓

Traverse Again

↓

Take Last

↓

Traverse Again
```

This results in

```text
O(n²)
```

instead of

```text
O(n)
```

---

# 🎯 Interview One-Liner

Split the linked list into two halves, reverse the second half, and merge both halves alternately to achieve **O(n)** time and **O(1)** extra space.

---

# 💻 Code (C++)

```cpp
class Solution {
public:

    void reorderList(ListNode* head) {

        if (!head || !head->next)
            return;

        // Step 1: Find middle
        ListNode* slow = head;
        ListNode* fast = head;

        while (fast->next && fast->next->next)
        {
            slow = slow->next;
            fast = fast->next->next;
        }

        // Step 2: Reverse second half
        ListNode* prev = nullptr;
        ListNode* curr = slow->next;

        slow->next = nullptr;

        while (curr)
        {
            ListNode* next = curr->next;

            curr->next = prev;

            prev = curr;

            curr = next;
        }

        // Step 3: Merge two halves
        ListNode* first = head;
        ListNode* second = prev;

        while (second)
        {
            ListNode* temp1 = first->next;
            ListNode* temp2 = second->next;

            first->next = second;
            second->next = temp1;

            first = temp1;
            second = temp2;
        }
    }
};
```
