# 416. Partition Equal Subset Sum

| Topic | Difficulty | Pattern |
| ----- | ---------- | ------- |
| Dynamic Programming | Medium | 0/1 Knapsack — Subset Sum |

---

# 📌 Problem Description

Given an integer array `nums`, determine whether it is possible to divide the array into **two subsets** such that both subsets have the same sum.

Return:

```text
true
```

if such a partition is possible.

Otherwise:

```text
false
```

Each element can be used only once.

---

# Example

### Example 1

Input:

```text
nums = [1,5,11,5]
```

Output:

```text
true
```

Explanation:

```text
[1,5,5] = 11

[11] = 11
```

Both subsets have equal sum.

---

### Example 2

Input:

```text
nums = [1,2,3,5]
```

Output:

```text
false
```

Total sum:

```text
1 + 2 + 3 + 5 = 11
```

Since `11` is odd, it cannot be divided into two equal integer sums.

---

# 🧠 Intuition

This problem is actually a **Subset Sum** problem.

Suppose the total sum of the array is:

```text
total
```

If we divide the array into two equal subsets:

```text
subset1 + subset2 = total
```

and:

```text
subset1 = subset2
```

then:

```text
subset1 = total / 2
subset2 = total / 2
```

Therefore, instead of finding two subsets, we only need to answer:

> **Can I find one subset whose sum is `total / 2`?**

That is exactly the **Subset Sum** problem.

---

# Key Observation

First calculate:

```text
total = sum of all elements
```

### If total is odd

For example:

```text
total = 11
```

Then:

```text
11 / 2 = 5.5
```

It is impossible to divide the array into two subsets with equal integer sums.

Therefore:

```cpp
if(total % 2 != 0)
    return false;
```

---

### If total is even

For example:

```text
total = 22
```

Then each subset must have:

```text
22 / 2 = 11
```

So the problem becomes:

```text
Can I form a subset with sum 11?
```

Use **Subset Sum DP**.

---

# Reduction

```text
Partition Equal Subset Sum

        ↓

Calculate total sum

        ↓

Is total odd?
   /          \
 YES          NO
  ↓            ↓
false       target = total/2
               ↓
          Subset Sum
               ↓
       Can target be formed?
```

---

# State

Use the same state as Subset Sum:

```text
dp[i][j]
```

where:

> `dp[i][j]` = whether sum `j` can be formed using the first `i` elements.

The answer we ultimately need is:

```text
dp[n][target]
```

---

# Choices

For the current element:

```text
nums[i-1]
```

we have two choices.

---

## Choice 1 — Don't Take

Don't use the current element.

The target remains:

```text
j
```

Therefore:

```text
dp[i-1][j]
```

---

## Choice 2 — Take

If:

```text
nums[i-1] <= j
```

we can take the element.

The remaining target becomes:

```text
j - nums[i-1]
```

Therefore:

```text
dp[i-1][j-nums[i-1]]
```

---

# Transition

If the current element fits:

```text
dp[i][j] =
    dp[i-1][j]
    ||
    dp[i-1][j-nums[i-1]]
```

Otherwise:

```text
dp[i][j] =
    dp[i-1][j]
```

We use:

```text
OR
```

because we only need **one valid subset**.

---

# Base Case

Sum `0` is always possible.

Why?

Because the empty subset:

```text
{}
```

has sum:

```text
0
```

Therefore:

```text
dp[i][0] = true
```

for every `i`.

---

# Example Dry Run

Consider:

```text
nums = [1,5,11,5]
```

Total:

```text
1 + 5 + 11 + 5 = 22
```

Therefore:

```text
target = 22 / 2
       = 11
```

Now the problem becomes:

```text
Can we form 11?
```

Possible subset:

```text
11
```

or:

```text
1 + 5 + 5 = 11
```

Therefore:

```text
dp[4][11] = true
```

So:

```text
return true
```

The remaining elements automatically form the other subset.

---

# Why Does Finding One Subset Guarantee the Other?

Suppose:

```text
total = 22
```

and we find a subset with:

```text
sum = 11
```

The remaining elements have:

```text
22 - 11 = 11
```

Therefore:

```text
Subset 1 = 11
Subset 2 = 11
```

So we don't need to explicitly construct the second subset.

---

# Algorithm

```text
Calculate total sum

↓

If total is odd:

    return false

↓

target = total / 2

↓

Create dp[n+1][target+1]

↓

Set dp[i][0] = true

↓

For each element:

    For each target:

        If element <= target:

            Don't Take
            OR
            Take

        Else:

            Don't Take

↓

Return dp[n][target]
```

---

# Code — Tabulation

```cpp
class Solution {
public:

    bool canPartition(vector<int>& nums)
    {
        int n = nums.size();

        int sum = 0;

        for(int i = 0; i < n; i++)
        {
            sum += nums[i];
        }

        // Odd total cannot be divided equally
        if(sum % 2 == 1)
            return false;

        int target = sum / 2;

        vector<vector<bool>>
            dp(
                n + 1,
                vector<bool>(target + 1, false)
            );

        // Sum 0 is always possible
        for(int i = 0; i <= n; i++)
        {
            dp[i][0] = true;
        }

        for(int i = 1; i <= n; i++)
        {
            for(int j = 1; j <= target; j++)
            {
                int val = nums[i-1];

                if(val <= j)
                {
                    dp[i][j] =
                        dp[i-1][j] ||
                        dp[i-1][j-val];
                }
                else
                {
                    dp[i][j] =
                        dp[i-1][j];
                }
            }
        }

        return dp[n][target];
    }
};
```

---

# Complexity

Let:

```text
n = number of elements
sum = total sum
```

Target is:

```text
sum / 2
```

Therefore:

| Complexity | Value |
|------------|-------|
| Time | **O(n × sum)** |
| Space | **O(n × sum)** |

More precisely, the DP table uses:

```text
O(n × (sum/2))
```

which is still commonly written as:

```text
O(n × sum)
```

---

# Space Optimized

Since every row only depends on the previous row, we can use a 1D DP array.

For 0/1 Subset Sum, iterate backwards.

```cpp
class Solution {
public:

    bool canPartition(vector<int>& nums)
    {
        int sum = 0;

        for(int x : nums)
        {
            sum += x;
        }

        if(sum % 2 != 0)
            return false;

        int target = sum / 2;

        vector<bool> dp(target + 1, false);

        dp[0] = true;

        for(int x : nums)
        {
            for(int j = target; j >= x; j--)
            {
                dp[j] =
                    dp[j] ||
                    dp[j-x];
            }
        }

        return dp[target];
    }
};
```

---

# Why Backward Iteration?

This is still a **0/1 problem**.

Each number can be used only once.

Suppose:

```text
nums[i] = 3
```

If we iterate forward, we could accidentally do:

```text
3 → make 3

then use that 3 again

3 + 3 = 6
```

That would use the same element twice.

Backward iteration prevents this.

```text
target → x
```

Therefore:

```cpp
for(int j = target; j >= x; j--)
```

# Recognition Pattern

When you see:

> "Divide/partition an array into two subsets with equal sum."

Immediately think:

```text
1. Calculate total sum
2. If odd → false
3. target = total / 2
4. Solve Subset Sum(target)
```

You should **not** invent a new DP.

This is a direct reduction to a pattern you already know.

# Key Takeaways

- Partition Equal Subset Sum is a **Subset Sum variation**.
- First calculate the total sum.
- If the total is odd, return `false`.
- If the total is even:

```text
target = total / 2
```

- Then ask:

```text
Can I form target using a subset?
```

- Use the same 0/1 Subset Sum DP.
- Each number can be used at most once.
- `dp[i][j]` means:

```text
Can sum j be formed using first i elements?
```

- `dp[i][0] = true`.
- Use `OR` because we're checking whether at least one choice works.
- Space-optimized 0/1 DP iterates the target **backwards**.

The key reduction to remember:

```text
              Equal Partition
                     ↓
                Total Sum
                     ↓
              ┌──────┴──────┐
             ODD           EVEN
              ↓               ↓
            false       target = sum/2
                              ↓
                         Subset Sum
                              ↓
                         true / false
```
