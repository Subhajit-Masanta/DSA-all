# 198. House Robber

| Topic | Difficulty | Pattern |
| ----- | ---------- | ------- |
| Dynamic Programming | Medium | 1D DP — Take / Don't Take |

---

# 📌 Problem Description

You are given an integer array `nums`.

```text
nums[i] = amount of money in house i
```

You want to rob the maximum amount of money.

However, you **cannot rob two adjacent houses**, otherwise the police will be alerted.

Return the maximum amount of money you can rob.

---

# Example

### Example 1

Input

```text
nums = [1,2,3,1]
```

Output

```text
4
```

Explanation:

```text
Rob house 0 → 1
Rob house 2 → 3

Total = 1 + 3 = 4
```

We cannot rob houses `0` and `1` together because they are adjacent.

---

### Example 2

Input

```text
nums = [2,7,9,3,1]
```

Output

```text
12
```

Explanation:

```text
Rob house 0 → 2
Rob house 2 → 9
Rob house 4 → 1

Total = 2 + 9 + 1 = 12
```

---

# 🧠 Intuition

At every house, we have two choices:

```text
ROB the current house
OR
DON'T ROB the current house
```

If we rob house `i`, we cannot rob house `i-1`.

Therefore, the previous house we can use is:

```text
i - 2
```

If we don't rob house `i`, we keep the best answer we already obtained from:

```text
0 ... i-1
```

This gives the classic:

```text
Take / Don't Take
```

DP pattern.

---

# Key Observation

Define:

```text
dp[i] = maximum amount of money that can be robbed
        from houses 0 to i
```

Now consider house `i`.

---

## Choice 1 — Rob House i

If we rob house `i`, we cannot rob house `i-1`.

So:

```text
candidate1 = nums[i] + dp[i-2]
```

---

## Choice 2 — Don't Rob House i

If we don't rob house `i`, the best answer remains the best answer up to house `i-1`.

```text
candidate2 = dp[i-1]
```

---

Therefore:

```text
dp[i] = max(
    nums[i] + dp[i-2],
    dp[i-1]
)
```

---

# Important DP Lesson

Do not confuse:

```text
nums[i-1]
```

with:

```text
dp[i-1]
```

They mean completely different things.

```text
nums[i-1]
```

means:

```text
Money inside house i-1
```

while:

```text
dp[i-1]
```

means:

```text
Maximum money that can be robbed
from ALL houses 0 ... i-1
```

We need `dp[i-1]`.

---

# Algorithm

```text
Create dp array

↓

dp[0] = nums[0]

↓

dp[1] = max(nums[0], nums[1])

↓

For i = 2 to n-1

    candidate1 =
        nums[i] + dp[i-2]

    candidate2 =
        dp[i-1]

    dp[i] =
        max(candidate1, candidate2)

↓

Return dp[n-1]
```

---

# Base Cases

For the first house:

```text
dp[0] = nums[0]
```

For the first two houses, we can rob only one of them:

```text
dp[1] = max(nums[0], nums[1])
```

# Code — Tabulation

```cpp
class Solution {
public:

    int rob(vector<int>& nums)
    {
        int n = nums.size();

        if(n == 1)
            return nums[0];

        if(n == 2)
            return max(nums[0], nums[1]);

        vector<int> dp(n, 0);

        dp[0] = nums[0];

        dp[1] = max(nums[0], nums[1]);

        for(int i = 2; i < n; i++)
        {
            int candidate1 =
                nums[i] + dp[i-2];

            int candidate2 =
                dp[i-1];

            dp[i] =
                max(candidate1, candidate2);
        }

        return dp[n-1];
    }
};
```

# Code — Memoization

```cpp
class Solution {
public:

    int solve(int i, vector<int>& nums, vector<int>& dp)
    {
        if(i == 0)
            return nums[0];

        if(i == 1)
            return max(nums[0], nums[1]);

        if(dp[i] != -1)
            return dp[i];

        int robCurrent =
            nums[i] + solve(i-2, nums, dp);

        int skipCurrent =
            solve(i-1, nums, dp);

        return dp[i] =
            max(robCurrent, skipCurrent);
    }

    int rob(vector<int>& nums)
    {
        int n = nums.size();

        vector<int> dp(n, -1);

        return solve(n-1, nums, dp);
    }
};
```

---

# Complexity — Memoization

| Complexity | Value |
|------------|-------|
| Time | **O(n)** |
| Space | **O(n)** |

Each state is calculated once.

The space consists of:

```text
DP array
+
Recursion stack
```

---

# Space Optimization

Notice that:

```text
dp[i]
```

only depends on:

```text
dp[i-1]
dp[i-2]
```

Therefore, we don't need the entire DP array.

We only need two previous values.

Let:

```text
prev2 = dp[i-2]
prev1 = dp[i-1]
```

Then:

```text
current =
    max(
        nums[i] + prev2,
        prev1
    )
```

After calculating:

```text
prev2 = prev1
prev1 = current
```

---

# Code — Space Optimized

```cpp
class Solution {
public:

    int rob(vector<int>& nums)
    {
        int n = nums.size();

        if(n == 1)
            return nums[0];

        int prev2 = nums[0];

        int prev1 =
            max(nums[0], nums[1]);

        for(int i = 2; i < n; i++)
        {
            int current =
                max(
                    nums[i] + prev2,
                    prev1
                );

            prev2 = prev1;
            prev1 = current;
        }

        return prev1;
    }
};
```

---

# Complexity — Space Optimized

| Complexity | Value |
|------------|-------|
| Time | **O(n)** |
| Space | **O(1)** |

Only three integer variables are used.

| Approach | Time | Space |

# DP Pattern Learned

```text
1D DP
+
Take / Don't Take
```

State:

```text
dp[i] = maximum money that can be robbed
        from houses 0...i
```

Transition:

```text
Take:

nums[i] + dp[i-2]


Don't Take:

dp[i-1]
```

Therefore:

```text
dp[i] =
max(
    nums[i] + dp[i-2],
    dp[i-1]
)
```

# Recognition Pattern

When you see:

```text
Array
+
Choose elements
+
Adjacent elements cannot both be chosen
+
Maximum / Minimum
```

Think:

```text
Take / Don't Take DP
```

Ask:

```text
If I TAKE i:

Which previous state can I use?

        ↓

i - 2


If I DON'T TAKE i:

What previous answer can I keep?

        ↓

dp[i-1]
```

# Key Takeaways

- House Robber is a **1D DP** problem.
- The main pattern is **Take / Don't Take**.
- If we rob house `i`, we must come from `i-2`.
- If we skip house `i`, we keep `dp[i-1]`.
- `dp[i-1]` is the best answer for all houses `0...i-1`.
- Do not use `nums[i-1]` as the skip candidate.
- Calculate the complete candidate for each choice before taking `max`.
- Tabulation uses **O(n)** space.
- Space optimization uses **O(1)** space.

The core pattern is:

```text
              HOUSE i
             /       \
          TAKE       DON'T TAKE
            |             |
   nums[i] + dp[i-2]     dp[i-1]
            \             /
             \           /
                 max
                  ↓
                dp[i]
```
