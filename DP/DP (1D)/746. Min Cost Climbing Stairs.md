# 746. Min Cost Climbing Stairs

| Topic | Difficulty | Pattern |
| ----- | ---------- | ------- |
| Dynamic Programming | Easy | 1D DP — Min Cost |

---

# 📌 Problem Description

You are given an integer array `cost`.

```text
cost[i] = cost of stepping on step i
```

After paying the cost of a step, you can climb:

```text
1 step
OR
2 steps
```

You can start from either:

```text
index 0
OR
index 1
```

Return the **minimum cost required to reach the top**.

The top is just after the last index and has **no cost**.

---

# Example

### Example 1

Input

```text
cost = [10,15,20]
```

Output

```text
15
```

Explanation:

Start at index `1`:

```text
Pay 15

1 → TOP
```

Total cost:

```text
15
```

---

### Example 2

Input

```text
cost = [1,100,1,1,1,100,1,1,100,1]
```

Output

```text
6
```

One optimal path is:

```text
0 → 2 → 4 → 6 → 7 → 9 → TOP
```

Costs paid:

```text
1 + 1 + 1 + 1 + 1 + 1 = 6
```

---

# 🧠 Intuition

This is the same **1D DP pattern** as Climbing Stairs.

The difference is:

```text
Climbing Stairs
→ Count number of ways

Min Cost Climbing Stairs
→ Find minimum cost
```

To reach step `i`, there are only two possibilities:

```text
i - 1 → i
```

or

```text
i - 2 → i
```

Therefore, we choose the cheaper previous state.

---

# Key Observation

Define:

```text
dp[i] = minimum cost required to reach step i
```

To reach step `i`:

```text
From i-1
OR
From i-2
```

So we take the minimum of the two previous costs and then pay the cost of step `i`.

Conceptually:

```text
minimum cost to reach i

=

cost[i]

+

minimum(
    cost to reach i-1,
    cost to reach i-2
)
```

---

# Important Observation — The Top

The top is **not** an element of `cost`.

For:

```text
cost = [10,15,20]
```

we have:

```text
index:

0       1       2       TOP
10      15      20        -
```

The top has no cost.

We can reach the top from either:

```text
n - 1
```

or:

```text
n - 2
```

Therefore the final answer is:

```text
min(dp[n-1], dp[n-2])
```

---

# Algorithm

```text
Create dp array

↓

dp[0] = cost[0]
dp[1] = cost[1]

↓

For i = 2 to n-1

    dp[i] =
        cost[i] +
        min(dp[i-1], dp[i-2])

↓

The top can be reached from n-1 or n-2

↓

Return min(dp[n-1], dp[n-2])
```

---

# Code — Memoization

```cpp
class Solution {
public:

    int solve(int i, vector<int>& cost, vector<int>& dp)
    {
        if(i <= 1)
            return cost[i];

        if(dp[i] != -1)
            return dp[i];

        return dp[i] =
            cost[i] +
            min(
                solve(i-1, cost, dp),
                solve(i-2, cost, dp)
            );
    }

    int minCostClimbingStairs(vector<int>& cost)
    {
        int n = cost.size();

        if(n <= 2)
            return min(cost[0], cost[1]);

        vector<int> dp(n, -1);

        solve(n-1, cost, dp);

        return min(
            dp[n-1],
            dp[n-2]
        );
    }
};
```

# Code — Tabulation

```cpp
class Solution {
public:

    int minCostClimbingStairs(vector<int>& cost)
    {
        int n = cost.size();

        vector<int> dp(n + 1, 0);

        dp[0] = cost[0];
        dp[1] = cost[1];

        for(int i = 2; i < n; i++)
        {
            dp[i] =
                cost[i] +
                min(dp[i-1], dp[i-2]);
        }

        int ans = min(dp[n-1], dp[n-2]);

        return ans;
    }
};
```

# Why Do We Not Calculate dp[n]?

Because:

```text
cost[n]
```

doesn't exist.

The last valid index is:

```text
n - 1
```

The top is:

```text
n
```

but the top has no cost.

Therefore:

```text
answer = min(dp[n-1], dp[n-2])
```

# Space Optimization

Notice the transition:

```text
dp[i] = cost[i] + min(dp[i-1], dp[i-2])
```

Only the previous two states are required.

Therefore, we don't need the complete DP array.

We can maintain:

```text
first  = dp[i-2]
second = dp[i-1]
```

Then:

```text
current = cost[i] + min(first, second)
```

After calculating:

```text
first = second
second = current
```

---

# Code — Space Optimized

```cpp
class Solution {
public:

    int minCostClimbingStairs(vector<int>& cost)
    {
        int n = cost.size();

        if(n <= 2)
            return min(cost[0], cost[1]);

        int first = cost[0];
        int second = cost[1];

        for(int i = 2; i < n; i++)
        {
            int current =
                cost[i] +
                min(first, second);

            first = second;
            second = current;
        }

        return min(first, second);
    }
};
```

---

# Complexity — Space Optimized

| Complexity | Value |
|------------|-------|
| Time | **O(n)** |
| Space | **O(1)** |

Only three integer variables are used:

```text
first
second
current
```

# Comparison With Climbing Stairs

| Climbing Stairs | Min Cost Climbing Stairs |
| ---------------- | ------------------------ |
| Count ways | Minimize cost |
| `dp[i]` = number of ways | `dp[i]` = minimum cost |
| `dp[i-1] + dp[i-2]` | `cost[i] + min(dp[i-1], dp[i-2])` |
| Addition | Minimum |
| Same 1D DP structure | Same 1D DP structure |

# Key Takeaways

- This is a **1D DP** problem.
- `dp[i]` represents the minimum cost to reach step `i`.
- To reach `i`, we can come from `i-1` or `i-2`.
- We choose the cheaper previous state.
- We pay `cost[i]` when reaching an actual step.
- The top itself has no cost.
- Therefore the final answer is:

```text
min(dp[n-1], dp[n-2])
```

- Tabulation uses **O(n)** space.
- Space optimization reduces it to **O(1)**.
- The important pattern is:

```text
Current State
     ↓
Previous Choices
     ↓
Choose Best Previous State
     ↓
Add Current Cost
```
