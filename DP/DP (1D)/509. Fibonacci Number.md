# 509. Fibonacci Number

| Topic | Difficulty | Pattern |
| ----- | ---------- | ------- |
| Dynamic Programming | Easy | 1D DP — Fibonacci / Linear DP |

---

# 📌 Problem Description

The Fibonacci sequence is defined as:

```text
F(0) = 0
F(1) = 1
F(n) = F(n-1) + F(n-2)
```

Given `n`, return `F(n)`.

---

# Example

### Example 1

Input

```text
n = 4
```

Output

```text
3
```

Explanation:

```text
F(4) = F(3) + F(2)
     = 2 + 1
     = 3
```

### Example 2

Input

```text
n = 5
```

Output

```text
5
```

---

# 🧠 Intuition

The Fibonacci problem naturally leads to recursion:

```text
fib(n)
  |
  +-- fib(n-1)
  |
  +-- fib(n-2)
```

But the same smaller states are calculated repeatedly.

For example:

```text
fib(5)
├── fib(4)
│   ├── fib(3)
│   └── fib(2)
└── fib(3)
```

`fib(3)` is calculated more than once.

This gives us:

```text
Overlapping Subproblems
        +
Store already calculated answers
        =
Dynamic Programming
```

---

# Key Observation

The state is:

```text
dp[i] = Fibonacci value for i
```

For every `i`:

```text
dp[i] depends on dp[i-1] and dp[i-2]
```

There are two main DP approaches:

1. Memoization → Top-Down
2. Tabulation → Bottom-Up

---

# Algorithm

## Approach 1 — Memoization

```text
Create dp array with -1

↓

If n <= 1
return n

↓

If dp[n] is already calculated
return dp[n]

↓

Calculate:
fib(n-1) + fib(n-2)

↓

Store result in dp[n]

↓

Return dp[n]
```

The important point is that the **same `dp` array must be shared** by all recursive calls.

---

# Code — Memoization

```cpp
class Solution {
public:

    int solve(int n, vector<int>& dp)
    {
        if(n <= 1)
            return n;

        if(dp[n] != -1)
            return dp[n];

        return dp[n] = solve(n-1, dp) + solve(n-2, dp);
    }

    int fib(int n)
    {
        vector<int> dp(n + 1, -1);

        return solve(n, dp);
    }
};
```

### Complexity

```text
Time  : O(n)
Space : O(n)
```

Each Fibonacci state is calculated once and then reused.

---

# Approach 2 — Tabulation

Instead of recursion, start from the base cases:

```text
dp[0] = 0
dp[1] = 1
```

Then calculate:

```text
dp[2]
dp[3]
dp[4]
...
dp[n]
```

---

# Code — Tabulation

```cpp
class Solution {
public:

    int fib(int n)
    {
        if(n <= 1)
            return n;

        vector<int> dp(n + 1, -1);

        dp[0] = 0;
        dp[1] = 1;

        for(int i = 2; i <= n; i++)
        {
            dp[i] = dp[i-1] + dp[i-2];
        }

        return dp[n];
    }
};
```

### Complexity

```text
Time  : O(n)
Space : O(n)
```

---

# Space Optimization

Notice:

```text
dp[i]
```

only needs:

```text
dp[i-1]
dp[i-2]
```

Therefore, we don't need the entire DP array.

We only need the previous two values.

---

# Code — Space Optimized

```cpp
class Solution {
public:

    int fib(int n)
    {
        if(n <= 1)
            return n;

        int prev2 = 0;
        int prev1 = 1;

        for(int i = 2; i <= n; i++)
        {
            int curr = prev1 + prev2;

            prev2 = prev1;
            prev1 = curr;
        }

        return prev1;
    }
};
```

### Complexity

```text
Time  : O(n)
Space : O(1)
```

---

# Comparison

| Approach | Time | Space | Idea |
| -------- | ---- | ----- | ---- |
| Recursion | O(2^n) | O(n) | Recalculates states |
| Memoization | O(n) | O(n) | Recursion + cache |
| Tabulation | O(n) | O(n) | Iterative DP table |
| Space Optimized | O(n) | O(1) | Keep last 2 states |

# DP Pattern Learned

```text
1D / Linear DP
```

State:

```text
dp[i]
```

Current state depends on:

```text
dp[i-1]
dp[i-2]
```

This pattern appears in:

```text
Fibonacci
   ↓
Climbing Stairs
   ↓
Min Cost Climbing Stairs
   ↓
House Robber
   ↓
Decode Ways
```

The important lesson is not Fibonacci itself.

The important lesson is:

```text
Define the state
      ↓
Find smaller states
      ↓
Store their answers
      ↓
Build the current answer
```

---

# Key Takeaways

- Fibonacci is the simplest introduction to DP.
- Naive recursion has overlapping subproblems.
- Memoization = Top-Down DP.
- Tabulation = Bottom-Up DP.
- `dp[i]` represents the answer for state `i`.
- Base cases are the starting states.
- Tabulation computes states in dependency order.
- If the current state only needs a few previous states, space can be optimized.
- The DP array must be shared across recursive calls in memoization.
