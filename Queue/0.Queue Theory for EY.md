# Queue — Complete Theory for EY

## 1. What is a Queue?

A **Queue** is a linear data structure that follows:

> **FIFO — First In, First Out**

The element inserted first is removed first.

```text
Front → [10] [20] [30] [40] ← Rear
```

* **Insertion** → Rear
* **Deletion** → Front

---

# 2. Why Do We Need a Queue?

Arrays/vectors are good for random access:

```cpp
arr[i]
```

But many problems require:

> Process elements in the same order they arrived.

Queue provides exactly this behavior.

### Common Applications

* CPU / task scheduling
* Printer jobs
* Request processing
* Network buffering
* Producer-consumer systems
* **BFS traversal**
* Level-order traversal of trees

---

# 3. Basic Operations

| Operation            | Meaning            | Complexity |
| -------------------- | ------------------ | ---------: |
| `enqueue()`          | Insert at rear     |       O(1) |
| `dequeue()`          | Remove from front  |       O(1) |
| `front()` / `peek()` | View front         |       O(1) |
| `back()`             | View rear          |       O(1) |
| `isEmpty()`          | Check empty        |       O(1) |
| `size()`             | Number of elements |       O(1) |
| Search               | Find an element    |       O(n) |

Space Complexity:

```text
O(n)
```

---

# 4. Queue Example

```text
Initial:
[10] [20] [30]

enqueue(40)

[10] [20] [30] [40]

dequeue()

[20] [30] [40]

front() → 20
```

---

# 5. Why Not Simply Use an Array?

Suppose:

```text
[10] [20] [30] [40] [50]
 ↑
remove
```

If we physically remove `10`, all elements must shift:

```text
[20] [30] [40] [50]
```

This takes:

```text
O(n)
```

A proper queue instead maintains a **front index/pointer**, avoiding shifting.

Therefore:

```text
Enqueue → O(1)
Dequeue → O(1)
```

---

# 6. Queue Implementation Using Array

Maintain:

```text
front
rear
```

Example:

```text
[10] [20] [30] [40]
 ↑              ↑
front          rear
```

After dequeue:

```text
[10] [20] [30] [40]
       ↑         ↑
     front      rear
```

No shifting is required.

---

# 7. Queue Using Linked List

Use:

```text
front → [10] → [20] → [30] ← rear
```

* `front` = first node
* `rear` = last node

### Enqueue

Insert at rear:

```text
front → 10 → 20 → 30 → 40 ← rear
```

### Dequeue

Remove from front:

```text
front → 20 → 30 → 40
```

Complexities:

| Operation | Complexity |
| --------- | ---------: |
| Enqueue   |       O(1) |
| Dequeue   |       O(1) |
| Front     |       O(1) |

---

# 8. Problem With Array Queue

Consider:

```text
[10] [20] [30] [40] [50]
```

After removing some elements:

```text
[ ] [ ] [ ] [40] [50]
            ↑     ↑
          front  rear
```

Space exists at the beginning, but `rear` may reach the end.

This causes:

> **Wasted space / False Overflow**

### Solution

**Circular Queue**

---

# 9. Circular Queue

A circular queue treats the array as circular.

```text
Last index → First index
```

Conceptually:

```text
      ┌─────────────────┐
      ↓                 │
[0] [1] [2] [3] [4] [5]
 ↑                     ↓
 └─────────────────────┘
```

Now freed positions can be reused.

### Important Formula

For array size `N`:

```cpp
rear = (rear + 1) % N;
front = (front + 1) % N;
```

Example:

```text
N = 5
rear = 4

(4 + 1) % 5 = 0
```

So rear wraps around.

### Why Circular Queue?

```text
Normal array queue:
free space at beginning
        +
rear reaches end
        ↓
wasted capacity
```

Circular queue reuses that space.

# 10. Types of Queue

## 1. Simple Queue

Normal FIFO queue.

```text
Insert → Rear
Delete → Front
```

---

## 2. Circular Queue

Last position connects back to first.

Used to efficiently reuse array space.

---

## 3. Deque

**Double Ended Queue**

Insertion and deletion can happen at both ends.

```text
← insert/delete [10][20][30] insert/delete →
```

C++:

```cpp
deque<int> dq;

dq.push_front(10);
dq.push_back(20);

dq.pop_front();
dq.pop_back();
```

---

## 4. Priority Queue

Not FIFO.

Element with highest/lowest priority is processed first.

```text
insert:
5, 1, 10

10 comes out first   // max priority by default
```

C++:

```cpp
priority_queue<int> pq;
```

Min-heap:

```cpp
priority_queue<int, vector<int>, greater<int>> pq;
```

Default `priority_queue` in C++ behaves as a **max-heap**.

# 11. Queue vs Stack

| Feature | Queue           | Stack     |
| ------- | --------------- | --------- |
| Rule    | FIFO            | LIFO      |
| Insert  | Rear            | Top       |
| Delete  | Front           | Top       |
| Example | Scheduling, BFS | Undo, DFS |

```text
Queue → First In First Out
Stack → Last In First Out
```

# 12. Queue vs Array

### Array

```text
Random access
arr[i]
```

### Queue

```text
Ordered processing
front → delete
rear  → insert
```

Use a queue when processing order matters more than random access.

---

# 13. Queue vs Linked List

A **Linked List** is a general node-based linear structure.

A **Queue** is an abstract data structure with restricted operations:

```text
insert → rear
delete  → front
```

A linked list can be used **to implement a queue**.

They are not the same thing.

---

# 14. Queue vs Deque

### Queue

```text
Insert → Rear
Delete  → Front
```

### Deque

```text
Insert/Delete from both ends
```

Useful mental model:

```text
Queue = restricted Deque
```

---

# 15. When to Use Queue?

Use Queue when:

> **Things must be processed in arrival order.**

Typical cases:

```text
BFS
Task scheduling
Request processing
Printer jobs
Buffers
Producer-consumer
```

---

# 16. When NOT to Use Queue?

### Need LIFO

Use **Stack**.

### Need random access

Use **Array / Vector**.

### Need highest/lowest priority first

Use **Priority Queue / Heap**.

### Need both ends

Use **Deque**.

---

# 17. Queue and BFS

This is one of the most important Queue applications.

Example:

```text
        1
       / \
      2   3
     / \
    4   5
```

BFS:

```text
1 → 2 → 3 → 4 → 5
```

Queue process:

```text
push(1)

pop 1
push(2), push(3)

pop 2
push(4), push(5)

pop 3
...
```

### Why Queue?

Because BFS processes nodes **level by level**.

```text
Level 0 → 1
Level 1 → 2, 3
Level 2 → 4, 5
```

# 18. Queue in C++ STL

```cpp
#include <queue>

queue<int> q;
```

### Insert

```cpp
q.push(10);
q.push(20);
```

### Front

```cpp
q.front();
```

### Rear

```cpp
q.back();
```

### Remove

```cpp
q.pop();
```

Important:

```cpp
q.pop();
```

does **NOT** return the removed element.

Correct:

```cpp
int x = q.front();
q.pop();
```

### Other functions

```cpp
q.empty();
q.size();
```

# 20. Queue Using Two Stacks

A Queue can be implemented using **two Stacks**.

Idea:

```text
Stack 1 → incoming elements
Stack 2 → outgoing elements
```

Suppose:

```text
enqueue:
10, 20, 30

Stack 1:
30
20
10
```

Move to Stack 2:

```text
Stack 2:
10
20
30
```

Now:

```text
pop → 10
```

FIFO behavior is achieved using two LIFO structures.

### Complexity

Amortized:

```text
Enqueue → O(1)
Dequeue → O(1)
```

A single transfer can cost O(n), but over many operations the amortized cost is O(1).

For EY:

> Know the concept and basic implementation idea. Don't waste time on deep amortized-analysis proofs.

---

# 21. Advantages

* Simple FIFO processing
* O(1) insertion/deletion with proper implementation
* Excellent for scheduling
* Natural structure for BFS
* Useful for buffering

---

# 22. Limitations

* No efficient random access
* Usually only front/rear are directly accessible
* Not suitable for priority-based processing
* Naive array implementation can waste space
* Circular queue is needed to efficiently reuse array capacity

# 23. Important Interview Traps

### 1. Does `pop()` return the removed element?

```cpp
q.pop();
```

**No.**

Use:

```cpp
int x = q.front();
q.pop();
```

---

### 2. Is Priority Queue FIFO?

**No.**

Priority determines removal order.

---

### 3. Why Circular Queue?

To reuse freed array positions and avoid wasted capacity.

---

### 4. What does `front()` return?

The element that will be removed next.

---

### 5. Can Queue be implemented using Stack?

**Yes**, using two stacks.
