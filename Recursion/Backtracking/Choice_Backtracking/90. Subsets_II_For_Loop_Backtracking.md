# 📌 Problem Description

Given an array that **may contain duplicate elements**, generate **all unique subsets**.

Example

```text
Input

[1,2,2]

Output

[]

[1]

[2]

[1,2]

[2,2]

[1,2,2]
```

Duplicate subsets are **not allowed**.

---

# 🧠 Core Insight

## Subsets I

Think

```text
Current Element

↓

Take

OR

Skip
```

Binary recursion.

---

## Subsets II

Think

```text
Current Subset

↓

What can I choose NEXT?
```

N-ary recursion using a **for loop**.

---

# ⚙️ Algorithm

```text
Store current subset

↓

Loop through every possible next choice

↓

Choose one element

↓

Recursive Call

↓

Undo choice

↓

Continue loop
```

# 🎯 Why does it return?

There is **no explicit base case**.

Suppose

```text
solve(3)

curr=[1,2,3]
```

Loop

```cpp
for(i=3;i<3;i++)
```

Check

```text
3<3 ?

false
```

No iterations.

Function reaches

```cpp
}
```

and automatically returns.

# ⭐ Duplicate Skipping

nums

```text
[1,2,2]
```

Level

```text
[]

↓

Choices

1

2(first)

2(second)
```

Choosing first

```text
2
```

already generates

```text
[2]

[2,2]
```

Starting another branch from second

```text
2
```

produces identical subsets.

Skip it.

# 💻 Code (C++)

```cpp
class Solution {
public:

    void solve(int index,
               vector<int>& curr,
               vector<vector<int>>& ans,
               vector<int>& nums)
    {
        ans.push_back(curr);

        for(int i=index;i<nums.size();i++)
        {
            if(i>index && nums[i]==nums[i-1])
                continue;

            curr.push_back(nums[i]);

            solve(i+1,curr,ans,nums);

            curr.pop_back();
        }
    }

    vector<vector<int>> subsetsWithDup(vector<int>& nums)
    {
        sort(nums.begin(),nums.end());

        vector<vector<int>> ans;
        vector<int> curr;

        solve(0,curr,ans,nums);

        return ans;
    }
};
```

# ⏱ Time Complexity

For every element,

```text
Choose

OR

Don't choose through loop branches
```

Total subsets generated

```text
O(2^n)
```

Copying each subset costs

```text
O(n)
```

Overall

```text
O(n × 2^n)
```

Sorting

```text
O(n log n)
```

is dominated by

```text
O(n × 2^n)
```

# ⚠️ Common Mistakes

❌ Mixing Pick/Not Pick with For Loop.

❌ Using

```cpp
nums[index]
```

instead of

```cpp
nums[i]
```

inside loop.

❌ Using

```cpp
solve(index+1)
```

instead of

```cpp
solve(i+1)
```

❌ Forgetting

```cpp
curr.pop_back();
```

❌ Forgetting

```cpp
sort(nums.begin(),nums.end());
```

❌ Writing

```cpp
if(nums[i]==nums[i-1])
```

instead of

```cpp
if(i>index && nums[i]==nums[i-1])
```

# 🎯 Interview One-Liner

> **Subsets II uses for-loop backtracking: store every node, choose one candidate, recurse, undo the choice, and skip duplicate values only at the same recursion level.**
