# 📌 Problem Description

Given an array that **may contain duplicates**, generate all possible subsets.

Example

```text
Input

[1,2,2]

Output

[]

[1]

[1,2]

[1,2,2]

[2]

[2,2]
```

Notice

```text
[2]
```

should appear **only once**.

---

# 🧠 Biggest Mental Shift

There are **TWO completely different recursion patterns**.

## Pattern 1 (Old)

```text
Current Element

↓

Take ?

OR

Skip ?
```

Binary Tree

```text
        1

      /   \

   Take   Skip
```

Used in

```text
Subsets
Target Sum
Partition
```

---

## Pattern 2 (New)

Think

```text
Current Subset

↓

Which element can I choose NEXT ?
```

Not

```text
Take / Skip
```

but

```text
Choose 1 ?

Choose 2 ?

Choose 3 ?
```

# 🌳 Recursion Tree

nums

```text
[1,2,3]
```

Tree

```text
                     []

          /            |            \

        [1]           [2]          [3]

      /     \           |

   [1,2]   [1,3]      [2,3]

      |

 [1,2,3]
```

Every node is already a valid subset.

# ⭐ Why ans.push_back(curr) is FIRST?

Code

```cpp
void solve(...)
{
    ans.push_back(curr);

    for(...)
    {
        ...
    }
}
```

Whenever recursion reaches a node,

it immediately stores it.

Example

```text
solve([])

↓

store []

↓

choose 1

↓

solve([1])

↓

store [1]

↓

choose 2

↓

solve([1,2])

↓

store [1,2]

↓

choose 3

↓

solve([1,2,3])

↓

store [1,2,3]
```

We store at **every node**, not only leaves.

# ⭐ How Return Works

Many people think recursion returns because of a base case.

Here,

there is NO explicit base case.

It returns because

```text
for(i=3;i<3;i++)
```

has zero iterations.

Function reaches

```text
}
```

↓

return

# ⭐ Duplicate Condition

```cpp
if(i>index && nums[i]==nums[i-1])
    continue;
```

Meaning

```text
Same recursion level

+

Same value already chosen

↓

Skip starting another identical branch.
```

Example

```text
nums=[1,2,2]

Level

i=1

Choose first 2

✓

i=2

Second 2

↓

Same level

↓

Skip
```

---

# ⭐ Why i>index ?

Because

the FIRST duplicate must still be explored.

Example

```text
nums=[2,2]
```

Need

```text
[]

[2]

[2,2]
```

If we skipped

```text
nums[i]==nums[i-1]
```

without

```text
i>index
```

then

```text
[2,2]
```

would never be generated.

# 🔥 Golden Rule

```text
Take/Skip Recursion

↓

Binary Tree

----------------------

For Loop Backtracking

↓

DFS

↓

Visit Node

↓

Store Answer

↓

Go Deep

↓

Return

↓

Continue Loop

↓

Go Next Branch
```

# 🎯 Interview One-Liner

> **For-loop backtracking is DFS over all possible choices. Every recursive call stores the current state, explores one choice, returns, undoes that choice, and continues the loop with the next available option.**
