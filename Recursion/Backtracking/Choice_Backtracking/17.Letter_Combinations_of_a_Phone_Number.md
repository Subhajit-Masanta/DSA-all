# 📌 Problem Description

Given a string containing digits **2-9**, return every possible letter combination represented by the phone keypad.

Phone Mapping

```text
2 -> abc

3 -> def

4 -> ghi

5 -> jkl

6 -> mno

7 -> pqrs

8 -> tuv

9 -> wxyz
```

Example

```text
Input

digits = "23"

Output

ad

ae

af

bd

be

bf

cd

ce

cf
```

# ⭐ Why only ONE loop?

Many people think

```
Need two loops

for abc

    for def
```

Wrong.

Recursion automatically creates nested loops.

We only write

```cpp
for(char c : map[digit])
```

Recursion creates the next loop.

```
for abc

↓

Recursive Call

↓

for def

↓

Recursive Call

↓

for ghi

...
```

# 💻 Code (C++)

```cpp
class Solution {
public:

    void backtrack(int index,
                   string digits,
                   string current,
                   vector<string>& ans,
                   vector<string>& map)
    {
        if(current.length()==digits.length())
        {
            ans.push_back(current);
            return;
        }

        int digit = digits[index]-'0';

        string s = map[digit];

        for(char c : s)
        {
            current += c;

            backtrack(index+1,
                      digits,
                      current,
                      ans,
                      map);

            current.pop_back();
        }
    }

    vector<string> letterCombinations(string digits)
    {
        vector<string> ans;

        if(digits.empty())
            return ans;

        vector<string> map = {

            "", "",

            "abc",

            "def",

            "ghi",

            "jkl",

            "mno",

            "pqrs",

            "tuv",

            "wxyz"

        };

        backtrack(0,digits,"",ans,map);

        return ans;
    }
};
```

# 🎯 Interview One-Liner

> **Letter Combinations uses for-loop backtracking: for the current digit, try every mapped letter, recurse to the next digit, then remove the chosen letter and continue exploring.**
