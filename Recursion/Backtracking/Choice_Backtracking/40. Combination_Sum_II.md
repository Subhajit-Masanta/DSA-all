# 📌 Problem Description

Find all unique combinations whose sum equals the target.

Rules

```text
✓ Every element can be used only ONCE.

✓ Duplicate combinations are NOT allowed.
```

Example

```text
Input

[10,1,2,7,6,1,5]

target=8

Output

[1,1,6]

[1,2,5]

[1,7]

[2,6]
```

# ⚙️ Algorithm

```text
Sort array

↓

Store current combination only when sum==target

↓

Loop over possible choices

↓

Skip duplicate values at same level

↓

Choose element

↓

Recursive call with i+1

↓

Undo choice

↓

Continue loop
```

# ⭐ Why duplicate check?

At root

```
[]

↓

1(first)

↓

creates

[1,1]

[1,2]

[1,5]

...

```

Starting another branch from

```
1(second)
```

creates exactly the same combinations.

So

```cpp
if(i>index && nums[i]==nums[i-1])

continue;
```

# 💻 Code (C++)

```cpp
class Solution {
public:

    void solve(int index,
               vector<int>& current,
               int currentSum,
               vector<int>& candidates,
               int target,
               vector<vector<int>>& ans)
    {
        if(currentSum==target)
        {
            ans.push_back(current);
            return;
        }

        if(currentSum>target)
            return;

        for(int i=index;i<candidates.size();i++)
        {
            if(i>index && candidates[i]==candidates[i-1])
                continue;

            current.push_back(candidates[i]);

            solve(i+1,
                  current,
                  currentSum+candidates[i],
                  candidates,
                  target,
                  ans);

            current.pop_back();
        }
    }

    vector<vector<int>> combinationSum2(vector<int>& candidates,
                                        int target)
    {
        sort(candidates.begin(),candidates.end());

        vector<vector<int>> ans;
        vector<int> current;

        solve(0,current,0,candidates,target,ans);

        return ans;
    }
};
```

# ⏱ Time Complexity

Worst case

```
O(2^n × n)
```

* `2^n` recursive combinations
* `n` to copy/store a combination

Sorting

```
O(n log n)
```

is dominated by recursion.

# ⚠️ Common Mistakes

❌ Forgetting to sort.

❌ Using

```cpp
solve(i)
```

instead of

```cpp
solve(i+1)
```

❌ Forgetting

```cpp
if(i>index && nums[i]==nums[i-1])
```

which generates duplicate combinations.

# 🎯 Interview One-Liner

> **Combination Sum II is Combination Sum with two extra rules: sort the array, skip duplicate branches at the same recursion level, and recurse with `i+1` because each element can be used only once.**
