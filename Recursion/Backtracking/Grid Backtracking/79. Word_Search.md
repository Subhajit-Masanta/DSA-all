# Problem

Given an `m x n` grid and a word, determine whether the word exists in the grid.

Rules:

- Move only **Up, Down, Left, Right**
- Cannot move diagonally
- A cell can be used **only once**

Example

Board

A B C E

S F C S

A D E E

Word

ABCCED

Output

true

# Starting Point

We don't know where the word starts.

So traverse the entire grid.

```cpp
for(i=0;i<rows;i++)
{
    for(j=0;j<cols;j++)
    {
        if(board[i][j]==word[0])
            solve(...)
    }
}
```

Only the main function uses two loops.

# Code

```cpp
class Solution {
public:

    bool solve(int row,int col,int index,
               vector<vector<char>>& board,
               string word)
    {
        int rows=board.size();
        int cols=board[0].size();

        if(index==word.size())
            return true;

        if(row<0 || row>=rows ||
           col<0 || col>=cols)
            return false;

        if(board[row][col]!=word[index])
            return false;

        char temp=board[row][col];
        board[row][col]='#';

        bool up=solve(row-1,col,index+1,board,word);
        bool down=solve(row+1,col,index+1,board,word);
        bool left=solve(row,col-1,index+1,board,word);
        bool right=solve(row,col+1,index+1,board,word);

        board[row][col]=temp;

        return up||down||left||right;
    }

    bool exist(vector<vector<char>>& board,
               string word)
    {
        int rows=board.size();
        int cols=board[0].size();

        for(int i=0;i<rows;i++)
        {
            for(int j=0;j<cols;j++)
            {
                if(board[i][j]==word[0])
                {
                    if(solve(i,j,0,board,word))
                        return true;
                }
            }
        }

        return false;
    }
};
```

# Time Complexity

Let

```
m = rows

n = cols

L = word length
```

Worst Case

```
O(m × n × 4^L)
```

- Every cell can be a starting point.
- At each character we may explore four directions.

---

# Space Complexity

Recursion Stack

```
O(L)
```

where

```
L = word length
```

(Result storage not included.)

# Interview One-Liner

> Grid Backtracking explores four directions from a cell, marks the current cell as visited, recursively searches for the next character, restores the cell, and returns whether any path successfully forms the target word.
