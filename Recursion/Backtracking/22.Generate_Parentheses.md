
| Topic                | Difficulty | Pattern                      |
| :------------------- | :--------- | :--------------------------- |
| Generate Parentheses | Medium     | Backtracking / Pick-Not Pick |

---

# 📌 Problem Description

Given `n` pairs of parentheses, generate all possible **well-formed** parentheses combinations.

Example

```text
n = 2

Output

(())

()()
```

---

# 🧠 Core Insight

At every step we have **two choices**.

```text
Add '('

OR

Add ')'
```

But we only make **valid choices**.

---

# ⚙️ Conditions

## Can add '(' ?

```text
open < n
```

---

## Can add ')' ?

```text
close < open
```

This guarantees the string is always valid.

---

# ⚙️ Algorithm

```text
Start with ""

↓

Try '('

↓

Try ')'

↓

If length == 2*n

Store Answer

Return
```

---

# 🌳 Recursion Tree (n = 2)

```text
                        ""
                         |
                        "("
                      /     \
                   "(("      "()"
                     |          |
                  "(()"      "()("
                     |          |
                  "(())"     "()()"
```

Only valid branches are explored.

## Initial Call


```
open = 0

close = 0
```

Only '(' can be added.

↓

```text

```

## From "("

Two choices are possible.

```text
                 "("

            "(("      "()"
```

## Left Branch

```text

↓

solve(2,1,2,"(()")

↓

solve(2,2,2,"(())")
```

Base Case

```cpp

return;
```

# 🔄 Where does return go?

It always returns to the **function that called it**.

```text
TOP

solve(2,1,"(()")   ← resumes here

solve(2,0,"((")

solve(1,0,"(")

solve(0,0,"")

BOTTOM
```

---

Back at

```text
solve(2,1,"(()")
```

No more statements.

```text
return;
```

↓

Back to

```text
solve(2,0,"((")
```

No more statements.

```text
return;
```

↓

Back to

```text
solve(1,0,"(")
```

# ⭐ The Magic

Current function

```cpp
if(open<n)
{
    solve(...);
}

if(close<open)
{
    solve(...);
}
```

The first `if` has completely finished.

CPU continues to the **next line**.

```text
if(close<open)

↓

TRUE

↓

Explore Right Branch
```

---

## Right Branch

```text
solve(1,1,2,"()")

↓

solve(2,1,2,"()(")

↓

solve(2,2,2,"()()")
```

Base Case

```cpp
ans.push_back("()()");
```

# 📚 Why is this a Subsequence Pattern?

Normal Subsequence

```text
Current Element

↓

Pick

OR

Not Pick
```

Tree

```text
           []
          /  \
       Pick  Not Pick
```

---

Generate Parentheses uses the same idea.

```text
Current String

↓

Add '('

OR

Add ')'
```

Tree

```text
               ""
              /  \
            "("   ")"
```

Difference:

For subsequences, **both branches are always explored**.

For Generate Parentheses,

```text
Invalid Branch

↓

Pruned

↓

Not Explored
```

So it becomes **Backtracking (Subsequence + Constraints)**.

---

# 💻 Code (C++)

```cpp
class Solution {
public:

    void solve(int open,
               int close,
               int n,
               string current,
               vector<string> &ans)
    {
        if(open + close == 2*n)
        {
            ans.push_back(current);
            return;
        }

        if(open < n)
        {
            solve(open+1,
                  close,
                  n,
                  current+'(',
                  ans);
        }

        if(close < open)
        {
            solve(open,
                  close+1,
                  n,
                  current+')',
                  ans);
        }
    }

    vector<string> generateParenthesis(int n)
    {
        vector<string> ans;

        solve(0,0,n,"",ans);

        return ans;
    }
};
```

# ⏱ Time Complexity

Approximately

```text
O(2^(2n))
```

Many branches are pruned, so actual nodes are much fewer.

---

# 📦 Space Complexity

```text
Recursion Depth

=

2*n

↓

O(n)
```

# ⚠️ Common Mistakes

❌ Using

```cpp
if(...)
{

}
else if(...)
{

}
```

Only one branch is explored.

Always use

```cpp
if(...)
{

}

if(...)
{

}
```

---

❌ Forgetting

```text
close < open
```

which creates invalid strings.

---

# 🔥 Golden Backtracking Rule

```text
Go LEFT as much as possible

↓

Hit Base Case

↓

Return ONE LEVEL

↓

Continue Remaining Code

↓

Explore RIGHT

↓

Return

↓

Return

↓

Finished
```

---

# 🎯 Interview One-Liner

> **Generate Parentheses is a Backtracking problem built on the Pick/Not Pick (Subsequence) pattern, where invalid branches are pruned using constraints (`open<n` and `close<open`).**
