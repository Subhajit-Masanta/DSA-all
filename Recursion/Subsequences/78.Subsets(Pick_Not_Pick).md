# 📌 Problem Description

Given an array of unique elements, generate **all possible subsets (Power Set)**.

Example

```text
Input

[1,2,3]

Output

[]

[1]

[2]

[3]

[1,2]

[1,3]

[2,3]

[1,2,3]
```

Order does not matter.

---

# 🧠 Core Insight

For every element we have exactly **two choices**.

```text
Take it

OR

Leave it
```

Every recursion call simply decides

```text
Current Element

↓

Take

OR

Skip
```

---

# 🌳 Decision Tree

Example

```text
nums = [1,2]
```

```text
                    []
                  /    \
             Take1    Skip1
              [1]       []
             /  \      /  \
         T2     S2   T2    S2
      [1,2]   [1]   [2]    []
```

Every leaf is one subset.

# 🧪 Dry Run

Input

```text
nums = [1,2]
```

Start

```text
curr = []

index = 0
```

---

## Take 1

```text
curr.push_back(1)

↓

curr = [1]

↓

solve(index+1)
```

---

## Take 2

```text
curr.push_back(2)

↓

curr = [1,2]

↓

Base Case

↓

Store [1,2]
```

Return

```text
curr.pop_back()

↓

curr = [1]
```

---

## Leave 2

```text
solve(index+1)

↓

Base Case

↓

Store [1]
```

Return.

---

Back to root.

Undo previous choice.

```text
curr.pop_back()

↓

curr = []
```

---

## Leave 1

Now explore

```text
[]

↓

Take 2

↓

Store [2]

↓

Leave 2

↓

Store []
```

---

Final Answer

```text
[1,2]

[1]

[2]

[]
```

# 💻 Code (C++)

```cpp
class Solution {
public:

    void solve(int index,
               vector<int>& curr,
               vector<vector<int>>& ans,
               vector<int>& nums)
    {
        if(index == nums.size())
        {
            ans.push_back(curr);
            return;
        }

        // Take
        curr.push_back(nums[index]);

        solve(index+1,curr,ans,nums);

        // Undo
        curr.pop_back();

        // Leave
        solve(index+1,curr,ans,nums);
    }

    vector<vector<int>> subsets(vector<int>& nums)
    {
        vector<vector<int>> ans;
        vector<int> curr;

        solve(0,curr,ans,nums);

        return ans;
    }
};
```

# ⏱ Time Complexity

Every element has

```text
Take

OR

Leave
```

Therefore

```text
2 × 2 × 2 × ...

↓

2ⁿ subsets
```

Time

```text
O(2ⁿ × n)
```

(`n` is needed to copy each subset.)

---

# 📦 Space Complexity

```text
Recursion Depth

↓

n

↓

O(n)
```

(Result storage excluded.)

# ⚠️ Common Mistakes

❌ Forgetting

```cpp
curr.pop_back();
```

The skip branch will contain extra elements.

---

❌ Using

```cpp
if...
else...
```

instead of exploring **both** branches.

---

❌ Forgetting base case

```cpp
if(index == nums.size())
```
