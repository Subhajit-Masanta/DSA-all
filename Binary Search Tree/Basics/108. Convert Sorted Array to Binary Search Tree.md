# 108. Convert Sorted Array to Binary Search Tree

| Topic | Difficulty | Pattern                      |
| ----- | ---------- | ---------------------------- |
| BST   | Easy       | Divide & Conquer / Recursion |

---

# 📌 Problem Description

Given a **sorted array** in ascending order, convert it into a **height-balanced Binary Search Tree (BST).**

A **height-balanced BST** is one where the height difference between the left and right subtree of every node is at most **1**. ([geeksforgeeks.org](https://www.geeksforgeeks.org/dsa/sorted-array-to-balanced-bst/?utm_source=chatgpt.com))

---

# 🧠 Understanding the Question

Input

```text
[-10, -3, 0, 5, 9]
```

We need to build a BST.

Remember the BST property:

```text
Left < Root < Right
```

---

# Why Can't We Choose the First Element?

Suppose root = -10

```text
-10
   \
   -3
      \
       0
        \
         5
          \
           9
```

Height becomes

```text
O(n)
```

Not balanced.

---

# Why Can't We Choose the Last Element?

```text
        9
       /
      5
     /
    0
   /
 -3
 /
-10
```

Again

```text
O(n)
```

Still not balanced.

---

# ⭐ Key Observation

Always choose the **middle element**.

```text
[-10  -3   0   5   9]
          ↑
        Root
```

Now

```text
Left

[-10,-3]

Right

[5,9]
```

Both halves are almost equal in size.

This naturally creates a **balanced BST**. ([algo.monster](https://algo.monster/liteproblems/108?utm_source=chatgpt.com))

---

# Intuition

The middle element becomes the root.

Then solve the exact same problem for

* Left half
* Right half

This is a classic **Divide and Conquer** problem.

---

# Algorithm

```text
Choose Middle

↓

Create Root Node

↓

Recursively Build Left Subtree

↓

Recursively Build Right Subtree

↓

Return Root
```

---

# Recursive Function

Instead of passing the whole array every time,

pass only

```cpp
(low, high)
```

Meaning

```text
Build BST using nums[low...high]
```

---

# Base Case

When

```cpp
low > high
```

there are no elements left.

Return

```cpp
nullptr;
```

# Code

```cpp
class Solution {
public:

    TreeNode* solve(vector<int>& nums, int low, int high)
    {
        if(low > high)
            return nullptr;

        int mid = low + (high - low) / 2;

        TreeNode* node = new TreeNode(nums[mid]);

        node->left = solve(nums, low, mid - 1);
        node->right = solve(nums, mid + 1, high);

        return node;
    }

    TreeNode* sortedArrayToBST(vector<int>& nums)
    {
        return solve(nums, 0, nums.size() - 1);
    }
};
```

---

# Why This Works

At every recursive call

```text
Choose Middle

↓

Middle becomes Root

↓

Left Half → Left Subtree

↓

Right Half → Right Subtree
```

Because both halves are nearly equal,

the resulting BST remains balanced.

---

# Common Mistakes

## ❌ Creating the node before checking

Wrong

```cpp
TreeNode* node = new TreeNode(nums[mid]);

if(low > high)
```

Always check

```cpp
if(low > high)
    return nullptr;
```

first.

---

## ❌ Choosing the first element

Produces

```text
Skewed Tree

Height = O(n)
```

---

## ❌ Choosing the last element

Also produces a skewed tree.

---

## ❌ Forgetting Divide & Conquer

This problem is not about traversal.

It is about repeatedly dividing the array.

# Complexity

| Complexity | Value                                              |
| ---------- | -------------------------------------------------- |
| Time       | **O(n)**                                           |
| Space      | **O(log n)** (recursion stack for a balanced tree) |

Every element is visited exactly once to create one tree node. ([algo.monster](https://algo.monster/liteproblems/108?utm_source=chatgpt.com))

# Pattern Recognition

Whenever you see

```text
Sorted Array

+

Balanced BST
```

Immediately think

```text
Choose the Middle Element

↓

Recursive Divide & Conquer
```

This is essentially **Binary Search used to construct a balanced tree**.

---

# Key Takeaways

* BST requires **Left < Root < Right**.
* Choosing the middle keeps the tree balanced.
* Solve recursively on the left and right halves.
* Pass indices (`low`, `high`) instead of creating new arrays.
* This is a **Divide & Conquer** pattern, not a traversal problem.
